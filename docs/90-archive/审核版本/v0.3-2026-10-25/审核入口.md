# 伙伴控制与代表房间专项审核 v0.3

状态：研究候选，待用户审核。本版沿[v0.2 成长与普通单局](../2026-10-25-v0.2/审核入口.md)，补充伙伴控制、行动顺序和同房间的逐回合对照。新增实质规则另成版本，v0.1/v0.2 正文保持原样。

先读[伙伴控制与代表房间推演](伙伴控制与代表房间推演.md)，重点看控制的输入负担、我方先行动的收益，以及四组行动表。记录见[审核记录](审核记录.md)，来源身份见[来源版本清单](来源版本清单.json)。

## 当前建议及代价

| 事项 | 研究起点 | 需要接受的代价 |
| --- | --- | --- |
| 伙伴控制 | 平时控制一名，伙伴默认跟随与保守普通攻击；提交回合前可改伙伴这一回合的行动 | 精确配合需要更多输入，复杂战斗可能接近全队手动 |
| 行动顺序 | 固定我方队列各行动一次，再由存活敌人各行动一次 | 集火先杀可以取消敌人行动；新增队员的价值会受先手顺序放大 |
| 移动与招式 | 一次移动或一次招式，不能同回合先移动再施招；免费切换选择角色不增加行动 | 站位准备有成本，当前不能攻击的伙伴可能只能等待或移动 |
| 新人作用 | 从另一条直线提前处理远程敌人 | 使用自身 PP；受墙和队友遮挡，击杀阈值改变时不一定立即减伤 |
| 老伙伴学习 | 等招式数、等 PP，用远距推退替换近身推退 | 消耗招式机并占配招位；可以保住前排，但也可能多挨远程攻击、多花一回合 |

## 本版能支持到哪里

四组推演说明：在明示的房间、伤害和行动顺序下，新人和培养招式可以改变可选行动；老伙伴的新招式并非每次都更划算。它们没有证明默认伙伴行为足够聪明、操作负担可接受、先手规则平衡或真实游戏好玩。

用户已确定的仍是行动推进回合。具体控制、队列、每人一次行动、射程、伤害、无友伤及暂不使用速度差异均是本版候选或对照输入。首批范围仍是一张普通迷宫、一条培养路径；未进入游戏实现、第二连续区域或 REA 外部研究。
