# 8.9 后续招式与道具范围

## 1. 目标与边界

招式与道具继续以《不可思议的迷宫》探险队系列为主要依据，数值换算到本作尺度。现行规则见[游戏规则](../../01-现行规则/游戏规则.md)，决定见[决策登记](../../03-决策/决策登记.md)。

用户2026-11-14已确认交付的规则草案，先细化B3休息与B9喜悦种子的本作接入；其余项目继续补齐事实或接口。dev独立完成研究与当前规格，依据见 [#229](https://github.com/392fyc/pokemon-dungeon-lab/issues/229#issuecomment-6874384171) 和[探险队机制研究](../../06-研究/玩法研究/探险队招式与道具机制.md)。具体实施issue须给出文件分工、入口和验收例子。平衡工作由 #168 恢复后统一处理；祝福与天赋按 D-20261030-13 另行设计。

## 已确认的B3接入

破坏光线、终极冲击、疯狂植物、加农水炮、爆炸烈焰至少使一个目标实际损失HP时，使用者在招式完整结算后进入休息。全体失手、无目标或全部伤害为零时不触发；目标损失HP后被复活种子救回仍算触发。

休息消耗下一次自身行动机会，期间移动、攻击、招式、道具、交互和换位均不执行；不额外扣PP。发动招式的当前机会不计入休息；下一机会即使同时被睡眠、冰冻等阻止也消耗休息。切换主控不能规避，敌人与伙伴相同。真正倒下、换层或远征结束时清除；复活种子在真正倒下分支之前救回时保留。上述生命周期是适配本作的代理推断，用户确认的是此适配方向，不代表原版所有组合已验证。

实施必须连同招式准入模板、状态类型、回合预检与正式行动、自动行动、事件和显示一起完成。休息状态与睡觉的打盹分开，不复用已有rest名称。命令合法性沿现行G4.2/G4.3在应有时点校验，不因新增状态撤销#211的倒下前校验；状态只阻止已接受动作。界面用“休息”标签，详细效果放悬停，不增加常驻解释句。

验收覆盖五招准入及学习表、实际扣血/全失手/全零、多目标部分有效、目标复活、发动者复活/真正倒下、主控切换、被干预伙伴、敌人AI、状态同时存在、换层与首领终局；每项核行动次数和PP，不只查状态字段。

## 已确认的B9接入与剩余取得入口

喜悦种子由能使用道具的存活同行使用，占其一次行动，推进全队共享局内经验。使用时令E为当前累计经验，L为按G6.3从E推得的有效等级，补上到L+1最低累计经验的差额；有效Lv100时拒绝，物品和行动不消耗。当前代码把击倒与委托经验立即加到prog.exp，等级在轮末更新，所以读取实际累计经验，不重复累加结算队列，也不使用尚未更新的等级字段。

例：经验3补到5；经验0连续使用两颗，先到5，再到11。种子后本轮新获得的击倒或委托经验照常累加，轮末可能因此超过一级。升级、学招、进化及后续选择全走G6.4流程；当前HP不增加，倒下者不复活、不学招、不进化，不改变永久探险队等级。

【dev推断】种子补的是精确阈值差额，不再经gainExp乘学者15%；之前及之后正常经验来源保留学者效果。否则会偏离已确认的阈值语义。实现中单独标明此来源，避免改动其他经验来源。

现行奖励表没有种子的取得概率或售价。按用户“平衡最后”的决定，这部分数值保持搁置；实施可先验证效果与背包入口，正常玩家取得路线必须补齐后才能记B9完整交付。不能把调试注入当正式取得方式，也不为此另问用户数值。

验收覆盖部分经验、同轮两颗、前后击倒/委托经验、学者、满级、状态阻止、行动前倒下的原有预检、当前HP不变、倒下同行、升级学招/进化/终局的队列顺序。实现时同步道具类型、说明、背包显示与相关版本规则。投掷使用不在本项内。

## 其他项目的缺口

| 项 | 需要的新规则 | 开工前需要解决的问题 |
| --- | --- | --- |
| B2 蓄力两回合 | 挖洞、日光束、飞翔、潜水等 | 蓄力期间的行动、受击和中断，以及自动选招 |
| B4 投掷 | 新行动“投掷”，铁刺、碎石等投掷物 | 投掷射程、目标、伤害、消耗和界面 |
| B5 多段 | 二连踢、种子机关枪等 | 先取得原版探险队段数；确定每段是否单独判附加效果、吸取与反击 |
| B6 固定伤害 | 地球上投、黑夜魔影 | 核实原版公式，确定本作小 HP 尺度下的换算及难度倍率 |
| B7 地震 | earthquake | 缺原始范围与目标数据，继续核实房间/走廊、误伤与自动选招，协调 G4.6 |

## 暂不准入的范围

- 天气、陷阱、场地、饱腹度、持有物、IQ，以及依赖这些系统的道具。
- 替身、挺住、着迷、挑衅、再来一次等各自需要独立规则的变化招式。
- 威力由体重、HP 比例等回调决定的招式，以及缺少官方迷宫资料的新世代招式。
- 一击必杀、换人，以及现行导入规则排除且未列入待定项目的机制。
- 黄金种子（等级 ＋5）。蛋招式和招式教学属于 v0.2 的后续范围。

具体准入与排除清单由锁定数据快照的导入器生成，见[图鉴批量导入规格](../../05-制作流程/图鉴批量导入规格.md)和[数据快照登记](../../05-制作流程/数据快照登记.md)。各后续项目的验收随定稿规格与 issue 一同确定。
