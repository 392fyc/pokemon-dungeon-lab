# 三人队当场替换与营地待机 v0.6

状态：用户方向已记录，相关细则待设计。第一版仍以三人队为基准，沿[首版范围 v0.5](../2026-10-25-v0.5/审核入口.md)继续。

## 用户确定的方向

用户原话：“三人参照救援队设计，可以当场替换成员，下场的回到营地待机。”

三人队允许当场替换，换下的伙伴回营地待机，保留其伙伴实例与个人培养。它离开当前在场队伍后，不参与之后场内全灭的走失判定。

## 当前满员招募怎样衔接

原队伍是 A、B、C，实际击败合格非 Boss 并触发 N 的邀请后，可以接受 N、选择 C 回营地，队伍变成 A、B、N，仍为三人。C 在营地保留自己的已学招式与培养，不属于走失救援订单。

邀请与接受继续分开，不保证每次击败都会出现邀请。换人不要求先遇到稀有交换机；也不把队员的离场解释为放弃该实例。用户未指定仅限本局新人，当前不能自行加上该限制。

本节落实当前满员招募问题，不据此确定“没有招募机会时，可随时从营地远程调入任意成员”的额外规则。

## 与已有结算框架的关系

- 之后全灭只处理仍在场的普通伙伴；已回营地者保留在营地。
- 按现有有效探险候选，原有伙伴空手回营地本身不是新跨局成果；本局新伙伴后来被替换回营地，则是实际保留下来的新实例，参与最终成果判定。
- 替换本身不结束探险、不单独发工资或推进救援次数。仍由整局结束时根据目标和实际新成果最多结算一次。
- 入队资源沿现有候选继续研究，替换不自动恢复其余在场成员；个人培养不复制到新人。

这些是新方向与既有状态归属的衔接，不批准具体生命、PP、收入、费用或等待次数。

## 交换机与仍待设计的部分

稀有交换机继续按已有框架研究：在没有招募机会时主动撤回伙伴，以及附带少量物资。它不再承担唯一安全送回成员的作用，具体价值与保留方式应按新替换规则重新评估；本次没有自动取消装置或新增使用费用。

尚未明确：替换是否消耗行动、倒下成员能否被替出、随成员回营地的携物与物资处理、回营后的整备时点，以及是否支持从营地换入当前探险。不要把这些问题以旧候选限制代填。
