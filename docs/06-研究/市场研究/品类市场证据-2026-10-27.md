# 品类市场证据与样本

本报告围绕用户参考项目附近的玩法比较需求与竞争，包含 25 个商业样本。它不是全球游戏品类前五名榜单。当前能确认各细分有受众，但样本选择、评价语言、发行年龄、价格与商业模式不一致，不能由表中评价量计算品类市场份额或成功率。宏观市场背景与当前项目目标见[研究汇总](研究汇总-2026-10-27.md)。

研究由 pokemon-dungeon-lab 云端完成，主会话整合当前有效结论。首批取数 2026-10-27 02:24–02:27，自走棋补充 02:30–02:32，均为 UTC+9。搜索服务可能返回缓存页面，取数时间不是后台刷新时间。主会话另核对了 Balatro 发行商公告、任天堂 PDF、年度市场分析的方法，以及 The Last Flame 与 Caves of Qud 商店页。

## 一、使用限制

- 这是目的性案例选样，不是随机样本或完整年度发行队列。较弱样本不等于亏损项目，头部产品也不证明普通新作容易成功。
- Steam 付费、免费运营与免费浏览器同人分开。官方 IP、价格、渠道与玩法贡献无法从这些数据拆分。
- 已尝试通过云端网页工具读取官方全语言评价接口，但未取得可用结果。保留 E/A 原始口径，不计算跨类别总和、均值、中位数或排名；失败不代表 Steam 接口本身失效。
- 本轮没有可靠中国、日本细分或移动市场比较。Pokémon Royale 的实时塔战和 Tazos 的弹射战术缺少商业对照样本，不能据此标为需求低。
- 现成自走棋 mod 的价值需要结合[制作管线研究](../REA辅助研究/参考项目—制作与发布管线—2026-10-27.md)判断，不由这组市场小样本决定其优先或靠后。

## 二、分类与指标口径

按玩家实际做什么分类，避免把 Steam 标签当成互斥品类。

| 类别 | 本轮定义 | 交叉及排除 |
|---|---|---|
| 幸存者／弹幕动作肉鸽 | 实时移动避险，持续清理大量敌人，局内随机构筑 | 自动攻击不等于自走棋；也不是所有弹幕射击游戏 |
| 肉鸽自走棋 | 招募、组合、装备或布阵，战斗主要自动执行，按一局推进 | 与挂机、卡牌有交叉；TFT 式多人竞技和单人闯关应分开 |
| 卡牌构筑肉鸽 | 局内改变牌组或组合，通过出牌解决遭遇或分数目标 | Balatro 属于组合计分分支，不是传统敌我战斗 |
| 格子回合地牢／传统 roguelike | 行动推动敌人和世界回合，探索格子地图，随机性与失败成本重要 | 单角色传统 roguelike、宠物系统、救援队式同行探索不是同一种产品 |
| 挂机／增量／收集 | 自动或离线积累，配置与长期成长是主要循环 | 不一定收集生物，也不一定肉鸽；免费运营与买断制不可混算 |

**指标定义：**

- 评价数：页面显示的用户评价条数，不是销量或独立玩家数。
- 好评率：该页面所示评价集合中的好评比例。
- 下表 `E` 表示明确显示 **English Reviews**；`A` 表示显示 **All Reviews**。购买类型过滤未统一核实；不能由 A 推定包含所有购买类型，二者也不能直接混排为全球热度排名。
- 价格为读取页面返回的本体购买价；不同页面返回不同币种，保留原币，不换算、不推导全球统一价格。`$` 页面未统一核实地区。
- 日期为 Steam 页面发售日；有抢先体验则另列 EA 起点。评价可能从 EA 累积，不能把正式版日期当成累计时间起点。
- 样本全部至少核实 Steam/Windows 商店记录；没有逐一穷尽主机、移动端等平台。

## 三、商业样本事实表

选样采用**目的性分层**：每类保留可核实的高关注样本、较小规模样本和口碑或关注相对较弱样本，优先接近独立团队的作品。这里的“一般／较弱”只描述样本内评价规模或口碑，**不是利润判断，也不代表品类中位数**。

各行游戏名链接即一手商店来源。商店页没有固定报告发布日期，首批 22 例均在 2026-10-27 02:24–02:27（UTC+9）读取。

## 六、需求证据与缺口

以下分层不是品类高低排序。

| 方向 | 已有证据能支持什么 | 尚不能支持什么 |
|---|---|---|
| 幸存者 | 多款独立买断作品存在明确付费受众 | 比其他类总体更热门；新项目成功率更高 |
| 卡牌构筑肉鸽 | 多款商业样本及官方销量披露证明需求存在 | 由头部数量推出市场中位表现或本项目优先级 |
| 自走棋 | 单人、异步、多人及背包构筑均有需求证据 | 把所有细分合并；从单人小样本判断整体较弱 |
| 传统回合地牢 | 非宝可梦作品也有付费受众 | 直接推断救援队式同行探索的独立市场规模 |
| 救援队式探索 | 官方产品有购买市场 | 非怀旧比例、玩法因果、小团队可复制收益 |
| 挂机／收集 | 挂机买断和免费产品均有受众 | 将增量需求直接等同于生物收集需求或付费意愿 |
| 实时塔战、弹射战术 | 当前仅有参考方向 | 需求低或不值得研究 |

任天堂披露的救援队 DX 销售单位证明该官方产品有购买市场，未披露购买者是否玩过旧作或是否出于怀旧。IP、重制、渠道、玩法各自贡献和小团队可复制性均未知。不能凭销量否定怀旧解释，也不能凭怀旧偏好否定已有购买市场。

用户已明确沿救援队／肉鸽地牢继续，本表仅作市场背景，不重新排列已排除的品类。当前研究重点由创作目标、已核实证据与个人制作负担决定，不以既有文档投入代替体验依据。
