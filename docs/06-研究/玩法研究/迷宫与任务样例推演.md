# 迷宫与任务样例推演

当前规则以[核心玩法与首版范围](核心玩法与首版范围.md)为准。下面三图保留为早期内容与经济样例，不是现行首片段规格。首版地图当前可返回G，单向推进只作对照；旧样例的概率和继续收益未按中途返回重估，不能直接证明新风险。现行比较见[返回研究](../../90-archive/试开发/可返回出口的探险对照.md)及[服务点取舍](../../90-archive/试开发/招募奖励与服务点取舍.md)；层数、段数、名单和参数均不冻结。

状态：用户允许沿共享前段、分段撤离与自愿深入的方向继续研究，并提出局内商店与伙伴交换机。本文把这些方向组合成三组普通定向迷宫的纸面路线，**不是已制作地图、最终名单或正式平衡值**。交换机按用户最新澄清作为低概率保伙伴事件，以下装置选择只在本次确实遇到时成立；无尽模式另见[分区与守关](无尽迷宫分区与守关规则.md)。

阅读顺序：[基础勘探与单局节奏](基础勘探任务与单局节奏.md) → 本文 → [商店与伙伴交换机](迷宫商店与伙伴交换机.md) → [费用与等待推演](救援费用与等待次数推演.md)。共同结算以[有效探险与基础收入](有效探险与基础收入.md)为准。

## 共用假设与玩家应知道的事情

- 一至三段是本组样例的预算；各段末尾提供整队正常出口，基础目标给报酬资格而非开门条件。未达标退出没有基础工资，是否有效看实际新成果。首版当前候选允许沿原路返回上一出口，单向推进仅作对照。段数不额外增加基础报酬或L/X计数。
- 以下可选局部目标只给列明的物品、奖励选择或本局情报，不再发第二笔基础工资、不额外推进 L/X。实物奖励先进入普通背包，只有按保护、交换机或整队撤离规则处理后才安全；同一目标与物品只取得一次。若基础目标未完成，但可选奖励最终作为本局新增跨局成果保留，整局仍按方案 B 最多计一次有效探险；没有基础工资。
- 基础目标在最后必要交互完成时取得一次报酬资格，整局结束才入基地账户。之后全灭仍发；新伙伴、袋外战利品继续各自承担风险。
- 最低恢复配置只用初始二人、无需门票或必购补给、必要路线无强制战斗。下列溪谷首段提供这个配置；普通任务的遭遇不能冒充零资产保障。
- 三张路线标注的是交换机可能出现的安全节点；低概率生成，未出现时仍照常探索和撤离。实际发现或侦察到后才给位置提示，不按每张图、人数或区域保证，普通出口永远不依赖它。
- 交换机在一个可安全选择的出口前庭，具体试算为每局一次、撤回一名仍能行动的成员及最多两份物资，剩下至少一名可行动成员。当前局不能召回，也不能从基地调入替补；后续须再次击败合格敌人并真实触发邀请才可补位，不保证填满或匹配原作用。具体次数、载量等仍为代理候选。
- 首版队伍按三人范围研究，以下招募例子使用两名出发后实际邀请到第三名；这是纸面局面，不代表已确定默认出发人数。见[队伍人数](队伍人数与满员招募.md)。角色动作、招式适配和首批名单尚未确定。提到乌波、蘑蘑菇、小磁怪等不承诺必遇或必招募，非 Boss 邀请仍按用户提出的概率机制。
- 分钟数是内容预算，含阅读、思考与动画，不是最低游玩时间或倒计时。所有路线、出口可达和初始队可完成性仍需要以后验证。

样例账本暂用普通游戏货币：最低净基础报酬 R = 100，三种任务单只救援报价 C 分别试 40、60、80，付款后统一试 X = 1，未付款期限试 L = 4。这是用于比较的低负担起点，不是基于真实掉落率得出的费率。各迷宫真实总产出、耗材和失败率未测，不能仅凭这组递增报价证明高阶经济已经成立。

## 样例一：苔溪浅谷——选生态，保住新伙伴，或把队伍继续带深

**本局任务：**记录一处支流迹象，再在汇流处确认对应生态方向。出生时即可看到两条路线的用途，不要求指定水系或草系队员。

路线关系：入口 → 林荫支路或溪边支路 → 汇流观察点与第一出口 → 浅滩或苗圃 → 第二出口（可能出现稀有交换机）→ 泉眼环廊 → 第三出口。

| 段落 | 基础目标或探索内容 | 当前值得作的选择 | 收获与结束方式 |
| --- | --- | --- | --- |
| 首段：支流调查 | 林荫路较短，确认植被与补给线索；溪边路略长，能观察水边生态，普通配置旁支有可选遭遇。两路汇合，确认记录即完成基础目标 | 想赶快恢复队伍可走短路；想补水边伙伴可走溪边。观察结果预告第二段的生态分布，不只是点亮图标 | 取得 100 的报酬资格。第一出口就在汇流处，可整队撤离；最低配置目标 3–5 分钟，带旁支的普通配置 5–8 分钟 |
| 第二段：浅滩与苗圃 | 浅滩偏乌波等水边生态；苗圃偏蘑蘑菇等林下生态。只需选择一条通路到出口，不必两边清空 | 为想要的队伍作用选择遭遇；可以绕开额外战斗直接收尾。招募不保证，路线价值还包括补给和地形用途 | 正常探索可能取得伙伴、消耗品和一件用途明确的招式机；到第二出口可撤离，若实际出现稀有装置，也可送回一名成员再深入。普通两段目标 12–20 分钟 |
| 第三段：泉眼环廊 | 两个主要遭遇区：绕障碍的近路与空间较大的外环；正常出口不锁在可选强敌后面 | 剩下的队伍是否仍有足够的控制、射程或补给；选择更适合现有阵容的路线 | 提供一次偏直线攻击或范围支援的招式奖励选择，以及新的生态遭遇；不是恢复伙伴的必需材料。三段目标 20–30 分钟 |

### 溪谷每段的完成事件与出口关系

| 段落目标 | 何时算完成、得到什么 | 跳过或拿到东西后怎样出去 |
| --- | --- | --- |
| 首段基础勘探 | 已记录任一支流迹象，再确认汇流标记；最后交互取得一次基础报酬资格 | 第一出口在汇流标记旁，未记录也可使用，但无基础工资 |
| 第二段可选：取得一份生态补给 | 浅滩和苗圃各有标明的补给支室；选择一处，处理该室已有普通遭遇后打开补给箱，取得一次恢复物品或普通交易物选择。招募成功不是目标条件 | 两条主通路都绕过补给支室通向第二出口；不取箱也可离开，取完沿短连接路回主通路，不必清另一生态区 |
| 第三段可选：泉眼招式箱 | 箱子位于环廊旁的小平台，普通遭遇和障碍构成接近路线；抵达开箱后从直线攻击、范围支援两类候选奖励中选一件，登记取得 | 环廊本身直通第三出口，平台是支路；可以不拿箱，或拿完经平台连接口抵达出口，不要求打可选强敌 |

普通配置可在第一出口前庭放一间有限库存商店：例如恢复物品或投掷用品，用已获得的局内钱购买。最低配置没有购买要求；商店不把未结算的 100 直接当余额。

**第二出口确实遇到稀有装置时的局面：**初始主控、一名常用支援伙伴和刚招募的乌波同行，包里有六份普通物资，其中一张招式机很想保住。

- 整队撤离：全部合法带回，推进一次救援；这局已经完整。
- 乌波携招式机与一份物资先行撤回：先保住新伙伴，剩余两人继续；如果乌波当前战力很低，代价可能较小，不能声称这一选择必然很纠结。
- 常用支援伙伴先行撤回：保住培养投入并带货，但第三段失去其支援作用；另一种合理取舍。
- 不用装置继续：维持当前阵容，承担随行普通伙伴和未保护物资的风险。

如果保护袋与两份运输恰好覆盖所有在意的物品，那么本次继续的物资风险可能很低，这是需要记录的实际结果。不要为了制造损失临时增加运输税；先检查物资组合、装置位置与伙伴作用是否仍让选择成立。

**变化而非换皮：**下一次溪边可提示补给更多、林下可提示特定队伍作用的招募机会，让路线价值随本局需求改变；不反复强制“先找两个点，再回入口”。尚未确定的物种只替换生态内容，不改变基本结算规则。

## 样例二：回声矿道——钱用来买下一段的胜算，还是留给救援

**本局任务：**标定一条可通行的运矿路线。入口提供两种明确地形：短直廊暴露于直线攻击，弯曲支撑室有遮挡但路程稍长；抵达出口处的路线终端即完成记录。普通任务可有公开的常规战斗。

路线关系：入口 → 直廊或支撑室 → 路线终端、商店与第一出口 → 开阔矿室或遮挡矿道 → 第二出口（可能出现稀有交换机）→ 深部作业区 → 第三出口。

| 段落 | 内容 | 当前值得作的选择 | 收获与约束 |
| --- | --- | --- | --- |
| 首段：通路标定 | 选短直线或较长遮挡路线，普通敌人组合与路线相配 | 当前队伍能否处理远程压制；是否愿意多走一段以减少消耗 | 完成目标取得基础报酬资格。商店、出口在同一前庭；直接撤离不另付钱 |
| 第二段：采集与招募 | 开阔矿室偏多名普通敌人的位置处理；遮挡矿道偏少量较强敌人的逐个处理。小磁怪、小拳石仅作候选生态举例 | 追求接触更多招募对象，还是集中寻找某类物资；是否值得消耗有限 PP | 有针对性的招式类别、交易物和招募机会。两路都通往第二出口，若这里生成稀有交换机，可选择保住一名伙伴；没有免费恢复 |
| 第三段：深部作业区 | 使用同类墙体、转角与射程组合，给已形成的队伍一个更难的空间局面 | 若已用稀有装置送走一人，原先依赖的配合是否还在；购买的补给是否足够 | 追加可带回物资与用途奖励。可选强敌守较高价值支路，不守正常出口，不要求完成全图战斗 |

### 矿道每段的完成事件与出口关系

| 段落目标 | 何时算完成、得到什么 | 跳过或拿到东西后怎样出去 |
| --- | --- | --- |
| 首段通路标定 | 从任一已公布路线抵达终端并确认路线记录，取得一次基础报酬资格 | 终端和商店共用出口前庭；不买商品、不确认记录也能撤离，未达标无基础工资 |
| 第二段可选：矿样回收 | 两条路各有一处可见矿样箱，任选一处到达并取出矿样即完成；矿样作为普通交易物入包，同行角色与随机掉落都不是条件。两处共享一次目标奖励，不凭反复互动再取 | 主路从箱所在侧室旁通过并汇合到第二出口；箱中物品不充当出口钥匙，玩家可跳过或取一份就走 |
| 第三段可选：旧测绘匣 | 支路里一组固定生成的普通敌人守着测绘匣；击败该组后开匣，得到一次偏远程用途的招式机或交易物选择，目标随选择完成 | 深部主路直接通第三出口；不进守匣支路也能撤离。已接近匣子后仍可返回本段主路，不要求清全图或击败 Boss |

普通首段仍以 5–8 分钟、两段 12–20 分钟、三段 20–30 分钟作预算。商店选择与整理也计入这些时间，不能把它们额外塞进表外。

**第一出口的资金局面：**基地可用余额 0，三只旧伙伴各需 60，均剩最后一次有效探险；当前基础报酬资格 100，局内钱袋 80，暂不计其他可卖物资。

- 直接撤离：本次可入账 180，最后付款窗口能同时保护三只伙伴；付款后各等下一次有效探险。
- 花 50 买 PP 补给再继续：钱袋剩 30，已取得的总现金能力变成 130；还需新获得并带回至少 50，才能全付。
- 买补给后全灭：本例假定普通钱袋丢失，只可靠已完成目标的 100；只能付一只的 60，不能承诺其他两只会自动获救。
- 如果先在第二出口将可出售的物品送回，保住的实际出售所得可以改善上述结果，但运输不提前支付旧订单，也不延长最后期限。

买补给可以提高活着到下一出口的机会，是否值得需要实际战斗与掉落数据；上述数字只显示资金取舍，不能据此捏造增加了多少胜率。商店界面应提示当前购买后的现金与已知救援缺口，不阻止玩家选择。

**变化点：**同样的矿道模块用不同遮挡、敌人位置与商品类别，改变“省钱回去”还是“花钱继续”的理由；不靠每次加长矿井或涨血量制造差异。

## 样例三：风蚀遗迹——先撤回珍贵队员，换一个不同的后半局

**本局任务：**三处有明确线索的观察室任选两处记录。三个房间围绕出口前庭连接，每处有短通路到前庭；最后记录完成即达标，退出无需回起点或重新穿过整条已清路线。

候选观察室分别提供：下一段遮挡路线提示、飞行生态提示、招式奖励类别提示。少走的一室可保留为额外探索；提示的用途是帮助选择下一段，不要求另做独立解谜小游戏。

路线关系：入口 → 选择两处观察室 → 第一出口（可能出现稀有交换机）→ 遮挡回廊或开阔高台（商店在已标明的支路）→ 第二出口 → 核心遗迹与可选守卫支路 → 第三出口。

| 段落 | 内容 | 当前值得作的选择 | 收获与结束方式 |
| --- | --- | --- | --- |
| 首段：遗迹观察 | 三选二；两处线索足够完成，第三处不是领奖门槛 | 优先知道敌情、伙伴生态还是招式方向；是否带着首段收获退出 | 报酬资格 100。若第一出口生成稀有交换机，可在后续主要风险之前保护珍贵成员 |
| 第二段：回廊与高台 | 遮挡回廊较长、适合分开处理敌人；高台较短、射程交错。商店位置与类别在进入前提示 | 撤回主力后，换用原先不常用的剩余成员或新伙伴；购物提升后半程能力，或保留现金 | 当段提供足够明确的招募与物资方向，不能只有“未来会更好”。不保证招到正好替代离队主力的角色 |
| 第三段：核心与守卫支路 | 正常主路有出口和基础探索收益；可选 Boss 支路额外提供可辨认的收藏或招式选择 | 是否还具备打 Boss 的队伍条件；也可以走主路直接带出，不需要为出口打 Boss | Boss 不招募；普通敌人仍按同一招募规则。深层奖励不作为付最普通救援费的必需品 |

### 遗迹每段的完成事件与出口关系

| 段落目标 | 何时算完成、得到什么 | 跳过或拿到东西后怎样出去 |
| --- | --- | --- |
| 首段三选二观察 | 记录任意两个不同房间的线索即取得基础报酬资格；重复同一房间不增加进度 | 每个房间都有短通路到共同出口前庭；可少做或不做就离开，无基础工资，成果计数另判 |
| 第二段可选：解读壁画 | 遮挡回廊一处有明确标记的侧室保留完整壁画，抵达后一次阅读完成，揭示第三段可选守卫的两种主要攻击提示和奖励类别；这是本局情报，不自动作为永久成长 | 回廊主路和高台路均通第二出口；壁画不是开门机关。高台路线更短但跳过这份情报，可直接收尾 |
| 第三段可选：守卫挑战 | 玩家主动进入支路挑战 Boss，胜利后打开后方奖励匣并选一件收藏物或招式奖励；Boss 不招募，实物仍需正常保护或带出 | 核心主路的普通物资与第三出口均在守卫支路之外，不挑战也有本段探索收获；战斗内能否脱离须随战斗规则细化，不承诺进战后随时无代价退出 |

**第一出口确实遇到稀有装置时的局面：**一名培养较多的支援伙伴已接近耗尽可用招式，队伍另有两名能够行动的成员，其中包含初始角色。未付费伙伴期限尚有余量。

- 保住该支援伙伴并带两份重要物资：剩余两人能继续尝试新的组合，避免将珍贵伙伴带入全灭判定；这可能是合理且明显的选择，不要求每次都五五开。
- 留下支援伙伴：其剩余少数关键招式可能正好适合高台，保留后半局的一个战术方案；需要根据实际状态选择。
- 整队退出：如果剩余阵容无法应对已预告内容，应当正常收尾，不把交换机变成“送人后必须继续”的强迫流程。

本例的候选生成节点较早，重点是保住培养伙伴，附带货物通常还不多。溪谷与矿道使用较后的候选节点作位置对照。撤回后可能始终没有邀请，即使补到人数也不保证恢复原来的支援作用，见[人数与补位](队伍人数与满员招募.md)。

## 三组样例到底比较什么

| 比较轴 | 苔溪浅谷 | 回声矿道 | 风蚀遗迹 |
| --- | --- | --- | --- |
| 基础目标的选择 | 路线与生态信息 | 地形风险与通路选择 | 三处观察中选对本队有用的两处 |
| 第一段已经值得结束的内容 | 基础收入、浅层物资和可选招募 | 一次完整战术选择与现金筹措 | 获得情报与当前可保住的收获 |
| 罕见装置出现时的用途 | 保住本局新招募者，可附带关键物品 | 保住状态不佳的重要伙伴，重新评估后段战术 | 保住培养伙伴，让剩余队伍自行判断是否继续 |
| 商店的主要取舍 | 低额补给与保留收入 | 买胜算与支付临期救援的直接竞争 | 按剩余队伍补缺，不假设被送走者还在 |
| 深入理由 | 更有针对性的生态与招式用途 | 空间变化与可带回的额外价值 | 组合尝试、奖励选择和可选 Boss |
| 最需警惕 | 观察只是重复点击，或把装置误当必有 | 不花钱就无法活着退出，或购物意外耗光救援钱 | 缺关键角色被绑在长局内，或错误承诺后续招募必能补位 |

三种主题只是比较样例。以后进入实现阶段，先选一张代表地图串起任务、出口、装置和结算；不因本文有三个名字就同时要求制作三套完整美术、敌人行为和系统。

## 逐局恢复怎样自然发生

使用中档报价 C = 60、X = 1、L = 4：

1. 一次已完成基础目标的失败带来三名普通伙伴走失；该局仍入账 100。基地原余额为 0，先付一只 60，余 40。新订单不倒算刚结束的失败局。
2. 下一次选择本来就想去的溪谷路线：初始二人能出发，可探索目标生态；完成目标即使后来失败也再入账 100。旧订单返回，用现有 140 付另外两只共 120，余 20。
3. 再选择矿道、遗迹或仍想玩的短溪谷完成一次有效探险，两只已付款者同时返回。期间没有专用救援关卡，也没有给每只伙伴分别刷一轮等待。

这说明在给定假设下，两次后续探险可以完成三人的恢复；若第一次失败未完成目标且没有可卖成果，起始没有那 100，则见[零余额对照表](救援费用与等待次数推演.md)，需要三次后续短局才全部回归。不能把已赚的失败报酬漏算，也不能把新招募当作必得替代品。

即便只需两次，玩家若只想使用正在等待的伙伴，仍可能觉得在打工。纸面方案降低了专用负担，没有证明玩家会喜欢这两次冒险。

## 后续如何判断这几张图是否值得保留

先用纸面路线核对目标与出口可达、每段的两种选择各有什么目的、店和装置如何改变下一段；不把全图清完当成功标准。以后原型分别记录：

- 玩家本来就想探索的内容，与纯为筹钱或等伙伴而开的局；
- 每次出口的继续/撤离原因，是否因目标已达成而满意结束；
- 实际碰到装置后的伙伴作用变化，后续完成多少场合格战斗、是否出现邀请，以及招到的成员是否适合当前队伍；
- 保护袋、交换机与普通背包分别保存多少**玩家在意的价值**，不只数物品格子；
- 从付款到回归的游玩与基地整理时间，以及临期伙伴是否有清晰可行的付款路径。

没有预设“深入比例必须高”。装置出现概率低是用户明确方向，遇到之后是否使用则由保护伙伴和继续探索的取舍决定。如果某个选择总是明显更好，先检查内容和代价；如果玩家有明确目标而主动早退，不因此判失败。
