# Pokémon Arena 2D 项目概况

研究对象为 Big Kid Nation 的 Pokémon Arena 2D。它采用像素角色和实时竞技场战斗，官网计划在 2026 年 12 月开放公开 Beta。截至 2026 年 10 月 25 日，官网仍明确标示完整游戏未发布。[官网](https://www.bigkidnation.com/)

## 公开展示的方向

官方预告展示宝可梦切换、招式攻击、水域与不同场地。10 月中旬的水场地专题突出场地变化与战斗演出；这是预告展示，尚不能据此验证公开版本的操作手感或规则完整性。[官方水场地专题](https://www.youtube.com/watch?v=fOLlRkttB6M)

官网目前列出的 Kanto adventure 和投票页的小战斗属于等待期间提供的其他内容，不能当作完整竞技场作品已经上线的证据。[游戏目录](https://www.bigkidnation.com/games)

## 市场信号

官网自述上一支 Instagram 预告超过 250 万次播放。官方水场地视频在本次页面读取时显示 85777 次观看、2419 个赞；这反映预告触达，不能换算为实际游戏玩家或留存。官网没有公布固定的最终阵容总数。
