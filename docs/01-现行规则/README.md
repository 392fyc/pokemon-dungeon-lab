# 现行规则

本目录只放“现在怎样运作”的规则：游戏规则（核心页加六个主题页）和 KB 维护规则（项目目标与范围类决定在决策登记）。每条规则注明来自哪条决策（[决策登记](../03-决策/决策登记.md)）；理由与原话不在这里。规则变了，在同一个 PR 里改这里，并删除因此过时的文字。

**先读：**

- [游戏规则](游戏规则.md)：核心页，当前构建里游戏实际怎样运作的概览、各节摘要和“改哪里要读哪页”。门禁必读它；规则正文在下面六个主题页里，要改或要回答哪部分，就全文读对应主题页，拿不准读全部。
- [KB 维护规则](KB维护规则.md)：本库怎样读、怎样改。
