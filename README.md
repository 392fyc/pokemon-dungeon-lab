# 宝可梦地牢探索（私有试玩构建）

二维随机迷宫、三人小队、可撤离带出的宝可梦救援队式地牢游戏，网页版，Phaser 4.2.1＋TypeScript，Vite 构建。2026-10-31 完成 7.6 EA（可试玩早期版本）验收：7 条通过条件都有制作者实测证据，玩家体验尚未经独立体验者验证；结论见[进度](docs/02-进度/进度.md)“7.6 EA 验收结论”。当前是私有构建：素材与数据只用于私有试玩，不公开发布。

## 运行私有试玩构建

**直接用构建产物（不需要安装）。** 试玩包是 `vite build` 的输出目录（`index.html`、`assets/`），用任何静态网页服务器托管即可，放在网站根路径或子路径都行（构建用相对路径）。例如在产物目录里用 Python 自带的服务器：

```sh
python -m http.server 8080
```

没有 Python 时可以用 `npx serve .`，但它会从 npm 下载第三方包 `serve`，按本项目的约定先确认来源再运行。

然后在浏览器打开命令输出的本机地址。直接双击 `index.html` 不行：构建产物用模块脚本（`<script type="module">`），浏览器不允许从 `file://` 加载它，要经 http 打开。

**从源码构建。** 使用 Node 24.22.1 及随附 npm，在仓库根执行：

```sh
npm ci
```

```sh
npm run build
```

```sh
npm run preview
```

产物在 `.artifacts/trial/dist/`；`npm run dev` 启动带热更新的开发服务器。

**怎么玩。** 标题“新游戏”选主控与副手，进基地整备后出发；方向键移动，点相邻敌人普攻，按 K 或点招式按钮先选招再点目标，句点等待；“安排伙伴”可以编辑整轮草稿。走到出口可以请求撤离，把成果带回基地；全灭会丢失钱袋与招式机，没有保护的伙伴可能走失，在基地付救援费能找回。进度只保存在同一浏览器、同一网页来源；设置里可以导出、导入存档文件。规则细节见[游戏规则](docs/01-现行规则/游戏规则.md)。

**开发者入口。** 网址参数 `?dev=1` 与 `?fixture=` 打开开发者模式（固定场景、隔离存储），浏览器检查需要它；普通流程没有入口。公开发布前要处理。

```sh
npm run check
```

```sh
npm test
```

```sh
npm run test:acceptance
```

浏览器检查 `npm run test:browser` 需要先 `npm run preview`，并设置 `TRIAL_URL` 与 `PLAYWRIGHT_MODULE`（Playwright 与 Edge）。

## 项目方向

- 每局进入随机地牢探索，包含轻度撤离带出机制；伙伴、招式机和特殊物品可用于以后冒险，具体保留和损失规则待设计。
- 可以采用 Pokémon Showdown 数据库，首批阵容从某个时代中选取有限而多样的子集。
- 角色视觉参考 Big Kid Nation 的 Pokémon Arena 2D；研究 PokéBonk 的招式适配、融合及内容生产方法。
- 本片段采用行动推进回合、三人同行、固定队列与一次伙伴干预；数据时代、正式名单、融合和长期经济不在本次实现范围。
