# 8.9 后续招式与道具范围

## 1. 目标与边界

招式与道具继续以《不可思议的迷宫》探险队系列为主要依据，数值换算到本作尺度。现行规则见[游戏规则](../../01-现行规则/游戏规则.md)，决定见[决策登记](../../03-决策/决策登记.md)。

用户2026-11-14已确认交付的规则草案，B3休息与B9喜悦种子的效果已接入；其余项目继续补齐事实或接口。dev独立完成研究与当前规格，依据见 [#229](https://github.com/392fyc/pokemon-dungeon-lab/issues/229#issuecomment-6874384171) 和[探险队机制研究](../../06-研究/玩法研究/探险队招式与道具机制.md)。具体实施issue须给出文件分工、入口和验收例子。平衡工作由 #168 恢复后统一处理；祝福与天赋按 D-20261030-13 另行设计。

## 喜悦种子的剩余取得入口

B3休息的现行规则已收进 [G5.16](../../01-现行规则/规则-战斗与敌人.md#g5-战斗)。B9喜悦种子的共享经验效果、满级拒绝、学者处理和背包入口见 [G9.1](../../01-现行规则/规则-物品结算与存档.md#g9-物品服务点全灭与结算)，升级顺序见 G6.4。

现行奖励表没有种子的取得概率或售价。按用户“平衡最后”的决定，这部分数值保持搁置；正常玩家取得路线补齐后才能记B9完整交付。调试注入只用于验证，不能当正式取得方式。投掷使用不在B9本项内。

## 其他项目的缺口

| 项 | 需要的新规则 | 开工前需要解决的问题 |
| --- | --- | --- |
| B2 蓄力两回合 | 挖洞、日光束、飞翔、潜水等 | 蓄力期间的行动、受击和中断，以及自动选招 |
| B4 投掷 | 新行动“投掷”，铁刺、碎石等投掷物 | 投掷射程、目标、伤害、消耗和界面 |
| B5 多段 | 二连踢、种子机关枪等 | 先取得原版探险队段数；确定每段是否单独判附加效果、吸取与反击 |
| B6 固定伤害 | 地球上投、黑夜魔影 | 核实原版公式，确定本作小 HP 尺度下的换算及难度倍率 |
| B7 地震 | earthquake | 缺原始范围与目标数据，继续核实房间/走廊、误伤与自动选招，协调 G4.6 |

## 暂不准入的范围

- 天气、陷阱、场地、饱腹度、持有物、IQ，以及依赖这些系统的道具。
- 替身、挺住、着迷、挑衅、再来一次等各自需要独立规则的变化招式。
- 威力由体重、HP 比例等回调决定的招式，以及缺少官方迷宫资料的新世代招式。
- 一击必杀、换人，以及现行导入规则排除且未列入待定项目的机制。
- 黄金种子（等级 ＋5）。蛋招式和招式教学属于 v0.2 的后续范围。

具体准入与排除清单由锁定数据快照的导入器生成，见[图鉴批量导入规格](../../05-制作流程/图鉴批量导入规格.md)和[数据快照登记](../../05-制作流程/数据快照登记.md)。各后续项目的验收随定稿规格与 issue 一同确定。
