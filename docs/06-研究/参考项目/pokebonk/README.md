# PokéBonk 项目概况

PokéBonk 是 Charcher 制作的浏览器宝可梦生存类同人游戏。2026 年 10 月 25 日的官网观察记录宣传范围为关都 151 种宝可梦。[原站](https://pokebonk.com/)

## 研究版本与适用范围

本库最近完成专项分析的固定快照是 **0.8.47／构建 `mvnpa0xv`**：官网 HTML 于 2026-10-25 20:57:38、主模块于 20:58:28 捕获；存档研究于同日 21:44:53 再次确认构建和主模块摘要一致。以上时间均为 UTC+9，精确记录与适用范围见[资料来源](资料来源与验证范围.md)。这是固定研究对象，不代表今天官网的实时版本。

2026-10-27 01:58:54（UTC+9）的[八款项目入口核查](../跨项目/八款浏览器游戏参考与研究优先级.md)发现，官网 HTML 已引用 `main-RauCMJ6f-mvpdimhl.js`。本轮仅确认入口标识变化，新版本号和内部行为尚未核实；以下专项结果仍限定于各自原构建。

此前记录的 **Beta v0.8.39** 属于 2026-10-25 的较早界面观察；原记录没有留下精确到时分秒的捕获时间，更新面板所列 2026-10-24 是版本日期。该观察及旧专题引用的 `mvmo2acf` 模块保留为历史资料，不作为后续 `mvnpa0xv` 分析的定位依据。下面的玩法、数据、融合与更新专题按各自来源快照阅读，不能因索引更新就视为全部已按 0.8.47 重新验证。

后续固定构建的结果从[普通招式执行路径](../../REA辅助研究/PokéBonk—普通招式执行路径—mvnpa0xv.md)和[存档与恢复路径](../../REA辅助研究/PokéBonk—存档与恢复路径—mvnpa0xv.md)进入。需要研究新的线上构建时，先重新确认目标版本、模块与摘要。

## 玩法循环

原站宣传选择和解锁宝可梦、在三维场景中应对野生兽潮、进化并使用终极技能。更新说明还涉及升级选卡、招式强化、捕捉、道具、守护者、祭坛、区域传送门和结算。由这些说明可概括其循环为：选择出发配置，进入区域探索与战斗，通过升级和拾取形成当局配置，再推进区域或完成结算。

局外研究所、星尘与背包商店连接了多次冒险。2026 年 10 月 22 日的说明提到最多三套配置预设并可在开局切换；10 月 24 日的说明加入用星尘购买背包物品的菜单商店。现有证据支持出发前配置、局内成长和局外购买的关系，不能据此认定它具有撤离失败损失机制。[版本说明模块](https://pokebonk.com/assets/news-Dk7pMGb3-mvmo2acf.js)

## 研究价值

本项目最直接的技术参考是大量招式的玩法转换和融合系统。其公开资料也同时包含完整物种输入与有限的宣传阵容，适合研究如何控制首批内容范围。

官网所链 Discord 邀请接口在核查时显示约 1.33 万成员、约 4586 人在线。这是社区人数，不能当作游戏并发；尚未获得日活、留存或付费需求数据。[官方社区邀请预览](https://discord.com/api/v9/invites/X7KusQqx8X?with_counts=true&with_expiration=true)
