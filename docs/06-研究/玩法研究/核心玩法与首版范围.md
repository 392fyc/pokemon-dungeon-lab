# 核心玩法与个人首版范围

当前推荐的核心体验：**带用途不同的三人队进入迷宫，决定怎样接近威胁、让谁承担风险、把哪些招式次数留到后面；途中招募改变当前做法，回营培养改变下一次选择。**

这是沿[用户当前目标](../../90-archive/早期框架/创作目标与地牢研究重点.md)形成的连贯设计候选。三人上限、当场替换回营、行动推进回合等已定约束继续有效；控制与能力仍为候选。数量只作预算，不作为内容上限或验收门槛。PR #1、PR #2已复审并经用户批准合入研究基线，玩法建议仍待采纳；没有游戏实现或真人测试。精确执行规则统一读取[当前规则表](../../90-archive/试开发/当前规则表.md)，本页负责体验与完整首版预算，近期推进按[阶段路线图](../../90-archive/试开发/从研究到试开发的阶段路线图.md)。

## 1. 一次冒险怎样连接下一次

| 环节 | 玩家要作的选择 | 有意义的代价 |
| --- | --- | --- |
| 基地编队与配招 | 从名册选最多三名；查看本次任务的主要威胁与奖励方向 | 有保护可能少一种射程，有新人就少一个熟悉的培养组合 |
| 接任务 | 选基础档或已解锁的风险档 | 用相同地图主题配置不同威胁和收益，低风险任务保留恢复入口 |
| 探索选路 | 决定在哪接敌、是否取旁支、把哪些资源留到后面 | 比较 PP、生命与遭遇类型，避免只有“多走几步”的空绕路 |
| 战斗 | 平时操作主控，关键轮干预一名伙伴 | 每名角色执行一次行动，移动、攻击、施招、等待相互占用机会 |
| 真实招募 | 邀请出现才决定接受、拒绝或替换 | 回营保住旧实例，但当前队伍失去旧作用；新人的资源也属于真实收益 |
| 完成基础目标 | 从正常出口带回成果，或进入可选后段 | 已完成目标不要求继续冒险；深入不能预设一定招到补位者 |
| 回营或失败 | 看清保留、损失、走失与救援订单 | 终局最多计一次报酬和有效探险；未付费期限按有效探险而非现实时间推进 |
| 培养再出发 | 用一项成果学习招式，再重配或换队 | 增加一个处理问题的方法；学习归属同一伙伴实例，不复制给新人 |

初始二人恢复、自由编队、基础收入和付费等待回归沿用户既有框架处理。成长暂采用“共享本局等级＋个人永久招式库”作为唯一工作候选，永久个体等级保留资料对照，不同时制作两套。数值、走失率、费用与等待次数继续按已有方案研究，不当成本轮已选数值。

## 2. 伙伴首先提供三类特殊用途

> 2026-10-30 更新：用户决定招式的射程、目标和效果改为照官方探险队（方向 B，见[招式表现与官方探险队对照](招式表现与官方探险队对照.md)）。本节“保护、直线、推退”三类用途是此前的设计，将在阶段 7.7 被官方招式模型替换；保护队友改由官方本有的招式（如广域防守）承担。下文保留作为历史设计记录。

所有角色都有不耗 PP 的普通近身攻击。当前用耗 PP 的贴身强击作为输出对照，特殊用途先研究保护、直线打击、近身推退，合计五种招式行为作为预算样例；具体招式数量、名称、属性和原作适配另按名单与选择需求调整。

| 特殊用途 | 战斗里做什么 | 怎样改变探索 | 限制 |
| --- | --- | --- | --- |
| 邻位保护 | 给相邻另一成员抵减下一敌方阶段的首次伤害 | 愿意由脆弱成员接近目标，或选择需要承受一次射击的通路 | 耗 PP 和施招行动，不治疗、不叠加、不保护整队；无受击也随该阶段结束 |
| 直线打击 | 在射程内沿无遮挡直线处理敌人 | 更愿意选择开阔走廊，或从另一侧接敌 | 墙、伙伴和前方单位挡线；不会自动取得射击位置 |
| 近身推退 | 把相邻敌人推离一格，不附送伤害 | 分开接敌时间、让出窄口或创造撤退空间 | 后方必须为空地；推退不眩晕，敌人仍有自己的行动，可能仍能攻击另一成员 |

探索用途首先来自相同空间与资源规则，不额外制作砍树、游泳和专属开门系统。基础目标与普通出口不以某一物种或能力为钥匙；拥有能力改变成本、接近方式和可选收获。

四种功能配置用于安排差异，不是四个职业槽，也不是最终四个物种：守护（强击＋保护）、射手（强击＋直线）、牵制（强击＋推退）、调位（直线＋推退）。三人上限迫使队伍放弃至少一类组合；有限学习范围避免培养后人人同套最佳招式。

两项重点取舍是：双射程更容易先行集火，但窄口被贴近时缺少保护；保护与近战组合能承压和推退，却需要绕路或挨打接近射手。老伙伴的可靠配招与新伙伴的新用途也形成机会成本，不能只看当前生命高低。

## 3. 三类代表场景

1. **长廊与转角。** 长廊有定点射手，转角路线挡住射线但有弱近战。射手队花远攻 PP；保护队花保护 PP 与前排生命；没有二者仍可在转角逐个接敌。若某一条路无论何种状态都更好，应改敌人或奖励配置，而不是增加角色门槛。
2. **可放弃的侧室。** 两敌守额外奖励。推退争取分开接敌，保护支持前排承压，普通队可退回转角或放弃。进入格和交互各占行动；成果点若兼出口，可一次取得并请求撤离，仍承受完整轮，不能把推退当免费取物和免伤。
3. **完成目标后的新邀请。** 继续前真实出现新人，玩家决定保住哪名旧成员、失去哪种当前作用，或拒绝后撤离。入队位置、PP 与具体后段敌人一起比较；没有邀请也能结束本局或走普通路线。

具体坐标与动作对照见[伙伴选择的代表场景](伙伴选择的代表场景.md)。[完整小探险](一段完整探险的连续推演.md)当前采用紧凑目标和成果出口：基础退出6轮，留C花远攻取物10轮，N替C后由B承伤取物也为10轮，后者需一次付行动换位和一次主动切主控。没有邀请仍能完成，带活敌撤离不要求无收益清场。[探索节奏与操作简化](探索节奏与操作简化.md)分开地图、跟随和确认成本；[入场](伙伴跟随与倒下通路.md)与[招募账本](招募资源与伙伴取舍.md)继续说明细节。都是纸面模型，不证明最优策略、胜率或趣味性。

保留C也可让B承伤、10轮取物而不耗PP，完整对照已补入连续探险。B的承伤能力不是新人带来的优势；招募在此增加实例、保住离队成员并改变资源与配招。立即回营时可有明确奖励优势，继续探索时是否形成取舍须比较相同打法，邀请定位及交换机首版去留仍待裁决。

## 4. 控制采用一个主控加一次伙伴干预

当前操作体验仍是一名主控加关键轮的一次伙伴干预。普通单步直接执行，组合先建立伙伴草稿；固定队列使站位、先后和付行动换位有实际代价。默认伙伴只负责普攻与靠近，不代替玩家决定花PP或找射线。

精确规则集中在[当前规则表](../../90-archive/试开发/当前规则表.md)：R02—R05定义回合、输入、跟随和换位，R06—R08定义倒下、资源与入场，R09—R11定义交互、返回及保存。这里不再另列入场顺序、轮末次序或取整公式，避免多处分别改动。

无敌走廊返向优先切靠出口者为主控，不强制重排队形；正常撤离按名单，不等待所有成员贴身。若普通房间频繁要求同时指挥两名伙伴，先缩短无选择路段、调整入口与遭遇，再评估操作扩展。规则能复算不等于跟随顺畅或草稿模式易懂。

当前工作候选保留可返回G与旧层，不恢复资源或重置地图；单向仅作对照。新人半额是统一研究输入，其他比例只用于明确对照。出口方向和比例尚非用户最终决定，研究建议见[返程与招募的首片段方案](../../90-archive/试开发/返程与招募的首片段方案.md)。

## 5. 首个片段与完整首版必须分开

首个可玩片段只证明“选择能成立”：进入固定地图，处理分岔和遭遇，带回一项培养成果，再进入对照场景。为了隔离变量，可以人为固定邀请输入，但记录为测试安排，不能当自然招募结果。

完整首版要接通随机布局、自然邀请与拒绝、当场替换回营、正常结束与失败、二人恢复、救援订单、学习与再编队、明确结束目标，以及中断和重新进入。不能把片段有趣直接写成首版完成。

| 工作面 | 完整首版预算示例与已定边界 | 为什么这样估算 |
| --- | --- | --- |
| 队伍 | 三人同行，基地名册按实例管理 | 保留组队与替换选择，不引入第四人适配 |
| 行为 | 以五种招式行为估算，优先共用数据与表现 | 同一套行为服务角色、敌人和探索，不为每只角色开发独有系统 |
| 敌人决策 | 以三类估算：接近普攻、定点射击、预告后逼近 | 让站位和接敌时间有区别，避免先开发复杂战术 AI |
| 地图 | 以一个普通迷宫主题、两层、六类房间模板估算 | 用连通和遭遇组合产生变化，先核算素材与规则数量 |
| 委托与结尾 | 以两档配置复用该迷宫估算；完成较高档目标并回营有明确完成记录 | 支持等级解锁风险收益，同时给首版结束点，不靠无限游玩补内容 |
| 消耗与培养 | 以两种恢复消耗品、一种保护容器规则、三种招式机定义估算 | 先围绕 HP/PP 与一条个人招式培养，不新增材料合成树 |
| 界面 | 以基地、迷宫、结算三种主要界面估算；邀请和学习作为必要面板 | 菜单数量服务流程，避免独立建设和收藏子游戏 |
| 服务点 | 首片段建议后置交换机与商店；完整首版是否加入仍待采纳 | 保留无邀请保人及少量运货的独立用例，不成为替换前置 |
| 载体 | 网页开发验证优先，Windows 封装单独验证 | 复用已选技术路线，不把网页可达当安装包通过 |

数量只作预算，不是工期承诺或已选名单。一组估算例子是：**三代共九个御三家定义用于初始自选，加三个非御三家定义，总计十二种，复用四种功能配置与五种行为。** 主控选一、副手从剩余候选中选是这组预算的配套示例，尚未选定实际初始名册；实例名册不因此限十二只。同行最多三只是独立的已定规则。

三代与十二种不构成对“历代御三家自选”提案的裁决。具体世代与物种需结合素材覆盖、配招和差异判断，不在本轮假定全量素材可用。若按全部 `g` 代并加三个野外种估算，总数为 `3g+3`，相对三代预算多 `3(g−3)` 种；每种仍需动作、方向、锚点、配招、学习范围、敌方配置和界面接入。以每种四动作四方向为预算检查维度，十二种有 192 组覆盖检查，不是 192 帧绘图或工时估计。

### 一张迷宫的具体结构

这组地图预算示例中，第一层包含入口 S、分岔 F、基础目标兼出口 G、可选侧室 B；第二层包含入口 D、挑战 K、收获兼出口 E，共七个节点。六类房间模板按需要复用；七个节点、两层和六种模板都不是已冻结的首版限制。

```text
第一层：S — F — G（完成基础目标，可结束）
             └ B（额外奖励，原路返回 F）
第二层：G — D — K — E（可选后段与普通出口）
            可沿原路返回 G
```

生成先固定 S—F—G 的普通连通骨架，再填地形、敌人与支路。基础完成只需三个节点；邀请、掉落、特定伙伴和第二层不负责开启 G。低风险恢复档的必需路径不放强制承伤或强制战斗；高档任务在同一结构配置可预见遭遇。路径存在不承诺残血队伍安全通过；倒下不挡路后，仍要结合活单位占位、威胁和入场资格判断。

长廊和转角的差异来自射线、接敌位置和额外近战，而不只是长度。若绕路只有额外空移动、没有其他代价，它就是安全替代，不能声称两路已经平衡，也不为制造成本加入饥饿或疲劳。低风险恢复路线仍可能无聊，不能凭稳定收入就认定其体验成立。

## 6. 保存与失败是完整首版的一部分

[当前规则表R11](../../90-archive/试开发/当前规则表.md#r11-保存与恢复)集中定义完整处理点、保存期间可做什么、失败重试和恢复要求。[玩家操作](玩家操作与中断恢复.md)保留面向玩家的提示与恢复情境。新的算例必须沿用这些定义，不在另一份表里另造半轮恢复或重复发奖规则。

完整首版必须接通正常退出、失败结算、伙伴归属、救援事项和再次出发，终局只发放一次。首片段可以明确缩小测试范围，但不能把未制作的中途恢复或救援经济算作完成。[首片段方案](../../90-archive/试开发/返程与招募的首片段方案.md)把先验证什么与后续完整首版分开。

保存成功不要求点击确认；写入停顿、强退恢复与平台一致性仍需后续真实环境验证。发布研究继续只参考[八款游戏](../REA辅助研究/八款参考游戏—发布与维护经验—2026-10-27.md)，不为当前研究增加账号、云存档或在线结算服务。

## 7. 先删什么，必须警惕什么

缩减顺序：额外主题与角色、Boss 专属机制和进化网络 → 商店、重复任务与旁支数量 → 多步点位等便利命令。Z 晶、Mega、无尽、繁殖、个体值／努力值、饥饿、疲劳、熟练度和营地建设后置。

保留核心的条件是：有限伙伴确实改变做法；基础二人能完成恢复路线；招募不决定主路是否开放；退出、失败和再次出发可以连接。若这些仍做不完，缩小内容量或明确只交付片段，不将未完成结算称为完整首版。

| 失败情境 | 需要调整的地方 |
| --- | --- |
| 每个窄口都必须挨打，保护成为必带 | 增加真实遮挡与接敌选择；保护保留次数、行动和邻位限制 |
| 推退反复取消一切敌人行动 | 不附送伤害或眩晕；检查墙边、射手和其他相邻目标，不能总有安全落点 |
| 每轮都要给两名伙伴让路和找射线 | 先改入口侧向空间、遭遇组合与意图提示；不自动把三人全手动或聪明 AI 作为前提 |
| 重要深入路线总由同功能新人独自覆盖 | 接受短段补给收益；用已有敌人组合、位置与可用配招增加具体选择，不靠降低招募率或新增惩罚强迫留下旧人 |
| 培养后所有人配置一致 | 限制重复学习组合，减少重复角色，而不是只用微小数值差填名单 |

接入完整首版的失败经济前，需要选定费用与期限、名单和成长参数。[阶段路线图](../../90-archive/试开发/从研究到试开发的阶段路线图.md)中的单层试开发不启用完整救援经济，因此只需固定本次场景、失败结果、实例归属与恢复边界，不以完整费表阻挡核心验证。好不好玩、输入是否顺手、读档是否可靠须留给实际样例，不能靠纸面补成通过。
