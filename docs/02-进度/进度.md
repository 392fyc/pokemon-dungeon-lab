## 已知问题

- 平衡只用 tactical 一种机器人策略测过，真人击杀数不同，进化频率和全灭率会偏离。
- 首领层大量局“到达却没接触首领”就撤离（99 局中 38 局），首领战本身的体验数据少。
- 五局浏览器检查的路线规划读取完整状态（不是只按玩家可见信息），见 7.8 运行时自测记录。
- GitHub 上 #34、#38、#43 三个协调 issue 对应的工作已合并，issue 仍开着，待关闭。
- **写游戏规则时，对照代码发现的不一致**（2026-10-31，#85）。游戏规则已按代码现状写，下面各项待决定是改代码还是改规则：
  - 风速狗的可学清单里有守住、吼叫、帮助、太晶爆发四张招式机，招募来的风速狗能学这四招；7.8 规格却写“不进招式机可学池”（`src/core/base.ts:53`）。
  - 帮助在走廊里也会对 2 格内的队友使用；7.8 规格写的是“同房间有两名以上己方时”（`src/core/engine.ts:363`）。
  - 睡着的敌人只有真的掉血或被吹飞时才醒，攻击被挡成 0 伤害时不醒；规格写“被攻击就醒”（`src/core/engine.ts:538`）。
  - 倒下的成员不进化，规格没写这一点；游戏规则 G6.6 已按代码记录。
  - `src/core/engine.ts:23` 的注释仍写首领“不可招募”，与现行规则矛盾，只是注释没改。
