# 阶段7.6 EA 验收清单

本页把[阶段7计划](https://github.com/392fyc/pokemon-dungeon-lab/blob/d03ef5144f5671b3b8d5418b94353223742e911a/docs/02-%E8%BF%9B%E5%BA%A6/%E8%AE%A1%E5%88%92/%E9%98%B6%E6%AE%B57%E2%80%94%E5%8F%AF%E8%AF%95%E7%8E%A9EA%E8%AE%A1%E5%88%92.md)“EA 是什么、怎样算达到”的 7 条通过条件，逐条对到**现在已有的证据、还缺什么、由谁补、什么时候补**，让 7.6 验收时不必临时找证据。本页是 main lane 的工作候选；所有证据都是代理操作的制作者实测，**不是玩家证据**。

## 为什么现在先写

7.7 官方招式模型会改掉全部招式行为，7.7b 还会加团队保护招式。这两步之后，下面所有“已有证据”都要重跑一次。先把清单写好，7.7 和 7.7b 合并后就能照单重跑，最后一次性验收。

## 译名差异（2026-10-30 对照 52poke）

招式（左为 `names-zh.json` 现值，右为 52poke 现行译名）：airslash 空气斩→空气之刃；dragonbreath 龙之吐息→龙息；focuspunch 聚气拳→真气拳；foulplay 欺诈→移花接木；hyperfang 必杀门牙→终结门牙；inferno 炼狱→烈火深渊；leechlife 吸血→汲取；megapunch 百万吨拳击→百万吨重拳；psychicfangs 精神利牙→精神之牙；sandtomb 流沙地狱→流沙深渊；spark 电火花→电光。这些招式目前不在任何物种的可学清单里，以后进入游戏时再改。

道具：“PP补剂”非官方名；官方回复全部招式 PP 的道具为“ＰＰ多项小补剂”（52poke 页面名中 PP 为全角）。

## 7.6 的执行顺序

1. 7.7a 合并 → main 重跑长测、定首领数值（含是否给首领大范围攻击）→ 7.7b 实现与合并。
2. dev 补“全新存档连续 5 局”浏览器检查（第 2 条缺口），可与 7.7b 一起做。
3. main 做界面文字巡查与译名核对（第 4 条缺口），问题开 issue 分给 dev。
4. 最终构建上：dev 跑全部检查与浏览器检查；main 复跑长测、浏览器检查，重测体积与首屏时间，核对开发者入口。
5. main 写 7.6 验收报告：7 条逐条给证据链接；未验证的内容（玩家体验）如实标出；交付私有试玩包（构建产物与使用说明）。是否放到 NAS 由用户决定。

## 不在本清单内

- 玩家体验：没有独立体验者，任何结论都不能当作玩家证据。
- 公开发布、联系体验者：需要用户另行决定。
