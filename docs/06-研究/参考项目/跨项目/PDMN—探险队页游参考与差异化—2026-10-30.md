# PDMN：探险队式页游参考与差异化

用户于 2026-10-30 补充了一个参考对象：[PDMN](https://pdmn.fr/)（Pokémon Donjon Mystère Navigateur，法国同人团队制作，可在浏览器里玩的《宝可梦不可思议的迷宫》同人游戏）。它和本作同属“浏览器里的宝可梦随机迷宫”，是目前已知最接近本作的作品，所以本页单独比较：哪些地方我们已经和它重合，哪些地方我们本来就不同，以及差异化应放在哪里。

## 证据范围

本页事实来自 2026-10-30 在内置浏览器中读取的四个官方页面：[首页](https://pdmn.fr/)（含展开的常见问题）、[简体中文介绍](https://pdmn.fr/zh/)、[新手指南](https://pdmn.fr/guide)和[更新日志](https://pdmn.fr/nouveautes)的前几条。这些都是**维护方的自述**，没有实际进入游戏验证。队伍人数上限、敌人行动方式和难度曲线都没有观察；页面写的“约两百种”“三百多个招式动画”等数量，也只是宣传数字，未逐项核实。

## PDMN 自述的主要做法

| 方面 | 维护方的说法 |
| --- | --- |
| 形态 | 免费、无广告；浏览器直接玩，电脑与手机都支持，手机横屏触控；提供简体中文 |
| 结构 | 选主角和搭档（34 种初始宝可梦，可用性格测验），20 章原创剧情，4 幕，约 12—15 小时；通关后有深层区域和保留队伍的二周目 |
| 迷宫 | 每次进入重新生成；找楼梯一层层往下到底；一步一回合；有隐藏陷阱、天气、9 种状态、持有道具、怪物屋、金色楼梯小游戏、饱腹度（走路会饿，苹果补充） |
| 队伍 | 打倒野生宝可梦后它可能请求入队；同伴按“均衡、积极、谨慎、和平、原地”五种行为方针自动行动，可禁用指定招式；升级学招、进化可在迷宫中发生 |
| 基地 | 营地有银行（存进去的东西永不丢失）、商店、委托板（救援、护送、送货、悬赏通缉、自愿入队） |
| 失败 | 全队倒下时，背包和随身金钱留在迷宫里；银行里的东西不受影响 |
| 线上 | 账号与云存档；用邀请码两人联机进同一迷宫；玩家之间的交易所；几乎每天更新 |
| 素材 | 地形沿用原作图块，角色用 SpriteCollab（PMDCollab）社区精灵 |
| 难度 | 自称比原作更需要思考：“一味冲锋”的队伍常常提早回营 |

## 与本作已经重合的地方

先说清重合点，避免把共有的东西当成卖点：

- **类型和平台相同**：都是浏览器里的回合制随机迷宫，打倒野生宝可梦后招募，迷宫之间回基地。
- **失败代价的“钱”这一半几乎一样**：本作 7.2 的“账户与钱袋”（全灭时钱袋按概率损失，账户安全）和 PDMN 的“银行与随身金钱”是同一个思路。
- **“救援”本身不是差异**：PDMN 的委托板已经有救援、护送和悬赏，和原作一样。
- **角色素材来源相同**：本作私有构建的角色目前也取自 SpriteCollab，画面会和 PDMN 很像。

## 本作本来就不同的地方

下面每一条都是本作**已经定下或已经实现**的规则，不是新增系统；对照的是 PDMN 的自述。

1. **三人队由玩家直接安排，而不是设行为方针。** 本作每轮三人各执行一次行动，玩家操作主控，并可在关键轮直接干预一名伙伴（[核心玩法](https://github.com/392fyc/pokemon-dungeon-lab/blob/d03ef5144f5671b3b8d5418b94353223742e911a/docs/06-%E7%A0%94%E7%A9%B6/%E7%8E%A9%E6%B3%95%E7%A0%94%E7%A9%B6/%E6%A0%B8%E5%BF%83%E7%8E%A9%E6%B3%95%E4%B8%8E%E9%A6%96%E7%89%88%E8%8C%83%E5%9B%B4.md)第 4 节）。PDMN 的新手指南写的是给同伴设行为方针、让它们自动行动。本作要玩家决定的是“这一轮让谁承担风险、把哪次招式机会留到后面”。
2. **失败代价落在伙伴身上。** 本作全灭时，非初始成员可能走失，要靠救援订单接回，等待按有效探险次数计算（[失败回归与服务点](https://github.com/392fyc/pokemon-dungeon-lab/blob/d03ef5144f5671b3b8d5418b94353223742e911a/docs/04-%E8%A7%84%E6%A0%BC/%E5%A4%B1%E8%B4%A5%E5%9B%9E%E5%BD%92%E4%B8%8E%E6%9C%8D%E5%8A%A1%E7%82%B9.md)）。PDMN 自述的失败只损失背包和金钱。
3. **短局，可以带着成果提前撤离。** 本作远征只有 3 层，完成目标后可从普通出口撤离，第 3 层在首领前也留了出口。PDMN 是一层层往下走到底，再配一条长剧情。
4. **没有饱腹度和大量道具。** 本作目前没有饥饿规则；招式按“保护、直线打击、近身推退”这几类明确用途设计，配招本身就是选择。PDMN 的乐趣更多来自道具、天气、陷阱和状态的组合。

## 用户定向（2026-10-30）

用户看过本页初稿后给出以下方向，是**已定约束**，优先于下文的分析：

- **不做剧情。** 本作核心是肉鸽玩法，以及以后陆续加入的各种系统；后续系统仍按前面的约定，等用户一起参与设计。
- **宝可梦数量随数据库扩充。** 物种和招式数据依赖 Showdown 这类数据库来更新，不靠手工逐个录入。
- **招式表现大多参照官方探险队。** 在迷宫里怎么生效（射程、范围、效果），大部分按官方《不可思议的迷宫》系列的做法；旧官方探险队里没有的宝可梦和招式，由本作自己设计它在游戏中的表现。
- **素材走同一条产线，效率优先。** 继续用现有的素材产线（SpriteCollab 角色加自制生成）快速产出；画面是否和其他作品相像无所谓，不刻意规避。

## 差异化建议（工作候选）

本节是 Claude 主会话的分析，**不是已定设计**，也不新增任何系统。

- **不拼剧情和线上服务。** PDMN 有 20 章剧情、联机、交易所，且几乎每天更新。本作不做剧情，也不把这些线上功能当目标。物种数量则不同：用户决定靠数据库扩充，所以数量可以随数据增长，重点是导入链路（数据 → 招式表现 → 素材 → 遭遇）足够快。
- **把差异集中在已有的核心上。** 上面四条就是本作的方向：少数伙伴、直接干预、失败落在伙伴身上、短局撤离。7.4 平衡长测应检验这几条是否真的产生选择，例如“谁来承伤”是否有不同答案、走失与救援的负担是否可以承受；而不是靠增加系统去追平 PDMN。
- **界面先讲清楚三人行动。** PDMN 的同伴是自动行动的，本作的卖点要靠玩家看清“本轮还有谁能行动、谁会挨打”才能体会到。这与[八款参考](https://github.com/392fyc/pokemon-dungeon-lab/blob/d03ef5144f5671b3b8d5418b94353223742e911a/docs/06-%E7%A0%94%E7%A9%B6/%E5%8F%82%E8%80%83%E9%A1%B9%E7%9B%AE/%E8%B7%A8%E9%A1%B9%E7%9B%AE/%E5%85%AB%E6%AC%BE%E6%B5%8F%E8%A7%88%E5%99%A8%E6%B8%B8%E6%88%8F%E5%8F%82%E8%80%83%E4%B8%8E%E7%A0%94%E7%A9%B6%E4%BC%98%E5%85%88%E7%BA%A7.md)中 Tazos 的行动预告是同一个研究问题。
- **画面不作为差异化手段。** 继续用 SpriteCollab 精灵会和 PDMN 相像，用户已决定以效率为主、不刻意规避。公开发布时的素材许可路线是另一件事，到时仍须用户决定。
- **当前不做的部分**：剧情、账号与云存档、联机和交易所、每日更新节奏。原作地形图块有许可问题，地形继续用自制生成的图块。额外的肉鸽系统、Z 招式、极巨化等系统等用户一起参与设计。

## 后续可补的核查

- 实际进入游戏，观察队伍人数上限、同伴自动行动的效果和失败结算画面。这需要玩过新手剧情，费时较多，等需要比较具体操作时再做。
- 若以后决定公开发布，再比较两边的素材许可做法。
- 扩充招式时，逐个核对官方探险队里该招式的射程和范围；官方没有的，记为本作自定并说明理由。
