# 伙伴探索价值与迷宫分工

首版现行研究从[核心玩法与首版范围](核心玩法与首版范围.md)进入：先用保护、直线打击与推退连接探索和战斗；下文六类用途作为扩展问题库，不要求同时制作。具体坐标、资源和失败例子见[伙伴选择的代表场景](伙伴选择的代表场景.md)。

状态：奖励方向与伙伴探索作用的研究候选。按用户最新要求，首批先让招募、成长、恢复、撤离与基地培养成立；招式、道具强化和培养材料按用途分批展开，Z 晶与 Mega 明确延后。此前方向保留，不等于同时进入首批。

关联：[队伍人数与满员招募](队伍人数与满员招募.md)、[无尽迷宫分区](无尽迷宫分区与守关规则.md)、[三张地图样例](迷宫与任务样例推演.md)、[招式数据适配流程](../../05-制作流程/数据整理与招式适配流程.md)。

## 让伙伴有用的判断标准

一个伙伴值得带，应当能改变至少一种路线、站位、资源或风险决定。高伤害是一种价值，但不是唯一价值；只写“采集某材料加 10%”容易让其成为出发时必带、入场后无事可做的工具角色。

候选做法是给每个首批伙伴记录：一个能经常用到的战斗作用、一个可改变探索决定的用途，以及至少一个明确限制。二者可以来自同一个招式，不要求为每只宝可梦制作独有小游戏。下表是行为模板，不是已确定的职业、原作特性效果或强制编队槽。

| 作用方向 | 在战斗中怎样有用 | 怎样影响探索选择 | 代价与普通替代路线 |
| --- | --- | --- | --- |
| 近距保护与牵制 | 在窄口阻挡推进、让伙伴有空间转位 | 愿意处理较短但迎敌密集的通路 | 占据前排、消耗生命或招式资源；也可走较长的遮挡路线 |
| 直线或远程攻击 | 从有利射程处理敌人，重视视线和遮挡 | 更愿意选开阔或直线走廊 | 被贴近或挡线时受限；其他队伍可用转角接近 |
| 范围控制与位置调整 | 分开敌群、创造穿越或拾取窗口 | 能争取旁支奖励而不必全清敌人 | 有持续时间、次数或位置条件；可以放弃支路走普通出口 |
| 有限恢复与解除状态 | 用一次行动或有限资源维持队伍 | 多探索一个房间、少买一件补给 | 不设无消耗无限恢复；普通队伍可带物品、早撤或避开风险 |
| 机动与带队转位 | 协助同伴通过危险区域或调整阵形 | 取一条可选近路、减少暴露 | 明确作用距离和可带对象；主目标及出口另有普通可达路 |
| 信息与道具运用 | 较早识别远处威胁，或更合适地投放物品 | 决定调查哪个分支、何时消费资源 | 信息不等于全图透视；基本攻击预告和必需路径不能只对某伙伴可见 |

六类作用是长期可选方向。首批先覆盖可靠攻击、射程、保护、控制等，恢复由物品和休整承担；队伍治疗与恢复 PP 招式下一阶段逐项比较，见[恢复专题](无尽迷宫恢复与局内成长.md)。

“每个伙伴都有用途”不等于每只都应在每张图同样强，也不意味着要把全部物种同时纳入首批。至少提供两种不同方法处理同一个探索问题；缺少某个属性或特性时可以改路线、用道具或在已明示的节点撤离，而不是永久卡门。

## 分批展开的奖励方向

奖励方向与地图生态分开：同一套地形可以搭配不同目标与奖励主题。按[阶段安排](分阶段范围与扩展顺序.md)，首批先用招式机和已有消耗品使循环成立，强化与培养材料在用途明确后分批加入；下表保留方向，不表示三套系统同时制作。Z 晶与 Mega 进入后续扩展。

| 迷宫类型候选 | 玩家主要想带回什么 | 本局可作的选择与目标例子 | 哪些伙伴作用容易体现 |
| --- | --- | --- | --- |
| 招式遗构 | 招式机或用途明确的招式选择 | 三条支路偏直线、范围、支援奖励；在有遮挡的房间接近记录匣，选择适合当前或下次队伍的一项，不要求先拥有该招式才能领取 | 射程、牵制、位置控制；玩家用已有招式解决问题，获得新的搭配机会 |
| 器材与道具材料区 | 对已定义道具进行强化所需的材料 | 在普通材料路线和较高价值的可选回收支路间选择，确认箱子取得实物；携带空间和本局消耗共同影响带走什么 | 防护、道具运用、路线信息；不开采集自动加倍的强制职位 |
| 伙伴培养区 | 让新伙伴更快可用或调整培养方向的材料，具体系统待定 | 选择偏招式准备、状态调理或培养调整的目标；挑战提供替代玩法，不要求带尚未能作战的指定伙伴完成唯一任务 | 恢复、控制与不同输出方式；奖励可给基地伙伴使用，不强迫弱新人反复陪跑 |

可补充“生态调查”作为偏招募机会的任务标签，复用溪谷等地图与普通战斗。它可以提高接触某类生态的机会，**不是击败一次必加入或补位保底**；实际邀请仍是概率事件。

### 定向不能变成唯一打工入口

- 出发时给主要奖励方向与可选类别，重要奖励点可提供少量明确选择，减少缺什么却只能完全随机碰运气的次数。
- 常规迷宫保留少量混合收获；同一种常用资源可出现在不止一套地图或目标中。不要要求“先刷 A 才能进入 B、再刷 B 才能恢复 A 的队伍”。
- 一次探险可以同时推进基础收入、伙伴招募和目标材料，不先插入专用恢复关。无尽是混合挑战和连续组合的选择，普通定向委托仍是寻找特定材料的稳定入口。
- 高阶或深层奖励可提高选择范围与潜在价值，但不能把初始二人重新出发的能力锁在高阶 Boss 材料后面。
- 不为每个迷宫类型新增独立货币、碎片和每日门票。Z 晶作为奖励类别不自动意味着要再建一套 Z 晶碎片合成链。
- 需要的材料数量与掉落概率尚未确定，不能凭“任务定向”宣称重复劳动已解决。

## 同一队伍在不同区域为何选择不同

以下保留为后续加入恢复型招式时的对照，不是首批必须完成的队伍。设三人分别具备近距保护、直线攻击兼机动、有限恢复的作用；角色只是功能示例，不固定物种或招式。首批可用控制伙伴与实际物品完成对应比较，不要求先提供治疗招式。

1. 招式遗构：利用直线攻击压住长廊，机动伙伴帮助转位；玩家可以选择较短支路，或保留资源走普通路线。
2. 道具材料区：可选高价值箱在有多方向威胁的侧室；保护和恢复使接近更稳，机动伙伴能帮助缩短暴露，但放弃箱子仍能到出口。
3. 如果碰到稀有交换机并送回恢复伙伴：该伙伴安全，队伍失去之后的恢复手段。应重新比较补给和下一段威胁；不能以“后面总会招到另一只治疗”作为继续的依据。
4. 若后来确实击败敌人并出现控制型伙伴邀请：可以接受填空位，但控制并不等同于原恢复作用。队伍可通过减小受击、改走另一条路继续，或者仍决定撤离。
5. 下一处招式区域改为多方向遮挡地形：控制与转位可能比直线输出更有用；复用已有主题也能改变行动，不需要先增加大型系统。

例子的目标是让新人改变做法，而不只填满人数。没有给出数值胜率，也不保证每种角色总能替代另一种角色。

## 培养材料不能让新人长期不可用

若刚招募者要先刷大量材料才能做任何事，玩家会更愿意一直用已培养队伍；迷宫类型再多也无法让新伙伴自然进入循环。

候选先保证接受时就有可行动状态和至少一种可用的战斗/探索作用。培养材料优先研究扩展选择、降低调整成本、让新人接近当前档位所需能力，而不是无限堆永久属性。跟随低风险任务获得准备资源应当可行，不能只在必须用成熟队伍打赢的区域发放唯一培养材料。

[入队与基地培养](新伙伴入队状态与基地培养.md)已比较共享本局等级、个人永久招式库的 B 候选，以及永久等级对照。新人有可用基础组合，老伙伴可预先配置已学招式；B 没有被定稿。首批先用基地招式机学习，培养材料用途随后补齐；没有自动返还已消耗招式机或复制同种老成员投资。

## 内容制作时怎样检查伙伴真的不同

每名候选伙伴和其关键招式补一张短卡，复用[内容制作卡模板](../../05-制作流程/内容制作卡模板.md)：

| 记录项 | 需要回答的问题 |
| --- | --- |
| 实际动作 | 玩家在什么情况下能用什么动作改变局面？是射程、位置、状态还是信息？ |
| 探索用途 | 在哪类房间或目标中会产生另一种选择？ |
| 资源与限制 | 消耗什么、不能处理什么；是否会变成无限恢复或全图必带能力？ |
| 普通替代方法 | 没有这只伙伴时，能否用另一角色、道具、普通路或合法早撤解决？ |
| 与现有伙伴的差异 | 如果只是同样技能多 5% 数值，是否值得占首批名额？ |
| 可复用来源 | 哪些资料来自固定版本 Showdown，哪些地牢行为需本作适配，动作与特效是否已有来源？ |

先让少量伙伴在一张图里表现出不同决定，再扩充种类。未运行原型前，这些卡只能证明设计表达了差异，不能证明玩家会使用或觉得有趣。
