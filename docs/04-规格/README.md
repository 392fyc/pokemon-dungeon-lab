# 规格（变更单）

每份规格是一次里程碑的变更单：写明当时要改什么、为什么、怎样验收，并保存用户原话与长测依据。合并后，结论已收进[游戏规则](../01-现行规则/游戏规则.md)，规格本身标为“已取代”，只作细节与历史依据。新的里程碑先在这里写规格（状态“草稿”），合并时再收编。
