# 游戏规则

本页写 `main` 分支上的游戏现在怎样运作：玩家能遇到的规则和数值。随 main 更新。游戏规则分两层：本页是核心页，只有概览和索引；每条规则的正文在六个主题页里。

- 每条末尾括号里是来源决策的编号；谁决定、为什么、当时的讨论，都在[决策登记](../03-决策/决策登记.md)里查。
- 数值能不能由代理调整，以所引决策在决策登记里的决定者为准：决定者是“用户”的，代理不能自行改；其余是工作值（代理按长测或推导定的，用户可以改）。正文里个别标“用户决定”的，是容易被误当成工作值的几处。
- 规则按代码写；与规格不一致时以代码为准。存档格式、随机序列、保留未用的代码等实现约定见[实现备注](../05-制作流程/实现备注.md)。
- 编号不复用：删掉的条目留空号，别处的引用不会指错。G 编号和子条编号分层前后不变。

## 怎样读

本页是门禁必读，读全文即可。要改哪部分规则、或要回答哪部分的规则问题，就用 Read 全文读下表对应的主题页；拿不准涉及哪几页时，六页全部读。不要只按关键词或编号去筛行，因为一条规则常常引用别的编号。下面的摘要只是目录，不能当规则依据，规则以主题页正文为准。

## 跨页依赖

下列条目被多个主题页引用，正文只在原条目里，改动时两边都要读：

- 换层和远征结束清零攻防阶段与异常（G3.6）影响战斗页的阶段与异常（G5.5、G5.13）。
- 自动选招（G4.6）共用 G5 的伤害、命中和相性公式，敌人的 30% 异常分支是 G5.11 的例外。
- 轮末结算顺序（G6.4）串起经验、学招、进化、首领招式机和招募（G8.1），也影响挑战房开门（G3.9）和委托经验（G3.11）。
- 祝福的抽取与效果（G3.12）被挑战奖励（G9.10）引用；橙橙果回复的算法跨 G3.12 与 G9.1。
- 物品里的宝珠与解除异常的果实（G9.1）依赖异常规则（G5.13）。
- 界面页（G13.1）引用命中与阶段公式（G5.1、G5.5）；百科（G13.6）的名词条目标注游戏规则各节的规则编号。
