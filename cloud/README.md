# Codex Cloud 环境准备

本项目目前没有游戏程序。云端环境用于后续数据整理、二维素材处理、实现与测试；本轮只准备环境和研究上下文。

## 当前准备目标

- 私有环境，仅连接本仓库，不连接 Ship of Theseus、Mercury 等其他项目。
- Node.js 24.22.1、npm 11.16.0，与本轮已经核实的 REA 6.7.0 工具链一致。工具链选择不等于确定游戏引擎。
- Python 3、Git，以及 JSON、CSV、XML、图像检查所需的基础工具。
- 可用的无头 Chromium 与 Playwright，用于未来网页预览和自动检查。
- 可以安装 REA 6.7.0 的 Linux CLI，验证 MCP 服务本身；具体分析引擎按任务另行配置，不据此宣称所有提供方可用。
- 本轮不需要模型 API 密钥、游戏账号或其他秘密值。

## 环境验证要求

记录实际运行时版本，验证 Node.js、npm、Python、图像读写、浏览器启动和 REA MCP 健康检查。验证使用临时样例，不创建游戏功能、选定引擎、下载整套游戏素材或提交安装缓存。

云端的安装与验证结果以真实 Codex Cloud 设置及实测报告为准。配置文件已保存、环境已发布、检查已通过分别记录，不能互相替代。Linux 云端不能代替 Windows 原生版本的验收。

## 后续任务

先取得具体实现目标，再决定引擎和相应构建、测试、导出命令。每个后续任务应说明输入、允许改动范围和需要验证的行为。
