# REA 辅助研究目录

本目录收纳独立路线产生的目标研究结果；玩法与制作入口在游戏项目路线（归档：`docs/90-archive/早期框架/游戏项目路线.md`）。

先读REA 路线职责（归档：`docs/90-archive/早期框架/REA辅助研究路线.md`）和审核范围 v0.1（归档：`docs/90-archive/审核版本/v0.1-2026-10-25/REA研究范围与证据.md`）。已交付 PokéBonk 0.8.47／构建 mvnpa0xv 的普通招式执行、存档与恢复两项静态研究；尚未进行目标实机验证。

## 已交付研究

- [八款参考游戏的发布与维护经验](八款参考游戏—发布与维护经验—2026-10-27.md)：八站入口矩阵，PokéBonk 旧包、PokéCatch 加载失败、FighterZ 首次与返回分支，及个人地牢首版发布候选。依据既有快照与静态片段，未完成全站运行或后台部署验证；[入口清单](八款游戏发布入口—证据清单—2026-10-27.json)记录采样身份。
- [参考项目制作与发布管线](参考项目—制作与发布管线—2026-10-27.md)：自有 mod 的素材、青焰技能与噩梦奖励，以及 PokéBonk 历史包的角色精灵、GLB 道具、连锁招式和协议；两项目静态深挖。发布经验以八款外部参考游戏为范围，自有 mod 不作为发布来源。
- [76 项管线证据索引](参考项目—管线证据索引—2026-10-27.md)：51 处固定提交源码与 25 处固定构建偏移，附输入摘要和交付范围。

- [PokéBonk 普通招式执行路径](PokéBonk—普通招式执行路径—mvnpa0xv.md)：来源数据、适配、学习与实例、执行、命中及状态结算；十万伏特、飞叶快刀、日光束三个分支。

- [PokéBonk 存档与恢复路径](PokéBonk—存档与恢复路径—mvnpa0xv.md)：招式等级与强化的保存边界、中断成果补交、长期档案、新局对象和历史展示。
- [存档与恢复证据索引](PokéBonk—存档与恢复路径—证据索引—mvnpa0xv.md)：字段结构、原始范围、REA 追踪记录，以及服务端和实机验证的未知。

## 后续报告命名

使用“作品—具体问题—版本或日期.md”，例如“PokéBonk—普通招式执行路径—构建标识.md”。名称示例不是已经存在的文件。报告中的版本和摘要应指向实际分析输入，不能只写“最新版”。

每次只增加解决明确问题所需的报告和证据引用，不复制一整套游戏设计库。本目录默认由 REA 路线维护；游戏路线消费结果后在自己的决定中引用。
