# 伙伴跟随与倒下通路

> 固定来源：392fyc/pokemon-game-research@5f3547889b30e59f6cdfebc5af8c91e46cba4ee4。本副本保留原文的研究阶段身份；2026-10-29用户已批准按准备包开始阶段3—4并采用Vite，当前授权以[执行入口](../README.md)为准。本文件为派生副本，库外链接已固定到同一来源提交；源与目标摘要见来源清单。

当前主候选是：**倒下成员仍占同行名额，但从地图退场；跨层后也可以替换。所有新人共用本批邀请固定的入场位置规则。**普通伙伴利用空路跟近，需要调整前排时双方付行动换位；无敌走廊返向优先切主控。

这是 pokemon-dungeon-lab 的设计交付与主会话整合结果，不是运行验证或用户最终裁决。三人同行、当场替换回营沿既定方向；具体跟随、换位和倒下资格为本轮候选。精确定义现集中在[当前规则表](当前规则表.md)R04—R08；本页保留方案比较与坐标反例，历史审核正文保留原身份。

## 1. 跟随负责靠近，不负责自动战术

现行算法唯一维护在[规则表R04](当前规则表.md#r04-默认伙伴行为)。它允许沿可走空路靠近，不要求终点必须是主控的空邻格；这使窄路后排能先跟到前一名伙伴之后。它不自动穿人、让位、耗PP或找射线。

只寻找主控空邻格的更短替代，在窄口会使尾部停滞；四组同输入比较见[探索节奏与操作简化](https://github.com/392fyc/pokemon-game-research/blob/5f3547889b30e59f6cdfebc5af8c91e46cba4ee4/%E7%8E%A9%E6%B3%95%E7%A0%94%E7%A9%B6/%E6%8E%A2%E7%B4%A2%E8%8A%82%E5%A5%8F%E4%B8%8E%E6%93%8D%E4%BD%9C%E7%AE%80%E5%8C%96.md)。每轮重算也可能因动态占位改路，不能证明所有地图都顺畅。例子中的伙伴等待不另加世界轮，出口不要求全员贴身。

## 2. 换位消耗双方行动，在较晚者到序时完成

提交、预留、到序交换、失效和入格效果均按[规则表R05](当前规则表.md#r05-换位)。双方付行动使调整前排有代价，不会让较晚成员提前出手或在交换后免费攻击。无敌返向只为退出时，选靠出口者为主控通常更省输入；下方分别验证两种目的。

## 3. 倒下跨层与入场方案比较

比较依据是：正常撤离已经按同行名单处理倒下者，不要求拾取身体。是否仍应让替换依赖身体坐标，需要说明它对玩家选择的价值，而不能只为了延续一个位置字段。

| 比较方案 | 玩家要记住什么 | 界面与保存职责 | 主要限制与取舍 |
| --- | --- | --- | --- |
| 原层原格资格 | 活人原格；倒下者再查楼层、占位、邻接；空位加入另看主控附近 | 倒下楼层、坐标、距离与占位均影响资格，需要解释多种失败原因 | 跨层后要回旧层或保留不能替出的名额；与按名单撤离的表达不一致 |
| 活人原格，倒下或空位在主控旁 | 两种入场方式，倒下位置不再重要 | 省去倒下坐标资格，仍要解释主控变化和不同落点 | 能取消跨层限制，但替换对象决定使用哪套空间规则 |
| **所有新人共用固定集结格，推荐** | 记一套入场顺序；选谁回营，决定保住谁及失去哪种作用 | 只为待处理邀请保存集结格，展示确定落点和当前占位 | 新人可能出现在比离队者原格更有用的位置；范围内没格仍不能接受 |

采用第三种作为当前主候选。它容许新实例入场时重新部署，留下的活伙伴没有免费移动，旧实例也不能从营地随时调回。当前没有必要另加跨层惩罚：倒下已使队伍少一个能行动的成员，幸存者承担威胁，补位仍依赖真实邀请与合法入场。这个判断是设计推荐，不是倒下成本已平衡的证明。

### 倒下状态

倒下退图、仍占名额、跨层可替与名单撤离统一按[规则表R06](当前规则表.md#r06-倒下与主控继任)。身体历史位置不再参与替换资格，当前活单位的真实占位仍然限制入场。倒下不等于回营、永久失去或额外名额。

## 4. 所有新人共用一个入场规则

邀请快照见[规则表R07](当前规则表.md#r07-邀请快照与资源)，集结格、五格检查、队列、自动继任与逐项替换见[R08](当前规则表.md#r08-邀请集结预览与替换)。这里不再重复另一套执行条文；下方四组对照都是对该规则的具体输入，不改变资源或给额外行动。

玩家只需看到选谁回营、新人实际落点和下一轮才行动；坐标与详细检查顺序放在研究例子及按需帮助中。

## 5. 跟随与通路的坐标例子

全部为封闭纸面模型：四方向；x 向右、y 向下；只列出的格为地面，其余为墙；我方固定队列后敌方。一人一轮至多一次移动、攻击、施招或等待，没有陷阱、持续伤害或反击。局部表在最后敌人倒下时停止记录，邀请仍到完整轮末处理。真实地图仍执行剩余成员；本表截断位置不能直接作为下一遭遇的开局。完整行进见[连续探险](https://github.com/392fyc/pokemon-game-research/blob/5f3547889b30e59f6cdfebc5af8c91e46cba4ee4/%E7%8E%A9%E6%B3%95%E7%A0%94%E7%A9%B6/%E4%B8%80%E6%AE%B5%E5%AE%8C%E6%95%B4%E6%8E%A2%E9%99%A9%E7%9A%84%E8%BF%9E%E7%BB%AD%E6%8E%A8%E6%BC%94.md)，不额外赠送移动或重排。

### 例一：单格走廊返向

地面 (0,1)…(4,1)，出口在0；A3、B2、C1，队列 A→B→C，均生命10，无敌人。表内省略共同 y=1。

只想退出：改选 C 为主控，不改队列。A 被 B 隔住，没有更近可达格而等待；B 与 C 相邻等待；C 从1移到0。轮末 A/B/C=3/2/0，零次伙伴覆盖、零次换位。之后按正常出口规则交互，不需要全员贴身。

如果确实要保持 A 前排，再比较有代价的队形调整：

| 轮 | 输入 | A | B | C | 轮末 A/B/C |
| --- | --- | --- | --- | --- | --- |
| 1 | A 与 B 换位 | 预留行动，不动 | 到序交换 A/B | 与新 A 相邻，等待 | 2/3/1 |
| 2 | A 与 C 换位 | 预留行动，不动 | 此时仍邻接 A，等待 | 到序交换 A/C | 1/3/2 |
| 3 | A 到0 | 1→0 | C 仍在2，等待 | 2→1 | 0/3/1 |
| 4 | A 等待 | 等待 | 3→2 | 与 A 相邻，等待 | 0/2/1 |

每轮每人至多一次动作；前两轮各用一次覆盖。第4轮仅展示固定队列造成的跟随延迟，不是额外撤离条件。换位适合特定位置需求，不作为无敌返向的必付成本。

### 例二：门口两名伙伴占道

地面为 (0,1)、(1,1)、(2,1)、(3,1)、(2,2)、(3,2)。队列 A→B→C，A 主控在(3,1)、B在(1,1)、C在(2,1)，均生命10，无敌人。

| 轮 | A | B | C |
| --- | --- | --- | --- |
| 1，覆盖 C 向下 | 等待 | 唯一出口被 C 占，等待 | (2,1)→(2,2) |
| 2，无覆盖 | 等待 | (1,1)→(2,1)，到达邻位 | 绕开 B，从(2,2)→(3,2)，到达邻位 |

共一次让路覆盖，每次移动都用该角色本轮行动。C 的第二步由空路规则得到，不假设伙伴理解战术。若两格侧路都是墙，此解法不成立，可以付行动换位或保持站位。

### 例三：主控倒下，幸存者经过原格仍会受伤

地面 (0,1)…(4,1)。队列 A→B→C；A 曾在2倒下，现已从地图退场；B在1、C在0，生命各8。B 接任主控，不改队列。敌 E 在3，HP6；相邻攻击3，否则向最近幸存者走一步，不能走后攻击。我方普攻6。

| 轮 | 我方 | 敌方与结果 |
| --- | --- | --- |
| 1，B 向右 | A 跳过；B 到2；C 跟到1 | E 打 B 3，B 余5 |
| 2，B 普攻 | A 跳过；B 击倒 E；本表记录止于击倒时 | A 仍倒下；此刻B/C=5/8 |
| 下一探索轮，B 向右 | B 到3；C 从1跟到2 | A 仍在同行名单中，地图格2可用 |

A 每轮零动作，其他成员每轮至多一次；倒下者没有替 B 挡伤害。若 B 初始只有3生命，第一轮会倒下，C仍在；这属于承伤代价，不是身体封死通路。

## 6. 四组入场对照

除另述，当前层为 x=1…4、y=1…4 的地面，边界外为墙，没有剩余敌人、陷阱或直接效果；活成员生命10，倒下者0。每个例子均已在完整轮末真实产生邀请，新人用固定资源，菜单内动作数为0。比较中的旧规则仅作为本轮被比较方案，不作为现行指令。

### 例一：倒下在一层，邀请在二层

队列 A→B→C，A主控在二层(2,2)，B在(2,3)，C曾在一层倒下；选择 C 回营。

| 方案 | 结果 |
| --- | --- |
| 原层原格 | C 不可替，需改选或拒绝 |
| 活人原格、倒下在主控旁 | N 到(3,2)，队列 A→B→N |
| 统一集结格 | 本格被 A 占，右格(3,2)合法，N 到该格；队列 A→B→N |

当前推荐下 C 安全回营，A/B 不恢复；下一轮 A 等待，B/N 均邻接 A 而等待，N 首次行动机会在队末。无需回一层，仍不能凭预期邀请提前恢复队伍。

### 例二：原倒下格已由活人占据

A主控在(2,2)，B在(3,2)，C曾在(3,2)倒下，队列 A→B→C。选择 C 回营。原格方案不可接受；当前推荐检查本格 A、右格 B 均占，取下格(2,3)，队列 A→B→N。B未移动，N没有叠在 B 上；下一轮 A 等待时 B/N 均默认等待。

身体的历史坐标不再限制资格，**当前存活单位的占位仍然限制入场**。

### 例三：附近全满，远处空格不作为备用

本例地面 x=1…5、y=1…5。A主控(2,2)，B=(1,2)，C倒下，队列 A→B→C；三个存活敌人占(3,2)、(2,3)、(2,1)。敌人在刚结束的轮中已行动，菜单内不再行动。远处(5,5)空闲。

| 选择 | 当前推荐的结果 |
| --- | --- |
| 替 C | 五格都被占，此方案不可确认；远处空格不使用 |
| 替 B | 预览释放左格(1,2)，N进入该格；队列 A→C→N |
| 替 A | 本格(2,2)释放，N进入；队列 B→C→N，B接任主控，集结格仍(2,2) |
| 拒绝 | 保留原队，处理完邀请后可以继续提交行动 |

下一轮 N 才在队末获得行动机会，敌人威胁仍在，不保证入场后存活。若同行只有 A/B而空名额加入，也因五格全满不能直接补入；可以选择有合法落点的替换或拒绝，不在菜单内先移动再接受。

### 例四：连续两份邀请，第一份替下主控

A主控(2,2)，B=(2,3)，C=(4,2)，队列 A→B→C，均存活。轮末邀请按 N、M 顺序处理：先 N 替 A，再 M 替 C。

| 步骤 | 当前推荐的结果 |
| --- | --- |
| 先替 A | 本格释放，N到(2,2)；队列 B→C→N，主控自动改 B |
| 再替 C | 集结格仍(2,2)，本格 N 占，右格(3,2)空，M到(3,2)；最终队列 B→N→M |
| 反复查看或恢复 | 集结格、顺序和当前占位不变，不能重选成 B 附近的(3,3) |
| 下一轮 B 等待 | B等待；N邻接 B等待；M从(3,2)跟到(3,3)，这是 M 本轮唯一动作 |

这里 M 没有出现在 C 原来的(4,2)，是统一入场明确允许的新实例重新部署。C离开本局、M只带自己的资源且排在队末；B/N没有免费移动。若把刚来的 N 再换成 M，同一批也不插入攻击或把两人的资源相加。

## 7. 保存与后续体验问题

保存与恢复统一遵守[规则表R11](当前规则表.md#r11-保存与恢复)，不保存半次换位或替换，不因自动继任而重选本批集结格。面向玩家的提示见[玩家操作](玩家操作与中断恢复.md)。

后续观察固定落点是否清楚、重新部署收益、附近拥堵频率，以及倒下退图但仍占名额是否易懂。当前纸面检查没有证明所有局面可逃、跟随不会反复，或输入已经顺手。
