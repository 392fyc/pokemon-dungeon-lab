# 单层试验的运行与检查

本片段执行研究PR #4准备包的临时基准：一张固定单层图、三名同行者、一名主控和一次伙伴干预，包含招式、倒下、邀请、取得成果、撤离／全灭与独立重开。画面使用自制几何，数值为人工输入。规则来源和授权见[当前规格入口](../trial-spec/README.md)。

## 运行与构建

使用Node 24.22.1、npm 11.16.0。根`.nvmrc`标记Node版本，`package-lock.json`固定实际依赖；运行时Phaser 4.2.1，开发依赖TypeScript 5.9.3、Vite 8.3.5。

```sh
npm ci
npm run dev
```

命令输出本机网页地址。需要查看生产构建时执行：

```sh
npm run build
npm run preview
```

构建目录为`.artifacts/trial/dist/`，包含HTML、脚本、样式和第三方授权声明。该目录被Git忽略，可作为私有构建交付；需要HTTP服务，不能靠双击HTML文件运行。这里没有公开部署步骤。开发服务和预览服务如果使用不同网页来源，存档互不共享。

## 操作

- 方向键或W/A/S/D移动；点击相邻敌人普攻；句点等待。普通合法输入立即推进完整一轮。
- 在队列中设为主控，或用1／2／3切换。切换免费，队列不重排；已有组合草稿会被清空，并提示“组合已取消”。
- 先选招式，再点目标。提示说明距离、效果和消耗，金圈表示按当前计划可用的目标；Escape取消选择。
- “安排伙伴”后选择伙伴，分别编辑伙伴和主控动作，再提交整轮。草稿中一直显示当前编辑者。换位占两人的行动和唯一干预。换位草稿中，方向键、句点和点地图都不会改写动作；要改成其他动作，先取消组合。
- 站在G／T上时首次可取得并继续或请求撤离；取得后仅可请求撤离，纯出口也只提供撤离。合法交互仍占一轮，敌人会行动，交互者倒下可能导致撤离取消。重复取得被拒绝，不推进世界轮。
- 邀请会暂停世界。比较资源、选择回营对象并确认，或明确拒绝；拒绝确认中的Escape返回比较，关闭详情不等于拒绝。倒下者仍占名额。

## 保存和异常恢复

当前试验及至多一份最近终局保存在浏览器localStorage的`dungeon-trial.player.v1`。每次初态、完整轮、单项邀请处理、待退出和终局都保存完整记录。待退出保存成功后完成一次终局，无需再扣行动。

保存中可以查看，普通行动阶段还可编辑未提交草稿；不能提交，也不会排队执行。保存失败时保留内存中的完整结果并冻结后续世界变化，重试仅写同一份记录。提示显示最后成功点；首次保存失败时明确没有可恢复记录。

正常撤离和全灭保留各自的实例结果。开始独立试验使用新身份与规格初态，同时保存上次结束记录；不继承物资、伤害或培养。重开写入失败时新地图不能操作。

损坏或版本不兼容的记录保持原字节，先导出并保留文件，再明确确认重置。关闭、清理浏览器数据或换浏览器不是游戏中的撤离。

## 检查

```sh
npm run check
npm test
npm run test:acceptance
```

自测覆盖实现的主要行为；`tests/acceptance/`由REA云从固定规格独立编写，核心断言不使用生产跟随、伤害或资源计算生成预期。浏览器检查覆盖真实键鼠输入、画面状态和实际localStorage调用，与纯规则检查分开记录。

Windows浏览器检查使用本机已有的Playwright和Edge。先运行本机服务，再设置`TRIAL_URL`为该地址、`PLAYWRIGHT_MODULE`为已安装Playwright的模块路径；需要指定其他浏览器程序时设置`BROWSER_EXECUTABLE`。执行`npm run test:browser`。该检查不自动下载浏览器，不是Electron验收。可用`TRIAL_CHECK_FILTER`选择单个相关检查，避免无关重复运行。

浏览器检查的日志与截图写入被忽略的`.artifacts/trial/`。页面的“检查入口”用`dungeon-trial.check.<场景>`隔离保存，检查初态不覆盖正常玩家记录。检查用例包含人工边界局面，不是新增玩家关卡。

## 当前限制

本片段用于验证规则能否正确执行、选择能否通过界面表达。玩家是否愿意反复游玩仍待独立体验者观察，纸面轮数和程序通过不能替代这个结论。随机地图、跨层、正式救援经济、商店、交换机、长期培养、真实角色素材、Showdown及mod代码均未接入。

Phaser进入主脚本后，生产构建存在大于500KB的体积提示；这是本次构建的已知限制，未以提高提示阈值隐藏。依赖授权声明随构建复制，见[第三方声明](../../../public/THIRD-PARTY-NOTICES.txt)。
