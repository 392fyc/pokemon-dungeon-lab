# 370条名单与素材导入规格

用户于2026-11-14确认推荐A档名单，原话见 [#229](https://github.com/392fyc/pokemon-dungeon-lab/issues/229#issuecomment-6874384171)。目标为370条：331条普通物种记录、39条地区形态。当前运行名单仍为175条，按本规格分批导入。

## 完整名单与来源

完整图鉴号、稳定Showdown ID、形态、选定学习表世代、素材路径和逐项来源在 `tools/research/roster216-approved.csv`。仓库中LF换行版本的SHA-256为 `dd147afffe9108191cfbc3590d3aad1e040addcc329350b0d74fea9a5e0869ee`，源A档集合SHA-256为 `0e070a68893157db1c44c8f5b5aab7e20dd181ed4a1f534be99d49255a6c029d`；本机研究回执中的CRLF版本哈希不同，记录集合与字段内容相同。

以当前175种为起点，加入固定表内85个Mega家族的普通成员，并补齐普通与地区形态的进化链。临时Mega不计永久候选；已经按D-20261110-01归并的外观形态不重复计数，其学习表按已有规则取合集。尚未核实的特殊形态保留研究记录。

## 素材交付口径

固定SpriteCollab `42a63b0757b3d55ebca29b27e62cd444cd29047b` 下，366条的XML、Idle/Walk/Attack/Hurt动作与阴影、署名文件和独立Normal头像路径存在。火炎狮、葱游兵、踏冰人偶、列阵兵为4项缺口，目标保留。该快照不同于当前游戏素材版本，导入时须保持每项明确来源，不能把本次存在性结果解释为现用素材丢失。

收集后逐项验证原字节、XML引用链、PNG解码和方向/帧尺寸；读署名正文并同步素材清单与第三方说明；视觉检查另记结果。当前头像仍从Idle帧取图，独立Normal头像存在不自动改变头像实现。

## 分批依赖

以下为dev依据已确认集合和当前接口作出的实施安排：保留175条的现有顺序，新增普通156条，再接入39条地区形态；新增项按全国图鉴号和稳定ID排序。新增普通中152条文件齐备、4条有缺口；地区形态39条均通过已完成的文件存在性检查。缺口状态与批次分开登记。

1. 保留当前175条已有稳定ID和存档引用。先解决收录表驱动、素材子目录与形态稳定ID的导入接口。
2. 新增普通物种与地区形态按进化依赖组织批次；完整目标集合不因素材缺口而缩减。每批都核学招、进化、百科和字体覆盖。
3. 各批以同一准入规则生成，不把有学习记录但尚未实现的招式自动准入。新增传说/幻按已有用户优先顺序安排，出场遵守G12.2。
4. 四项缺口由dev收集或制作可用资产并验收，再补入相应批次；自制产线和原文件来源分别记账。

### 当前接口必须改动的部分

- `tools/data/import_pokedex.py` 目前硬编码175条选择器及522招并集，改为已确认ID清单驱动；按新学习表并集补全PMD招式页快照，先校验来源再导入。现有175的冻结初始招式保持。
- `tools/art/build_character_index.py` 目前只扫描直接子目录；导入器和`src/render/sprites.ts`依赖全国图鉴号查素材。地区形态共用图鉴号，须引入稳定物种ID到素材子目录的显式映射，保留旧数字目录兼容。禁止静默使用同图鉴号的普通形态图。
- 地区显示名按稳定ID补充，沿用已核中文基础名与地区标签；更新后按现有字体扫描流程检查。
- 已选集合包含15个多分支进化父物种。现行引擎已有通用选择流程；dev推断沿用G6.6现有进化条件与玩家分支选择，把额外已选目标逐一列入验收。按各目标自身门槛过滤候选；完整家族为多分支时，即使当前只有一项达标也保留可取消选择，不强制提前进化。新增皮丘后雷丘的阶段换算门槛由20变36已在版本方案中确认。不引入时间、地点或持有物等未实现系统；正式游戏规则随实现同步。
- 版本与迁移已由用户在 [#237](https://github.com/392fyc/pokemon-dungeon-lab/issues/237) 确认（D-20261114-05）：B3/B9之后保持`trial-rules-7`，内容升`trial-content-9`，格式仍为`format:2`。显式迁移7/8、6/7及已支持历史精确配对，保留成员稳定ID、配招与PP、培养、队列、仓库、碎片、难度和永久进度；非法档拒绝且原字节保留，不承诺旧程序能读取新增物种。两批合并顺序为B3/B9→370，各自仍需稳定后用户试玩确认。
