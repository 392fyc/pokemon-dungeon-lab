# 宝可梦地牢 KB 入口

本库是 pokemon-dungeon-lab 的知识库：现行规则、进度、决策，以及背后的规格与研究。项目是一款二维随机迷宫、三人小队、可撤离带出的宝可梦救援队式地牢游戏，网页和 Windows 两端；目标是完成一个能展示个人能力、让玩家喜欢的作品，变现不是核心。

## 先读这三份

1. **[进度](02-进度/进度.md)**：做到哪了、已知问题、下一步、等用户决定的事。
2. **[游戏规则](01-现行规则/游戏规则.md)**：当前构建里游戏实际怎样运作，每条注明来源决策。
3. **[决策登记](03-决策/决策登记.md)**：现行的每条决策，谁在什么时候定的。

怎样读、怎样改本库见 [KB 维护规则](01-现行规则/KB维护规则.md)。每个改动规则、决策或进度的 PR，都要在同一个 PR 里更新这三份文档之一，并写一行 `KB:`。
