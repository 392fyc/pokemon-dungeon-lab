# 八款浏览器游戏参考与研究优先级

用户于 2026-10-27 提供八个项目入口。本页保留首轮官网与说明核查，以及地牢候选下的参考问题。当前跨项目研究按[市场与制作管线分工](../../市场研究/研究范围与双云分工.md)推进；本页不提供品类热度排名。Pokémon Arena 2D 的既有视觉研究继续保留。

用户随后补充了自有[Pokémon Auto Chess 肉鸽 mod](../pokemon-autochess-mod/README.md)。其 `pve-mode` 已有可直接读取的奖励、绑定和 Boss 代码，相关实现经验优先从该来源核对；本页的优先级用于安排外部样本，不替代自有项目经验。

当前用户已确定沿救援队／肉鸽地牢继续；下文按二维迷宫、行动推进回合、三人同行、招募替换和个人培养保留研究参考方法，不重新开放其他品类选择。角色总数、模式数量和画面热闹程度不作为开发效率或适配价值的证明。

## 地牢候选下的具体研究问题

### 优先：Tazos 的三人行动信息

说明页提出每名上场成员一回合有两次行动，可移动加攻击或移动两次，攻击至多一次；还会预告受击目标、伤害与落点是否暴露。它为“玩家行动前需要知道什么”提供了明确参照，但不能证明这种操作量适合本作的伙伴控制方式。[规则入口：官网 → HOW TO PLAY](https://chapas.fun/tazos)

后续先比较三个可观察的问题：玩家能否看清本轮仍可行动的成员；落点会暴露给哪些敌人；一次攻击会影响谁。把这些问题放进已有[三人代表房间](../../../90-archive/审核版本/v0.3-2026-10-25/伙伴控制与代表房间推演.md)，再判断是否需要更复杂的操作。暂不引入弹射物理、十二点编队预算或随队替补。

Tazos 的说明还区分战斗内进化与长期形态，并把部分冒险捕获的保留绑定到下一道馆。可比较“何时生效、何时保留”的提示是否清楚；本作的个人培养、回营和撤离仍以[现有候选](../../../90-archive/审核版本/v0.7-2026-10-26/审核入口.md)为依据，不据此改成道馆结算。[说明入口](https://chapas.fun/tazos)

### 优先：Kanto Tactics 的编队表达与 PokéBonk 的已有实现证据

Kanto Tactics 的站位与协同说明，适合帮助研究如何向玩家解释三人队的功能缺口。例如缺少远程攻击、保护或恢复时，界面应该说明具体影响，而不是只给一个总战力数字。这是本作的分析候选，官网尚未证明它的实际提示质量。[官网说明](https://einoow.com/kanto-tactics)

PokéBonk 已有更深的静态证据，继续用于[招式适配](../pokebonk/招式适配与融合系统.md)、[普通招式执行路径](../../REA辅助研究/PokéBonk—普通招式执行路径—mvnpa0xv.md)与[存档路径](../../REA辅助研究/PokéBonk—存档与恢复路径—mvnpa0xv.md)。实时冷却和本作回合代价仍须分别设计。新入口的发现只触发版本区分，未要求重做所有旧报告。

### 次优先与专项参考

PokéTide 用于像素画面可读性；PokéCatch 用于名册与长期培养入口；Pokémon Royale 用于收藏、队伍和道具配置的关系。这三类问题分别连接[视觉规格](../pokemon-arena-2d/视觉样式参考与素材规格.md)与[入队及基地培养](../../玩法研究/新伙伴入队状态与基地培养.md)，暂不扩展成全功能拆解。

FighterZ Tactics 作为自走棋对照，避免重复研究同类购买与编队循环。Underground Survivors 目前只有入口视觉证据，先保留为低优先级样本。上述排序是针对本作当前问题的研究建议，不是对作品质量的评价。
