# 内容制作卡模板

复制本卡为具体内容建立记录，文件名使用内容名称与研究方向；只有选定内容后再填写。当前模板不代表已经开始制作。

## 内容与依据

- 内容名称与类型：
- 解决的玩法问题：
- 来源身份、规则版本与链接：
- 本作身份与关联物种或形态：
- 已核实事实：
- 来源处理方式：直接复用资料、格式转换、玩法适配或本作新增行为。
- 用户已给定的方向：
- 代理补充候选与仍待决定的问题：

## 行为与投入

- 共用行为、参数覆盖或全新行为：
- 目标、范围、遮挡与敌我关系：
- 触发、结算顺序与结束条件：
- 可强化的字段与单位：
- 伙伴和敌方 AI 的使用条件：
- 组合内容的输入、资格、消耗、继承与结果：
- 撤离、失败和存档需要保留的信息：

## 素材与展示

- 角色动作、方向与发射点：
- 起手、范围、命中及结束特效：
- 界面说明与目标提示：
- 作者、素材来源、版本、许可与修改：
- 缺失资源与可接受的临时表现：

## 当前状态与验证

- 状态：研究中、待决定、待制作、待验证或已验证；混合状态时逐项标明，不以整张卡的标签覆盖未定字段。
- 已完成的部分与证据：
- 实际遇到的问题及复现输入：
- 关联笔记与下一步：
