# 旧版本形状的回归样本

这些 JSON 用于保留 `rescue.test.mjs` 与 `save-transfer.test.mjs` 的旧档迁移测试。来源为固定提交 `f757d51b8b3863d5e76649775802db4527435eb9` 的 v1 规则、基地和保存代码，在 Windows Node 24.22.1 中生成后，按原测试删除 7.2 新增字段或构造旧终局形状。它们是从固定旧实现构造的测试样本，不是真实玩家的历史存档。

- `base-before72.json`：默认基地档案，移除 7.2 新增字段。
- `transfer-before72.json`：木守宫与火稚鸡的新游戏档案，用于导入旧档。
- `run-before72.json`：默认队伍、种子 7 的旧远征，保留旧 `tm` 和背包形状。
- `ended-before72.json`：种子 5 的全灭终局，包含旧招式机及目标结算形状。
- `recent-before72.json`：菊草叶、火球鼠与新招募伙伴的旧全灭历史，用来验证迁移不会再次结算；测试分别代入随机数状态 1、7、123。

样本的版本固定为 `trial-rules-1` / `trial-content-1`，不会随当前版本常量变化。迁移后的规则状态、继续游玩、原记录保护由调用这些样本的测试验证。
