# Obsidian 研究库使用说明

本库位于 D:\Project\Pokemon_Game_Research，用于管理 PokéBonk 和 Big Kid Nation 的 Pokémon Arena 2D 研究。

从 [研究总索引](README.md) 进入，先阅读 [[项目目标与当前决策]]，再按问题查找项目主题。标准 Markdown 链接与 Obsidian 双向链接共同连接笔记；反向链接和关系图可用于追踪结论与来源。

标签按项目和主题分类。事实依据、静态代码观察、分析建议和待决定事项保持区分。当前阶段只研究与整理文档。
