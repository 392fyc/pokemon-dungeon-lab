## 受控发布约定

本任务沿用禁止裸`git push`和禁止直接切换受保护分支的规则。主会话可在已授权GitHub连接中，以Git Data API的`create_tree`、`create_commit`、`update_ref`发布到专用任务分支；提交前核对远端头、白名单、独立审查与必要验证，更新ref必须带`expected_sha`且`force=false`。不向main直写，不修改受管文件，不以其他Shell绕过拒绝。

主整合分支为`codex/trial-slice`。两云实际使用未挂分支的Git候选树交付；主会话按白名单导入当前基线，核对文件后发布任务分支。没有建立`codex/trial-implementation`分支。冲突先回读和整合，不强推。PR审核或提交不自动合并游戏代码，也不公开部署。
