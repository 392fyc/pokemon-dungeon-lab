# 界面设计稿

各个画面当前设计的固定位置。用户和代理讨论样式时都看这里，不用开游戏。

## 怎么看

- **网页版：** [界面设计稿](https://claude.ai/artifact/Wimv8S6LMPmif7QRr5yVFK)，地址固定，每次更新后地址不变。
- **本地：** 用浏览器打开本目录的 [index.html](index.html)。

## 维护规则

- 一个画面一页，顶部标签切换，下方写这个画面的设计要点和待确认项。
- 改样式先改这里，用户同意后才实现。实现时改动同一个 PR 更新这里，让这份稿和游戏保持一致。
- 没有重做稿的画面放在“其他画面”，用游戏实际截图。这些截图随画面改动更新。
- 每次更新后，把网页版重新发布到同一地址。

## 各画面进度

| 画面 | 进度 |
| --- | --- |
| 详情、设置、结算、伙伴小屋、仓库、记录板 | 设计稿，待实现 |

| 天赋石碑 | 暂不改动；天赋内容以后由用户和 main 一起重做，见 [#201](https://github.com/392fyc/pokemon-dungeon-lab/issues/201) |
| 其他画面 | 游戏截图，还没有重做稿 |

## 界面用词

玩家看到的文字用完整的书面说法。规则文档可以继续用简称，界面不用。

| 不用 | 用 |
| --- | --- |
| 打（攻击的意思） | 攻击 |
| 普攻 | 普通攻击 |
| 追 | 追击 |
| 对手、对方（指敌人） | 敌人 |
| 贴住 | 紧跟 |
| 贴身 | 相邻 |
| 睡着 | 睡眠 |
| 朝前 | 向前 |
| 回到 | 返回 |
| 带上（招式） | 携带 |
| 教给 | 学习 |

角色台词可以口语化，例如吉利蛋和卡比兽的对话；官方招式说明不改。

## 版面约定

列表都要考虑条目放不下的情况：固定的摘要留在原位，只让列表自己滚动，并提示还有多少项。结算页的“条目溢出示例”是参照样例，其中标“示例”的奖励并不存在。
