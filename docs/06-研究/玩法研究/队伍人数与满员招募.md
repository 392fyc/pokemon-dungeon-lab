# 队伍人数与满员招募

## 当前已确定范围

用户已明确第一版以三人队为基准，局内同样不增加第四同行位。四人队仅保留为未来更新候选，当前不展开其规则或验证。人数裁决见[首版范围 v0.5](../审核版本/2026-10-25-v0.5/审核入口.md)，当场替换与回营方向见[v0.6](../审核版本/2026-10-25-v0.6/审核入口.md)。

三人指同行队伍，不限制基地名册。初始主控和副手不走失、不强制出战；初始二人、零资产的恢复路线继续保留。当前仍只审核与设计。

## 在三人范围内继续解决什么

当前完整补充见[替换、携物与回营 v0.7](../审核版本/2026-10-26-v0.7/审核入口.md)：轮末邀请、不额外耗轮、允许尚有存活队员时替出倒下者、共用背包不运输物资及本局不可调入。它们是继续研究的候选，尚未成为用户裁决。

- 控制与跟随：一名常规控制、伙伴默认行为与少量覆盖指令，地图和招式按三人验证。
- 新人即时价值：实际击败合格非 Boss 并触发邀请后，有空位可以接纳；满员时可以替换一名同行成员。邀请不保证出现，也不要求默认必须少带一人。
- 满员招募：已明确可以当场替换，换下的伙伴回营地待机，保留实例与个人培养。例：A/B/C 遇到 N 的真实邀请，选择 C 回营，队伍变为 A/B/N。
- 长期培养：比较三人组合中新人基础用途与老伙伴个人配招，不以额外同行位置代替培养价值。

## 必须保留的归属边界

邀请与接受分开；尚未接受者不是队员。替换回营地与交换机撤回都使成员离开当前在场队伍，回营者不参与之后场内全灭。倒下成员的替换资格尚未确定，不沿用旧候选自动排除。

交换机依用户框架保持稀有，送走一名后由三人变两人，失去的是该成员的实际作用。后续补位仍须实际击败合格敌人并触发邀请，不保证补齐人数或原作用。两人恢复路线不依赖装置或成功招募。

替换的行动成本、倒下成员资格、携物、回营整备及是否支持从营地直接调入当前探险仍待设计。新人资源、概率和救援数值也仍为候选；替换不自动恢复其余在场成员。

## 当前可复用证据

[v0.4 走廊账本](../审核版本/2026-10-25-v0.4/走廊入场与操作负担.md)中的三人默认与单次保护路径可以在原输入下复用；其伤害、PP 和回合顺序仍是候选，不代表玩家体验获批。后续只围绕三人继续验证。
