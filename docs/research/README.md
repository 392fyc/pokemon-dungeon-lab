## 项目目录

- [PokéBonk](pokebonk/README.md)：已经上线的浏览器生存类游戏；可研究公开客户端中的招式转换、融合配方，以及版本更新后的修复。
- [Pokémon Arena 2D](pokemon-arena-2d/README.md)：Big Kid Nation 的像素实时竞技场项目；公开 Beta 计划在 2026 年 12 月，当前适合研究素材复用、场地演出、角色投票和宣传节奏。
- [跨项目分析](跨项目/内容生产方法与开发启示.md)：连接来源事实与我们可能采用的方法。这里的建议尚未成为游戏设计决定。

## 当前最有用的结论

PokéBonk 的公开客户端将资料筛选、招式候选、共享攻击原型、参数覆盖和特殊行为分开处理。融合另有资格筛选、配方优先级、分字段强化继承与槽位替换；新融合实例会重新从等级 1 开始，不能简单宣称所有成长等价保留。相关研究已经连接到制作流程。

两个项目都署名使用 SpriteCollab 的部分角色图像资源。Pokémon Arena 2D 的预告还把水域和场地变化作为专题展示，说明角色动作之外的场地、特效和演出同样值得研究；公开资料不足以确认其内部实现。

版本号数量和预告播放量各有明确边界：前者不能直接换算为开发效率，后者不能直接换算为实际玩家或留存。

## 检索与维护

文件名按研究主题保持稳定。各项目的来源文档记录公开链接、核查日期和验证范围；主题文档通过相对链接连接相关证据与比较结论。后续代理先读本索引和当前决策，再按问题进入主题，避免从历史聊天重新猜测范围。

可在本目录运行：rg -n "融合|冷却|范围|场地|更新|待验证" . 。网页、在线人数、版本号和 Beta 计划属于会变化的信息，继续依赖它们时应重新核查原站。
