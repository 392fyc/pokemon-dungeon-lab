# Obsidian 研究库使用说明

本库是 pokemon-dungeon-lab 仓库的 `docs/`（用 Obsidian 打开主 checkout 的 `docs/` 文件夹），用于管理 PokéBonk 和 Big Kid Nation 的 Pokémon Arena 2D 研究以及本作设计。

从 [研究总索引](../README.md) 进入，先阅读[当前创作目标](../90-archive/早期框架/创作目标与地牢研究重点.md)，再结合 [[90-archive/早期框架/项目目标与当前决策]] 查找具体规则。标准 Markdown 链接与 Obsidian 双向链接共同连接笔记；反向链接和关系图可用于追踪结论与来源。

标签按项目和主题分类。事实依据、静态代码观察、分析建议和待决定事项保持区分。当前为初期框架构建，整理用户方向、补充规则、反例和制作流程，尚未开始游戏功能实现。

代理在任务 worktree 中直接读写 UTF-8 Markdown，与相关改动一起提交 PR；合并后 Obsidian 读到主 checkout 的新内容。在 Obsidian 中的直接修改由代理收录到任务分支后提交。不使用 Computer Use 编辑文档。

## 当前审核与路线

整体审核按用户指令延期，当前任务为救援队／肉鸽地牢的核心玩法与个人首版设计。已定规则沿用 v0.5/v0.6，[替换、携物与回营 v0.7](../90-archive/审核版本/v0.7-2026-10-26/审核入口.md)是细则候选。用户裁决与文档检查分别记录。按职责使用[游戏项目路线](../90-archive/早期框架/游戏项目路线.md)或[REA 辅助研究路线](../90-archive/早期框架/REA辅助研究路线.md)。既有主题目录保持位置；新逆向结果单独保存，不移动或复制整库。
