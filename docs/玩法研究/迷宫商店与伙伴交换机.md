# 迷宫商店与伙伴交换机

状态：用户提出在迷宫设置类似变隐龙商店的商店，以及让一名队友提前安全撤回、携少量物资、不能参加后续战斗的伙伴交换机。**用户已明确装置低概率出现，主要保护伙伴防止走失；撤回削弱探索队伍，补位必须再次击败合格敌人并触发概率邀请。** 使用次数、载量、位置、货币规则与存档顺序仍为代理候选。 本轮不实现功能。

用户已明确三人队可当场替换，下场回营地待机；当前满员招募不依赖装置，成员实例与培养保留。交换机继续比较没有招募机会时的主动撤回及少量物资运送，其具体价值须按新规则复核。

本文使用“伙伴交换机”沿用用户称呼，功能暂定为先行撤回，不包含从基地换入队员或召回正在救援的伙伴。具体地图见[迷宫与任务样例](迷宫与任务样例推演.md)，成本见[救援费用与等待次数](救援费用与等待次数推演.md)。

## 普通出口、交换机与商店各解决什么

[替换、携物与回营 v0.7](../审核版本/2026-10-26-v0.7/审核入口.md)继续比较替换不运输物资、首批仅用共用背包的组合。交换机的少量运输因而有明确区别，但不据此宣称它已经有足够的使用价值；本页额度仍未定稿。

| 节点 | 玩家付出的代价 | 本局结果 | 对旧救援池的影响 |
| --- | --- | --- | --- |
| 招募当场替换 | 接纳实际邀请的新人并选择一名成员回营；携物规则待定 | 人员替换后仍为三人，回营者保留个人培养 | 当场不推进，整局结束按成果判断 |
| 整队正常出口 | 放弃本局尚未探索的机会 | 结束本局并结算合法带回内容 | 根据有效条件最多推进一次 |
| 伙伴交换机 | 一名队友离开本局，使用有限运输机会 | 该成员与准入物资安全保存，剩余队伍仍在同一局 | 当场不推进；整局结束再判断 |
| 局内商店 | 花局内资金、卖出物品或放弃购买 | 改变当前队伍补给与背包，不自动带回基地 | 当场不推进 |

“每局统一结算”在这里指基础报酬、最终结果和 L/X 只结算一次。交换机是**显式的局内安全转移事件**，其保存结果必须立即生效；它不能被解释成整局又结束了一次，也不能在后续全灭时撤销已经送回的成员和物资。

## 交换机的首轮候选

| 项目 | 用于本轮推演的规则 | 为什么这样比较 |
| --- | --- | --- |
| 出现信息 | 低概率事件，不按人数、残血或区域保证；探索接近或侦察到后才提示实际位置，候选节点靠近普通出口 | 装置主要保人，正常退出不依赖它；出发界面不把每局是否有装置当可反复筛选的保证 |
| 使用额度 | 优先比较每局至多一个生成机会、出现后只用一次，每次一名成员 | 具体概率与额度仍为候选；跨层、跨段和无尽换区不刷新 |
| 载量 | 最多两份准入物资，每份招式机、单个果实、单件交易物按一份算 | 不把一堆 99 件当一份；两份是试算值 |
| 准入 | 样例先允许普通物品、招式机和明示可出售的交易物；不装其他容器、无限现金堆、任务绑定对象或临时赠送补给 | 携物是保伙伴的附带用途；正式清单未定 |
| 队员资格 | 可以选初始主副、普通成员或已接受的新伙伴；暂要求目标仍能行动、剩余至少一名可行动成员 | 不凭稀有度排除新伙伴；重伤/倒下携出与单人控制规则仍需后续设计 |
| 队长 | 可先把控制交给留队成员；不能把换队长变成初始保护身份转移 | 自由编队与身份保护分别处理 |
| 使用费用 | 首轮比较不额外收现金，主要代价是离队与运输额度 | 避免救援费外再叠固定保护税；不代表代价已足够 |
| 后续资格 | 已撤回成员本局不能再参与、不能远程施加队伍效果；本局结束后按基地规则用于以后探险，不进入救援池、不等待 X | 已安全撤回不再交救援费；成长 B 候选按基地免费整备恢复可出发状态，仍不可本局召回 |
| 补位 | 先击败其他符合条件的非 Boss，再真实触发并接受邀请；空位不增加邀请率、不从基地补人 | 补到人数也未必补到原作用或资源；不能预设马上补齐 |
| 其他资源 | 留队者不回血、不恢复 PP、不发额外工资；未装上的普通物资继续有风险 | 将装置与免费整备分开 |

普通出口与交换机可共用前庭空间，但分别标明“全队撤离”和“队员先行撤回”。不需要额外一场护送、防守战或按现实秒数等待；装置应在已经清楚可交互的安全节点，不作为战斗中随时无敌传送。

两份运输之外，穿戴装备、绑定物和已消耗物不能暗中再带一套。装备体系未定，本轮账本不计装备；以后允许随成员带出的装备要计入明确额度或单列规则，不能留成无上限暗道。

## 伙伴、物资和有效探险的归属

1. 使用时选定**同一个伙伴实例**和确切物品数量，从在场队伍、普通背包或保护袋移出，写为已安全撤回。不能同时在两处拥有同一物品或角色。
2. 已送回者不属于本局之后全灭的走失名单；保留本局参与记录，但走失按失败时仍在场的普通成员判定。送回的新伙伴同样安全。
3. 已送回物资不因后来失败或其他伙伴到期而再丢失；也不在最终结算时重新生成一份。若先从保护袋移出再送回，保护袋空位确实释放，后续新取得的物品仍可放入，但必须计入整体保护能力。
4. 装置当场不发基础报酬，不推进 L/X，不让已付费救援者中途加入。基地中的安全货物先保留，本局结束后再开放正常编队、出售与付款操作，避免一局中穿插基地经营与出发。
5. 新招募伙伴或本局新增物资已安全送回，会使本局最终拥有新增跨局成果；即使目标没完成、后来全灭，也应计一次有效探险，但不自动获得基础报酬。
6. 仅将已有伙伴空手送回、转回带入的旧物或旧钱，不产生新的跨局成果；若没有目标和其他新成果，本局不推进 L/X。
7. 关闭或重开游戏恢复同局及已使用额度。伙伴转移、物品扣除、装置使用记录应保持同一次保存结果，不能靠重载恢复角色、重复运货或刷新库存；这是未来实现检查要求，当前未运行存档程序。

“角色不再参战”不仅指不能主动攻击。其持续支援、共享招式、携带效果等如果以后存在，也须按离队边界处理；成长 B 候选保存个人已学招式、结束该成员的本局临时成长，详见[入队与基地培养](新伙伴入队状态与基地培养.md)；永久等级路线仍需分别定义。

## 商店先让玩家用钱改变当前选择

保留原作地牢商店的直观性，候选先做有限商品：恢复生命、恢复 PP、投掷用品、用途明确的招式机。普通出口与最低路线不要求购买。买卖通过明确报价确认，展示层可使用地面货物或柜台；偷窃、敌对追杀、动态定价不纳入这轮依赖。

- 只使用本局钱袋：出发时主动带入的预算、局内获得的钱和卖货所得。基地救援账户不自动扣款，尚未结算的基础工资也不能提前消费。
- 买到的商品、卖物品所得的钱都处在本局风险中。出售不等于存款；仍需正常撤离或进入明确的保护容器才能安全保留。
- 样例先取普通钱袋在全灭时丢失，且不允许无限现金堆装进交换机；现金、装备与保护袋正式准入仍需统一决定。已送回的合法交易物可在本局结束后按真实出售价格筹钱。
- 库存有限且本局固定，不因关菜单、进出房间、跨段或存档重载刷新；新的探险可以按任务配置生成新库存，不是跨局永久售罄。同一商品即时回售价不高于买价，不通过自己的买卖循环制造净财富；跨店套利暂不作为玩法。
- 出发带来的旧物出售后仅把钱带回，或买回自己刚卖出的同一件旧物，不凭形式变化制造新增成果。本局新发现的物品若出售，其所得在最终保留时仍属于新成果；同一物品与售款不能重复算收益。
- **首次从本局商店实际购入并最终保留的新商品，先按真实的新取得物品纳入有效候选，即使用的是旧钱。** 买回自己卖出的旧物、只来回换钱或把新商品卖掉且没有其他新成果，不凭交易次数触发。这是一项明确的补充候选，尚未实装；若后来实际解锁跨局招式等成长，按最终成长保留规则处理。
- 这一选择允许付出钱和路程、带回新商品的短局推进等待，但没有完成基础目标就不发工资。它不等同于出生后免费送死；也不声称排除了花小钱快速推进 X 的策略。本轮三张图的商店都在基础目标后的节点或后续段，通常已由目标决定有效；以后若前置到目标前，须再比较这种购物短局，不先引入隐蔽门槛或逐枚金币的复杂计价。
- 商店可提示“买后本局可带回现金还差多少救援费”，其中基础报酬资格、局内危险资金与已安全货物必须分别显示；估值不是立即可用余额。

推荐交易节点不附送全队治疗。玩家买一件恢复品是用有限预算换后续能力；[恢复专题](无尽迷宫恢复与局内成长.md)的休整是另一种明确的一次性操作，生命与 PP 二选一，不附属于普通出口或购买动作。库存不因等待、离开再回来或重新载入刷新。

## 保人、缺员与携物怎样一起评估

### 少一名伙伴之后还能否继续

当前先比较保护重要伙伴与失去其战斗、支援和探索作用的关系。装置本身稀有，送回后也可能一直没有新邀请；即便招到新人，射程、招式、状态与资源也未必能替代原成员。具体人数和概率例子见[队伍人数与满员招募](队伍人数与满员招募.md)。

只有在实际遇到装置、送回影响较小的成员、又成功击败敌人并触发合适邀请等条件共同成立时，才讨论这条路径的代价是否偏低。这里不能预设“随时找一个替补”或把装置当常规货运线路。主目标是让玩家有机会保住伙伴，少量携物仍需与保护袋一起观察，但不先增加运输税或强迫出场门槛。

### 商店把大包战利品压缩成一个安全贵重品

把多件普通战利品出售，再买一张高价招式机放入保护袋或装置，两份运输仍可能承载大部分价值。禁止装现金不能自动阻止这种转换。

候选限制有限库存、没有凭空利润的来回买卖，并分开记录消费与安全保存；仍必须测量**被保护的价值**，不能仅凭两份物品宣布风险得到保留。不因物品刚从商店购买就临时剥夺保护资格，否则会破坏规则可读性。

## 一个战力与保护的算术对照

以下只在本局已经实际遇到装置的条件下，沿用[撤离收益公式](撤离点与深入探索收益.md)：Δ = sG − (1−s)(V+D) − k。V 为继续后仍可能损失的当前物资价值，G 为成功到下一出口新增收益，s 为假定成功率，D 为失败条件下的预期救援费，k 为额外消耗。相对基准是此刻整队撤离。

| 情况 | 假设 | 继续相对整队撤离的货币变化 |
| --- | --- | --- |
| 留全队 | s=0.8、V=200、G=120、D=60、k=10 | +34 |
| 送走有用队员和价值 80 的货物 | s=0.65、V=120、G=120、D=40、k=10 | +12 |
| 送走几乎不影响战斗的队员和同样货物 | s=0.8，其他同上一行 | +54 |

送回物资已安全保存，V 相应减少；送回成员不再需要本次救援，D 可以降低，但少一名有用队员可能降低 s。例子里的概率、价格、同样的 G 和 D 都是人为假设，未测任何实际队伍。它只说明装置可能改变取舍，也可能成为明显优势；忽略情感价值、伙伴等待与后续招募的公式不能代替体验判断。

## 无尽模式中的稀有性

[无尽迷宫](无尽迷宫分区与守关规则.md)比较每次出发至多一个生成机会，先决定本局是否有，再安排安全节点位置。每区独立低概率在很长局里仍会接近必遇，因此不能把它与整局低概率混为一谈。具体模型仍是候选，普通出口始终保留。

招募替换回营与装置撤回均保留成员实例及培养。替换时的携物尚未确定，不能把装置的少量物资运输额度自动套用到替换；交换机仍按没有招募机会时主动撤回的场景继续评估。见[当场替换方向](队伍人数与满员招募.md)。
