# 八款参考游戏的发布与维护经验

> 固定来源：392fyc/pokemon-game-research@5f3547889b30e59f6cdfebc5af8c91e46cba4ee4。本副本保留原文的研究阶段身份；2026-10-29用户已批准按准备包开始阶段3—4并采用Vite，当前授权以[执行入口](../README.md)为准。本文件为派生副本，库外链接已固定到同一来源提交；源与目标摘要见来源清单。

本报告的发布来源仅为用户列出的八款游戏。REA-research-lab 分析主会话提供的既有入口摘录及 PokéBonk 固定发布包，主会话核对关键片段后整合。本轮没有新请求七个受限站点、执行目标脚本、实际试玩、登录账号或修改云环境。

本作当前采用 Phaser＋TypeScript，以网页作为开发验证载体；Windows Electron 沿用已选封装路线，但是否首发仍未定。这些参考只能帮助设计玩家入口、更新与恢复流程，不能替代本作运行验收。

## 三条可追溯的路径

### PokéBonk：资源身份、协议与结算恢复

旧包通过动态导入加载游戏，按资源表生成 URL；HTTP 请求携带客户端协议标识，开局取得票据，之后提交 checkpoint，结算先写入本地待提交队列，再发送或重试。

B02 定位资源版本表；B18 定位 `X-Client:2` 与服务器 `update` 标记回调；B19–B20 定位开局 key、checkpoint、`pb.pending` 最近五项及重试处理。B21 的构筑计划不是完整战斗存档，B22 的默认字段补齐也不证明任意旧档迁移。服务端是否保证重复请求只结算一次，不能单凭客户端代码认定。

这提示本作应明确“保存了哪些状态、何时保存、失败时怎样告知”。个人首版不需要因此复制账号、票据和云结算服务。实际构建命令、部署平台、缓存响应头与回滚流程仍不可见。

### PokéCatch：加载失败后给出下一步

H8 可直接追踪：正式入口 → 尝试注册同源 Service Worker → 加载外部 boot → 脚本加载错误调用 `BOOT_FAIL` → 显示本地化错误和重试按钮 → 刷新页面。处理还避免重复插入错误框，并容忍语言偏好读取失败。

证据只覆盖这条外部脚本加载失败路径，不保证捕获脚本内部异常或所有子资源故障。保持正式入口、将资源单独发布的说明出自 HTML 注释，尚未以平台配置验证。本作可以借鉴清楚的失败提示，无需引入双站托管或资源转发。

### FighterZ：首次进入与资料恢复分开

H6 L53 检查返回登录标记和本地／会话资料，设置等待状态；L182–188 定义游客入口，L52 设置 12 秒后移除启动遮罩。由此能追踪界面分支，不能把解除遮罩视为登录完成或成功开局。

本作可以区分“首次开始”“继续当前探险”“恢复失败”，避免重复让玩家创建内容。名字、头像、第三方账号与在线房间并非单机地牢试玩的必要前置。

## 对个人首版的建议

下表为主会话整合的本作候选，功能存在不能证明参考游戏因此提高了留存。

| 事项 | 本作建议 | 来源与理由 |
| --- | --- | --- |
| 首次进入 | 一个稳定链接；开始新探索，有可恢复记录时显示继续；基本操作随首次探索介绍 | Kanto 的直接浏览器说明、FighterZ 的首次／返回区分；减少体验前的额外输入 |
| 加载 | 区分加载中、失败、可重试；不把超时解除当成功 | PokéCatch 错误分支与 FighterZ 等待状态；让玩家知道下一步 |
| 版本 | 菜单显示可复制构建号与简短更新记录，说明存档兼容影响 | PokéBonk 版本身份、Kanto 更新入口；帮助定位玩家遇到的版本 |
| 资源 | 每次发布的入口与资源引用一致；保留上一版材料，检查旧页面刷新行为 | PokéBonk 资源表；不因看到 manifest 就加入离线缓存 |
| 保存 | 完整首版支持明确的完整轮末中断恢复；接受邀请、替换和终局也有一致保存边界；恢复同一局和已抽取结果 | 伙伴替换与随机探险自身的设计需求，结合参考作品恢复边界教训。不是声称八站均如此实现 |
| 保存失败 | 写入失败要可见；未知格式先保留原档，避免直接覆盖；若提供导出导入，需检验格式与损坏提示 | 本作的有限本地保存方案，不依赖账号、云同步或服务器补偿 |
| 反馈 | 一个入口，提供构建、运行环境、阶段、复现步骤及已有地图种子；不默认收集整份存档 | Kanto 的联系入口提供前台参考；具体记录项由本作问题复现需要推导 |

首个可玩片段可以先只在终局保存，并明确该限制；完整首版若仍只能结束后保存，就不能宣称解决了地牢中断负担。发布取舍与[核心玩法及首版范围](https://github.com/392fyc/pokemon-game-research/blob/5f3547889b30e59f6cdfebc5af8c91e46cba4ee4/%E7%8E%A9%E6%B3%95%E7%A0%94%E7%A9%B6/%E6%A0%B8%E5%BF%83%E7%8E%A9%E6%B3%95%E4%B8%8E%E9%A6%96%E7%89%88%E8%8C%83%E5%9B%B4.md)使用同一份保存承诺。

首版后置：第三方登录、云存档、跨设备同步、多人房间、排行、在线结算补偿、PWA 离线缓存、双站资源转发和自动更新服务。Windows 封装另检资源路径、存档目录、离线依赖、安装与升级后保留数据；八站资料没有提供本作可用的 Windows 安装包证据。
