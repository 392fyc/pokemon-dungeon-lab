## 已知问题

- **地形图块是原版素材**：私有构建默认用 PMDCollab 提取的原版迷宫图集，没有授权文字；公开发布前必须换成升级后的程序画师（D-20261103-12）。
- **换层生成变慢**：#178 的生成约束让单层生成平均约 20 ms（原约 6.6 ms），单独运行最大约 0.2 s，并行负载下最大约 0.4 s，换层时可能有一次轻微卡顿。
- **走廊转弯比统计的少**（#200）：生成路线时把原地掉头也算成转弯。600 个种子 × 5 层实测，30967 条路线里 23431 条有这种来回；抽样 600 层去掉假转弯后，真有转弯的路线约 24%（1517/6225）。`tests/core/terrain-85b.test.mjs` 的“至少一半走廊有转弯”是靠假转弯通过的。真修要改地图生成，已有种子的地图会变，等用户决定。
- **平衡暂缓**（D-20261104-01）：#168 暂停，首领 HP 倍率保持 4。2e3e226 上 tactical 普通档击败首领 46.1%（115 局，低于目标 50—65%），倍率 3.0 实测 59.1%；完整数据见 [#168 评论](https://github.com/392fyc/pokemon-dungeon-lab/issues/168#issuecomment-6609210592)。
- **天赋内容待重做**：现有三项继续生效，内容以后由用户和 main 一起重做，见 [#201](https://github.com/392fyc/pokemon-dungeon-lab/issues/201)。

- 平衡只用机器人测过（四种打法，见“8.6 校准长测”），没有真人数据；8.6 校准后普通档谨慎打法的进化率 84.3%。
- **困难档打不过首领**：8.6 校准后困难 tactical 115 局 0 胜，只有 67 局到达首领层。三档对首领用同一倍率是用户决定（D-20261101-01）；困难档要不要调（例如降低困难档倍率），交用户在 8.7 试玩时决定。
- **长测性能**：8.2 大地图上长测耗时约为 8.1 的 4.6 倍；#128（PR #130）优化寻路后约减少 34%。剩下的主要开销是每条命令的整局状态复制（`structuredClone`），暂未处理。单轮游戏响应估计仍是毫秒级，没有实测。
- 结算画面在 v0.1 只有“收获型奖励”有内容；深度和难度奖励自 8.5 起列出探险队经验；营地任务奖励写“本局无此项奖励”，等 v0.2 填入。
- 开发者模式可用网址参数 `?dev=1`、`?fixture=` 打开（浏览器检查需要），私有构建保留；公开发布前要处理。
