# REA 后续七站研究的网络访问补充方案

状态：仅完成只读准备，尚未更改配置、重新发布或请求受限站点。用途是继续[管线研究](../REA辅助研究/参考项目—制作与发布管线—2026-10-27.md)中尚未覆盖的七站。

REA 当前运行环境的域名策略由平台强制执行。自动审批拒绝了包含未许可站点的网络申请，理由是不能以额外命令执行权限绕过域名策略。之后的研究只采集许可来源和已有样本；该限制不能通过修改容器内 network-policy.json 解除。

## 最小拟议变更

保持 restricted 模式与现有许可，仅追加以下八个精确 HTTP(S) 主机名，不添加通配符：

```text
einoow.com
pokemonroyale.com
poketide.com
chapas.fun
dragonballtft.online
underground-survivors-jsetmq.rive.to
pokecatch-online.netlify.app
pokecatch-online.pages.dev
```

最后一项是已观察到的 PokéCatch 外部 boot.js 入口。其他重定向、资源 CDN 和嵌入服务尚未核实，不预先扩大许可。不涉及 VPN、TCP 目的地址或凭据变更。
