# 8.9 招式与道具对齐原版规格

## 1. 为什么做

用户 2026-11-04 决定：平衡暂缓（#168 暂停），先把内容做起来；“先把招式和道具稳定，这两个更接近原版内容，不太需要我的创意发挥”。祝福与天赋属于需要用户创意的部分（D-20261030-13），不在本规格。

“对齐原版”的意思：招式与道具的种类、效果按《不可思议的迷宫》探险队系列（以时／暗／空之探险队为主，现行优先级见 `src/data/pmd-moves.json` 的 `gamePriority`）实现；数值换算到本作的尺度（本作 HP、伤害公式与原版不同，见游戏规则 G5）。不引入本作没有的大系统（饱腹度、持有物、天气、陷阱、IQ）。

## 3. 分两步

### 3.1 第一步（8.9a）：不加新规则系统，但要新增效果分支

只用现行的阶段（G5.5，−3…＋3）、异常（G5.13）、伤害与命中规则，不改这些规则本身。但引擎要新增下列分支（`executeSkill`，`src/core/engine.ts` 约 1040—1110 行；可复用 `applyStatus` 与 `applyStageChange`），导入脚本要新增对应模板：

| 项 | 准入范围 | 效果 | 需要的新代码 |
| --- | --- | --- | --- |
| A1 降对方能力 | 只降对方攻、防、特攻、特防、命中、闪避的变化招式（叫声、瞪眼、刺耳声、撒娇、假哭、泼沙等）；只降速度的（鬼面等）不准入 | 对目标照原版级数降阶段，先过命中判定 | 现在附加效果只在招式带伤害时运行（约第 1091 行），要给纯变化招式另写一条分派；守住、快速防守的挡下判断照第 1092 行 |
| A2 升自身能力 | 只升攻、防、特攻、特防、命中、闪避（可多项）的变化招式（瞬间失忆、诡计、冥想、影子分身等）；含速度的多项招式忽略速度部分（龙之舞只升攻击）；破壳（有升有降）、充电（附带下次加强）、生长（随天气）不准入 | 照原版级数 | 现在只解析 `stage:(atk|def)`（约第 1058 行），导入脚本只收攻防两项（约第 546 行），都要放开 |
| A3 施加异常 | 中毒、剧毒、灼伤、麻痹、混乱的变化招式（剧毒、电磁波、鬼火、奇异之光、超音波、毒粉等）；虚张声势、吹捧（同时提升对方能力）与摇晃舞（多目标）不准入 | 先过命中判定；异常照 G5.13。本作没有属性相性（伤害公式 G5.3 也没有），所以变化招式对任何属性都有效；属性相性列为第二步 B10 | 同 A1 的新分派 |
| A4 反作用 | 猛撞、舍身冲撞、疯狂伏特、闪焰冲锋、勇鸟猛攻等 | 使用者受到本次造成伤害的固定比例（照 Showdown `recoil`），至少 1；没造成伤害就不受 | 新分支，放在伤害结算之后 |
| A7 回复 | 自我再生、光合作用、偷懒、生蛋 | 回复自身最大 HP 的一半（四舍五入，不超过上限）；生蛋例外，照原版 `room/party` 回复房间内全队各自最大 HP 的一半；光合作用不随天气变化；睡觉不在第一步 | 新分支 |

**初始招式不变，新招式经招式机获得**（用户 2026-11-04 决定）：导入脚本的初始招式（`kit`）只从原有准入范围里选，第一步新准入的变化招式不进初始招式，只进可学招式（`learnable`）。为了让新招式在游戏里拿得到，招式机池（G9.3，现为九种）扩充为：现有九种 ＋ 第一步准入招式中原版《空之探险队》也有招式机的那些（由 dev 按 Bulbapedia 的空之探险队招式机清单取数列出，预期包括剧毒、冥想、健美、鬼火、电磁波等，待核对）。抽招式机时仍只给能学这一招的伙伴使用（现行规则）。招式机池变化影响存档里的池版本（`tmPoolVersion`），与道具一起走版本号流程。PR 附 175 种初始招式比对（应为 0 变化）和新的招式机池清单。

**自动选招（G4.6）**：伤害组合仍然优先。没有可用伤害组合时，依次考虑：A3（目标当前没有该异常）→ A1（目标该阶段未到 −3）→ A7（自身 HP 不到一半）→ A2（自身该阶段未到 ＋3）→ 现有的守住、变圆／变硬等。也就是说，这些招式主要在“打不到对方”时才会用；敌人照同一规则（D-20261030-18）。是否让 AI 更积极地用变化招式，留给平衡恢复后再定。

每招在 `move-effects.json` 记来源（Showdown 字段或 Bulbapedia 探险队行）。

#### 原版效果的取舍

按现行作品优先级选择效果：时／暗／空之探险队优先，再按导入器登记的后作顺序取数。首选作品能直接对应本作六种能力阶段时照用；效果依赖本作没有的系统，或使用独立于阶段的倍率时，依次看后作。都不能对应时，取固定 Showdown 数据的阶段级数。逐招例外写入 `tools/data/moves-items-191-sources.json` 并随效果数据生成。（[main 规格解释](https://github.com/392fyc/pokemon-dungeon-lab/issues/191#issuecomment-6622895284)）

| 招式 | 本作采用的效果 | 依据或例外 |
| --- | --- | --- |
| 刺耳声 | 防御 −2 | 原版是独立防御倍率，本作取 Showdown 阶段 |
| 撒娇 | 攻击 −2 | 原版是独立攻击倍率，本作取 Showdown 阶段 |
| 变小 | 闪避 ＋1 | 探险队级数，覆盖现代主系列的 ＋2 |
| 甜甜香气 | 闪避 −1 | 探险队级数，覆盖现代主系列的 −2 |
| 金属音 | 特防 −3 | 探险队级数，覆盖后作与现代主系列的 −2 |
| 烟幕 | 命中 −1 | 效果取超不可思议的迷宫；探险队的“必定落空”状态不进入本作。PP、命中率和射程保留所选原版行 |
| 生蛋 | 同房间全队回复各自最大 HP 一半 | 沿用原版 `room/party`；四舍五入并封顶 |

新增招式机六种：冥想（TM04）、剧毒（TM06）、健美（TM08）、鬼火（TM61）、电磁波（TM73）、剑舞（TM75）。与原有九种合成十五种池；[空之探险队招式机表](https://bulbapedia.bulbagarden.net/wiki/List_of_TM_and_HM_locations_in_the_Pok%C3%A9mon_Mystery_Dungeon_series#Explorers_of_Time,_Darkness,_and_Sky)中的影子分身已改为珠子，因此不加入本轮招式机池。

## 4. 不做

- 不改“最多带 2 招”（D-20261030-44）、天气、陷阱、场地、饱腹度、持有物、IQ、珠子 Orb。
- 不做平衡：数值按原版换算后直接用；长测只报告，不作门槛。平衡留给 #168 恢复后统一调。
- 祝福、天赋不在本规格（需要用户创意，D-20261030-13）。

## 5. 验收

- 导入脚本输出新的准入／排除清单；175 种初始招式与现行相同；新增准入的每招都有来源字段；新的招式机池清单附每招在空之探险队招式机表中的来源。
- 每个新分支至少一条规则测试：命中与未命中、阶段到上下限、目标已有该异常、被守住挡下、对首领、敌人使用；反作用在未造成伤害时不扣 HP；回复不超过上限。
- 自动选招测试：没有伤害组合时按 3.1 的顺序选中，条件不满足时不选；有伤害组合时仍选伤害。
- 新道具：道具房获得、使用、换层、存档往返；旧存档读入。
- 全套检查（check、build、单元、验收、浏览器）与 600 局长测 0 超时。
- KB：同一 PR 更新游戏规则 G3.10、G4.6、G5.1、G9.3（招式机池）、G9.10（挑战奖励里的招式机池）（不再写“没有招式改变闪避”）、G5.5（stage 招式不再只改攻防）、G5.13（变化类异常招式）、G9.1（含“大树果与全员 PP 补剂来自道具房和挑战奖励”一句补上新道具），以及实现备注；由 main 在合并前补到 dev 的 PR 里。
