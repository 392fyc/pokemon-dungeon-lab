# 核心循环与撤离规则

当前规则以[核心玩法与首版范围](核心玩法与首版范围.md)为准。本页是框架背景：首版同行上限已定三人；首版地图当前候选可返回G，单向推进仅作对照，尚未成为用户裁决。

当前为初期框架研究。行动推进回合、未付费期限按后续有效探险计数，以及等级解锁高风险高收益任务并由玩家选择的关系已明确；用户允许有效探险与收入方案 B 作为候选继续研究。详细规则以[救援框架](伙伴招募与委托救援框架.md)为入口，不把候选数值视为定稿。

## 一次冒险与跨局循环

在基地从可用伙伴中自由编队，接取救援队等级允许的任务，准备补给与少量物资保护空间，进入随机地牢。初始主控和副手可以留在基地，不是出发必选项。当前建议把基础目标放入普通任务前段，使招募、收集和恢复尽量同局进行；另保留零资产二人能完成的最低风险配置。

探索中通过战斗获得招募机会、招式机与特殊物品；利用位置、射程、伙伴配合和资源决定继续还是撤离。用户提出局内商店和低概率出现的伙伴交换机：可花局内资源补给，或用稀有装置保住一名队友并附带少量物资，剩余队伍少一份战力；补位必须经过后续真实战斗与概率邀请。成功整队撤离带回其余收获，供后续冒险使用。

全灭按当前提案损失大部分物资，少数受保护物品保留；仍在场的普通伙伴判定是否走失，初始二人和交换机已安全撤回者不走失。未付费走失者有 L 次有效探险的期限，付款后转为固定 X 次等待且必定返回。玩家用其他可用伙伴继续冒险，推进旧伙伴的计数；普通伙伴全失时仍可用初始二人出发。

后续全灭不对救援池伙伴重复判走失，不取消已付款救援；符合有效条件的探险只按正常规则推进一次。离线和停留基地不推进时钟。有效判定、到期付款顺序和基础收入细则仍属候选；当前推荐按公开目标取得基础报酬，目标完成或保留新跨局成果才计一次有效，见[有效探险与基础收入](有效探险与基础收入.md)。

## 行动推进回合

玩家行动后世界推进，停下来即可思考。具体行动代价、速度和顺序仍待裁决；[v0.3 伙伴控制与代表房间](../审核版本/2026-10-25-v0.3/伙伴控制与代表房间推演.md)用一名常规控制加可选伙伴指令、固定我方队列先行动作为纸面对照。每人一次行动与不使用速度差异仅是该对照输入，不能据此认定正式战斗永远同速同次数。[v0.4 走廊入场](../审核版本/2026-10-25-v0.4/走廊入场与操作负担.md)进一步计入队列、让路和展开成本，比较默认与每回合最多改一名伙伴，并将点位优化限制为省重复输入、保留真实回合成本。动画可以连续播放，判定与演出分别组织。

重复移动与简单遭遇的时长需要关注。安全区域连续移动、快速演出或操作辅助可评估；救助队 DX 官方自动移动在敌人接近时停止，提供局部参考。[官方玩法](https://mysterydungeon.pokemon.com/en-us/gameplay/)

## 撤离应让玩家作什么选择

关键局面：找到一张稀有招式机并接受了一名新伙伴，补给已经不足。玩家可以把招式机放入有限保护空间，但新伙伴仍面临全灭走失风险，普通背包的额外收获也未受保护；继续与撤离应各有理由。

首版地图当前候选在基础目标附近提供正常出口，继续后可沿原路返回G，旧层敌人、目标与物品状态保留，不自动恢复。单向推进只作对照候选，若未来采用须另行选择并明确提示，不能关闭当前承诺可返回的出口。普通出口不附送存货、回血、补给或额外救援计数，见[撤离点与深入探索收益](撤离点与深入探索收益.md)。[交换机](迷宫商店与伙伴交换机.md)保留为服务点对照，不是招募替换的前置；本次不决定其首版去留。菜单中止仍按候选失败规则处理；关闭游戏恢复原局，不等于撤离。

成功带出的伙伴、招式机与特殊物品应增加后续选择。[成长专题](新伙伴入队状态与基地培养.md)优先比较本局共享等级、个人永久招式库：新人立即发挥基础作用，老伙伴保留配招投入；永久个体等级仍作对照。临时等级不作为跨局成果，真正保留的新伙伴、招式机和最终选定的永久成长才按有效探险规则处理。

## 队伍与迷宫分工的当前候选

[队伍人数](队伍人数与满员招募.md)按首版三人队范围研究，初始二人恢复保留。已明确可当场替换、下场回营地待机；当前满员招募接纳新人后仍保持三人，回营者保留个人培养。招募仍须实际触发邀请，携物和营地直接调入等细则另行设计。

[迷宫分工](伙伴探索价值与迷宫分工.md)保留招式与材料方向，按实际用途分批展开；伙伴通过射程、保护、控制等改变路线。Z 晶与 Mega 延后。[无尽迷宫](无尽迷宫分区与守关规则.md)先用两个区域比较连续探索；Boss 阻挡下一区域，战前可撤离，换区不恢复、不增员、不额外计数。[恢复候选](无尽迷宫恢复与局内成长.md)使用有限物品和明确的一次性休整，不由普通出口自动治疗。

## 等级、保护物资与救援期限怎样配合

救援队等级提高后开放更危险、收益更高的任务，玩家可选择承担相应风险，也可继续低风险任务或在局内安全撤离。救援费用随对应产出配套增长，以占比可承受、扣除损耗后仍有成长吸引力为目标。该关系已由用户明确，具体数值与衡量方法见[救援队等级与失败成本](救援队等级与失败成本.md)。

少量保护物资能使失败仍有收获，但也可能让“装满保护袋后快速全灭”比正常撤离更划算。基础收入与救援计数还会叠加这个动机。必须用完整时间、收益、伙伴损失与付款期限比较，不能仅凭规则名字宣称平衡。

## 已有研究怎样参与

PokéBonk 提供共用招式行为、参数覆盖、强化与有限配方的组织经验；Arena 2D 提供角色、地形层次和演出参考。招式融合仍未决定采用。公开资料不能直接证明本作完整循环成立。

主控御三家池与首批普通伙伴名单分开整理；用能力覆盖、进化线与素材完成度估算制作范围。首版同行上限已定三人，局内不增加第四人；物种和名单数量仍作预算。

## 当前研究顺序

按[分阶段范围](../项目框架/分阶段范围与扩展顺序.md)，先让一次普通冒险完成招募、成长、资源选择、撤离与基地配招，再研究连续区域的恢复和变化；不把大型扩展或多套材料链设为首批前置。

沿用户允许的 B 候选继续研究。[基础勘探任务与单局节奏](基础勘探任务与单局节奏.md)提出最低路线 3–5 分钟、普通两段 12–20 分钟的待测区间，分钟数不是倒计时或有效门槛；固定按局等待会让短局恢复更快，需一起比较费用与 X 的负担。当前已用[三组迷宫样例](迷宫与任务样例推演.md)细化目标选择、服务点与深入收益，并用[费用与等待对照](救援费用与等待次数推演.md)比较恢复负担。后续围绕代表队伍与实际内容继续核对，不因每个局部数值频繁停下询问。用[案例与风险验证](救援机制案例与风险验证.md)中的零资产、连续全灭、多人到期与快速失败局面比较。

按[研究与制作运行方式](../项目框架/研究与制作运行方式.md)复用资料并检查实质反例；当前只更新 Obsidian 研究，不开始游戏功能开发。
