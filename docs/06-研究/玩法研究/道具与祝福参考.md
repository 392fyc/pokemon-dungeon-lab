# 道具与祝福参考

这页说明本作道具和祝福（#213）参考了什么。用户要求基础系统照成熟做法来，不凭感觉改。

## 结论

- **道具**：照探险队系列的做法。解异常的果子同时回血；加入能改变局势的宝珠；加入自动救命的复活种子。
- **祝福**：14 条，取自 PokéBonk 的祝福和遗物，按本作的回合制改写。

## 来源和可信度

| 内容 | 来源 | 可信度 |
| --- | --- | --- |
| 宝珠、种子、树果 | [Mystery Dungeon Wiki：Wonder Orbs](https://mysterydungeonwiki.com/wiki/Explorers_TD:List_of_Wonder_Orbs)、[Seeds](https://mysterydungeonwiki.com/wiki/Explorers_of_Sky:List_of_Seeds)、[Berries](https://mysterydungeonwiki.com/wiki/Explorers_of_Sky:List_of_Berries) | 粉丝维基，二手。Bulbapedia 访问被拒，52poke 没有查 |
| 22 种祝福、32 件遗物 | PokéBonk 0.9.15 客户端源码，见[局内成长与局外养成](../参考项目/pokebonk/局内成长与局外养成.md) | 源码，没有运行观察 |
| 奖励的稀有度与保底 | Slay the Spire 的社区维基摘要、GDC 2019 报道 | 二手。“每次选择该改变打法还是只加数值”没有找到维护方的明确说法，这里不下结论 |

## 为什么旧内容弱

本作 Lv5 伙伴的最大 HP 多在 18—31，Lv20 约 39。以下是手算，不是长测结果。

- 橙橙果固定回 8 HP：HP 24 时占 33%，HP 39 时只占 21%。
- 换层回复 3 HP：只占最大 HP 的 8%—13%。
- 樱子果：麻痹只有 2—3 轮，用果子要占一次行动，几乎等于等它自己结束。
- 地上物品原来 65% 是解异常的果子，只有 35% 回血。

## 采用的内容

**道具**

| 道具 | 效果 | 参考 |
| --- | --- | --- |
| 橙橙果 | 回复 max(8, 最大 HP 的 30%) | 现有，改成随 HP 缩放 |
| 桃桃果、莓莓果、樱子果 | 解异常并回 4 HP | Berries：原版解异常时也回 HP |
| 睡眠宝珠、慌乱宝珠 | 同房间敌人睡着或混乱 | Slumber Orb、Totter Orb |
| 发光宝珠 | 显示本层全部地形 | Luminous Orb |
| 邀回宝珠 | 把同行拉到身边 | Rollcall Orb |
| 复活种子 | 倒下时自动消耗，以 50% HP 站起 | Reviver Seed；原版要 IQ 技能才生效，这里不要 |

**祝福**

| 祝福 | 效果 | 参考 |
| --- | --- | --- |
| 树果加量 | 橙橙果回复 ＋50% | 现有，改成比例 |
| 换层回复 | 进入新层回最大 HP 的 20%，至少 4 | 现有，改成比例 |
| 战意、号召 | 不变 | 现有 |
| 选机 | 立即三选一一张招式机 | 现有，改成当场生效 |
| 安眠 | 之后每层敌人出生睡着 40% | 现有，扩大范围 |
| 克星 | 对有异常的敌人伤害 ＋10% | 遗物余烬 |
| 猎首 | 对首领伤害 ＋15% | 祝福“对精英和首领伤害” |
| 满血爆发 | HP 高于 80% 时伤害 ＋8% | 遗物琥珀滴 |
| 学者 | 全队经验 ＋15% | 祝福“经验” |
| 击倒回复 | 打倒敌人回 8% 最大 HP，至少 1 | 祝福“吸血”；本作伤害小，改成按击倒 |
| 再生 | 每 10 轮全队回 max(1, 最大 HP 的 1/20) | 祝福“回复” |
| 厚皮 | 每层每人第一次受伤减半 | 遗物石鳞 |
| 背水 | 每层第一次 HP 低于 35% 时回 25% | 遗物花岗岩之心；本作没有护盾，改成回复 |

## 没有采用

饱腹度、陷阱、IQ、天气类道具依赖本作没有的系统。持有物栏、投掷物、祝福稀有度要新系统，这次没做。
