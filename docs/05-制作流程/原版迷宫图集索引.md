# 原版迷宫图集索引

本页是 PMDCollab RawAsset 仓库 `TileDtef` 目录的文字索引，方便按主题挑选地形图集（[#178](https://github.com/392fyc/pokemon-dungeon-lab/issues/178)）。图集本身不进仓库，快照在被忽略的 `.artifacts/rawasset/RawAsset/TileDtef/`，版本与校验值见[数据快照登记](数据快照登记.md)。

## 使用限制

- 这些是从原版《宝可梦不可思议的迷宫》系列提取的图块，权利属 Spike Chunsoft、任天堂等。RawAsset 仓库没有 README 和 LICENSE，没有任何授权文字。
- 只用于私有构建（D-20261103-12）；公开发布前必须换成本作原创或许可明确的图集（[8.8地形重做方案](../02-进度/计划/8.8地形重做方案.md)第 5 节选项 B）。
- 文件只当图片数据读取。

## 格式

- 每套一个目录，`tileset_0.png` 为 432×192，横向依次是墙、第二地形、地面三段，每段 6×8 格、24 像素（DTEF 排布，见 SkyTemple `skytemple-dtef` 的 `docs/format.rst`）；每段第 3 行最右一格空着（WaterfallCave、MagmaCavern2 两套看图核实）。
- `tileset_1.png`、`tileset_2.png` 等是其他变体；按 DTEF 规范，空图块表示沿用上一个变体。`tileset_more.png`（432×24）是额外图块。
- 动画帧命名为 `tileset_<变体>_frame<层>_<帧>.<时长>.png`，时长以 1/60 秒计。依据：PMDO 维基 Modding Tilesets（https://wiki.pmdo.pmdcollab.org/Modding_Tilesets）给出同样的命名；[PDMN 源码解析](../06-研究/参考项目/跨项目/PDMN—场景渲染与界面源码解析—2026-11-02.md)记小小森林每帧 9 刻，与 TinyWoods 帧文件名后缀 `.9` 一致。目录里没有 DTEF 标准的 `tileset.dtef.xml`。

## 各列含义

- **三段**：`tileset_0.png` 的墙、第二地形、地面三段是否都有九成以上的像素不透明（脚本推断）。“不齐”的多是只含一类的分包（名字带 Floor、Wall、Secondary），或第二地形本身透明（虚空、深渊类）。
- **变体**：`tileset_N.png` 的个数。
- **动画**：哪个变体有几层动画。
- **第二地形色系**：第二地形一段不透明像素的平均颜色归类（脚本推断，不等于实际是水还是岩浆，挑选时以图为准）。
