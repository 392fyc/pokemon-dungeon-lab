# 成长与普通单局专项审核 v0.2

状态：代理候选，待用户审核。日期：2026-10-25。本版完成一项相互关联的议题：新人即时用途、老伙伴培养、普通一局和失败后的恢复。没有开始游戏功能开发。

## 本版怎样阅读

1. 阅读[成长与普通单局推演](成长与普通单局推演.md)，比较两种成长路线，再看同一张迷宫和失败账本。
2. 在[审核记录](审核记录.md)区分用户裁决、接收核验、独立审查和仍缺的体验证据。
3. 需要其他框架时返回[v0.1 完整基线](../2026-10-25-v0.1/游戏框架与候选决策.md)。本版是专项续版，不重做 REA 范围或扩展系统。

v0.1 正文保留。讨论本次议题时，以 v0.1 为共同背景，再使用本版明确列出的建议；两个版本的互斥候选不能同时执行。尚未被用户选择的建议不会成为现行规格。

## 本版建议和 v0.1 的关系

| 事项 | v0.2 当前建议 | 与 v0.1 的关系 |
| --- | --- | --- |
| 成长 | 优先继续共享本局等级＋个人永久招式库；永久个体等级完整保留为对照 | 延续研究优先级，补上经验与救援时钟的交互；尚未选定 |
| 人数 | 最多三名出发、局内四名；固定四名为主要对照 | 人数候选未变，强调无邀请时也能正常探索 |
| 满员 | 首批优先只拒绝，不开放放归后换新人 | 从 v0.1 的可放归补充候选收束；放归保留为对照，不与本版主例混用 |
| 代表迷宫 | 苔溪浅谷收束成基础前段＋一个可选深入段，最低恢复配置只走前段 | 从三张多段纸面样例缩成一张可判断的普通循环；其他样例仍作参考 |
| 培养 | 一条能看到用途的招式机学习与下次配招路径 | 延续原候选，增加同种未培养伙伴的对照，防止只靠第四招总 PP 宣称培养有价值 |
| 收入和救援 | 沿目标报酬、成果判有效、统一终局结算；示例 R=100、C=60、L=4、X=1 | 规则顺序与费用均未获批；补充目标前有成果但没钱的反例 |
| 恢复与撤离 | 有限恢复、普通出口；交换机仅作为确实遇见时的额外分支 | 保留原候选，普通循环不依赖稀有装置、随机邀请或补位 |

## 这次需要判断的真实取舍

- 是否愿意让长期培养主要积累可选配招，而不是永久等级带来的直接数值优势？如果更看重练到高等级的积累感，就应选择永久等级路线并一起处理失败经验与救援计数。
- 是否接受首批满员时放弃后续邀请，以避免反复换新人补资源？固定四人出发也可以主动留空位，但不能既满编老队伍，又无代价带走每份邀请。
- 付费后至少还要完成一次有效探险，可能仍是玩家只为等伙伴而开的局。短等待和顺路探索只能减轻这项负担，不能证明已消除重复劳动。

具体生命、PP、费用、次数、房间和物种仍是纸面输入。当前完成的是方案比较与状态推演；战斗行动顺序、伙伴控制和代表房间尚未确定，不能据此宣布新人实际好用、培养值得或恢复体验已通过。
