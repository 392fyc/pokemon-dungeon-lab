# 阶段7.5 网页构建与存档自测

本记录对应 [issue #33](https://github.com/392fyc/pokemon-dungeon-lab/issues/33)，由 dev lane 在 Windows 本机执行。分支为 `feature/web-ea-build-dev-codex`，起点为 `aee1d9645105716c18205d1a6c876cccd5e1d8be`。这是代理操作的制作者自测，不能据此认定玩家体验、正式平衡或阶段7整体验收通过。正式审查与合并由 main lane 按 PR 的提交 SHA 执行。

## 本次实现

- 构建采用 `base: './'`。Phaser 单独分包，标题与存档工具先加载，进入游戏画面才请求 Phaser。
- 标题与游戏页均提供“设置与存档”。动画仍使用原来的浏览器偏好；按键说明集中在设置窗口内。设置打开时，方向键不会操作背后的游戏。
- 导出文件包含完整 envelope，包括 `format`、`rules`、`content`、`build`、当前远征、最近结算和基地档案。导入前提示覆盖，导入仍经过 `decode` 校验与既有迁移。
- 不能迁移的版本说明原因，原始记录可以逐字节导出。无效导入、取消和写入失败保留原记录；正在保存或保存失败未解决时不接受导入。
- `ECON`、`RULE_VERSION`、`CONTENT_VERSION` 和数据文件均未改动。没有新增依赖，没有使用云任务。

相对路径和分包配置依据：[Vite 构建选项](https://vite.dev/config/build-options)、[Rolldown codeSplitting](https://rolldown.rs/reference/OutputOptions.codeSplitting)。本次实际安装并运行的是锁定的 Vite 8.3.5、Phaser 4.2.1、TypeScript 5.9.3。

## 实际运行结果

平台为 Windows，Node 24.22.1，npm 11.16.0；浏览器为无头 Microsoft Edge 156.0.4314.50。依赖使用 `npm ci --ignore-scripts` 按现有 lockfile 安装。

| `npm run check` | 通过，退出码 0 |
| `npm test` | 250 项通过，0 失败，约 132.6 秒；包含仓库已有的长测，未修改长测代码 |
| `npm run test:acceptance` | 75 项通过，0 失败 |

浏览器命令实际设置了 `TRIAL_URL` 和 `PLAYWRIGHT_MODULE`，后者指向本机已有的 Playwright 模块。根目录由 `vite preview --host 127.0.0.1 --strictPort` 提供；子路径由本机 Python `ThreadingHTTPServer` 提供，只映射 `/private/ea/`，其他路径返回 404。测试脚本位于 `tests/browser/web-ea.mjs`，首屏测量脚本位于 `tests/browser/web-ea-performance.mjs`。

根目录和子路径均实际执行：

1. 标题 → 选择木守宫和水跃鱼 → 基地 → 出发 → 从入口正常撤离 → 回基地。这是一轮结束的入口撤离，未声称完成有效探险或三层通关。
2. 在另一独立浏览器上下文完成固定主图六轮：右移、三次普攻、拒绝邀请、移到 G、取得目标并正常撤离。该流程通过真实按键、画布点击和按钮完成，未通过修改游戏状态完成。
3. 在基地下载存档文件，再通过文件选择导入。比较导出、导入后以及重载后的完整 JSON，结果一致；将最近远征的轮数改为负数后，导入被拒绝，原记录不变；取消覆盖也不改变记录。
4. 构造不兼容版本的本地记录，页面显示中文原因；下载的原记录与构造文本逐字节相同，然后导入有效备份恢复。这一步是专门构造的恢复场景。
5. 标题资源请求不包含 Phaser；进入游戏后才请求。动画偏好经重载保留，设置内方向键不推进回合。两种托管下均未发现页面脚本错误或失败资源请求。

新增存档单元测试 `tests/core/save-transfer.test.mjs` 的 8 项检查覆盖完整字段往返、非法篡改、支持的旧结构迁移、不兼容版本、覆盖确认、坏档导出保护、写入失败恢复，以及保存中的并发拒绝。这里的“篡改拒绝”指既有规则校验能识别的非法状态，不代表存档具有密码学防伪能力。

## 构建体积与首屏

正式基线是在改动前、上述起点提交上运行的 `npm run build`。Vite 原始输出为：

```text
index-ICPsVOZx.js  1,538.37 kB │ gzip: 412.68 kB
```

修改后的同命令输出为：

```text
index-2ridgwm3.js     176.11 kB │ gzip: 57.84 kB
phaser-DG4mytAH.js  1,367.25 kB │ gzip: 357.11 kB
```

以下表格统一用文件实际字节数和 Node `gzipSync` 默认参数测量，gzip 数字与 Vite 的压缩统计口径不同，不混用：

| 指标 | 开工基线 | 本次候选 |
| --- | ---: | ---: |
| 首屏主脚本字节数 | 1,538,375 | 176,117 |
| 首屏主脚本 gzip 字节数 | 410,711 | 57,564 |
| 延迟加载的 Phaser 字节数 | 包含在主脚本 | 1,367,250 |
| 延迟加载的 Phaser gzip 字节数 | 包含在主脚本 | 355,436 |

首屏脚本减少约 88.6%；进入游戏仍需下载 Phaser，总脚本体积没有因此减少。标题时间从导航开始计时，到标题按钮插入 DOM 后经过两个绘制帧为止。每组使用五个新浏览器上下文，本机 HTTP、无网络限速；基线五次为 351.8、188.5、167.4、162.2、159.8 ms，候选五次为 106.1、67.4、64.4、64.7、63.6 ms。这里只比较本机观测值，不推断 NAS、外网或其他设备的加载速度。

本次没有部署到 NAS，没有公开发布，没有验证 Windows 桌面封装，也没有独立玩家体验证据。测试完成后，两台本机服务器已停止，测试端口没有监听进程。
