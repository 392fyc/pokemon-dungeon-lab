# 招募资源与伙伴取舍

当前主候选是：**容许局内换人补资源，旧伙伴的同行价值由仍可使用的配招和当前作用体现。**同功能且只有资源更充足的新人可以是明显好选择，不要求每份邀请都两难。回营保留培养和情感收藏另列价值，不冒充眼前的战术优势。

本页整合 REA-research-lab 的独立研究，与[跟随、倒下和入场规则](伙伴跟随与倒下通路.md)使用同一接口。三人同行、当场替换、旧实例安全回营并保留培养是已定方向；初始化公式、数值和场景是当前研究候选。PR #1已完成研究范围复审与合并；玩法、数值和体验未因此获批。资源定义与替换规则统一维护在[当前规则表](当前规则表.md)R07—R08，本页保留具体资源比较。

## 1. 资源怎样来，何时固定

| 方案 | 能带来什么 | 主要代价 | 当前取舍 |
| --- | --- | --- | --- |
| 按实例上限统一比例初始化 | 看见上限即可预判；资源不另外随机；不同配招仍有不同用途 | 小 PP 上限的取整比例不同，具体比例仍需体验调整 | 主候选 |
| 每种功能配置单列入队次数 | 可以突出某个招式当下能用几次 | 每种配置需要维护和解释，邀请更依赖查表 | 保留比较，不先逐角色定制 |
| 继承被击败时的状态 | 与上一场战斗有联系 | 击败后通常 HP 为零，仍需补恢复规则，还可能诱导操纵敌方耗 PP | 当前不采用 |

本页各例采用[规则表R07](当前规则表.md#r07-邀请快照与资源)的半额资源样例，包含逐招向下取整、合法招式至少一次及快照固定时点。满员替换与落点按R08，其他成员与共用背包不恢复。旧稿的60%值仅作历史或敏感性对照，不作为另一套现行规则。

固定公式是为了让相同输入能复算，不是平衡结论。连续邀请、资源阈值与招募定位的进一步比较见[首片段方案](返程与招募的首片段方案.md)。

## 2. 用同一份资源比较三种理由

下面三组分别从同一资源快照开始，不把上一组消耗带入下一组。位置和敌人由各组明确给出。数值不是最终角色定义。

| 成员 | 生命 | 已装备的特殊招式与剩余次数 |
| --- | --- | --- |
| A，主控 | 12/20 | 贴身强击：伤害 10，2/2 PP |
| B | 12/20 | 邻位保护：抵减下一敌方阶段首次伤害 4，1/2 PP |
| C | 6/20 | 直线打击：伤害 10、射程 3，1/2 PP |
| 邀请中的 N | 10/20 | 贴身强击：伤害 10，1/2 PP；近身推退：无伤害，1/2 PP |

共同规则：四方向，普攻伤害 6，每次施招耗 1 PP；一人一轮只能移动、攻击、施招或等待之一。伙伴不自动花 PP。我方固定 A→B→C 后敌方；换人删除旧人并把 N 追加到队末，入场按[本批固定集结格](伙伴跟随与倒下通路.md)。下面逐例说明邀请时的主控与占位；处理完邀请后，战斗均选 A 主控，每轮至多覆盖一名伙伴。最后敌人倒下时停止局部记录，真实地图仍执行剩余成员与轮末处理；表内截断不能直接作为下一场位置或迷宫终局。

地图均为 x=1…4、y=1…5 的开放地面，边界外为墙，另加的墙见各例。射线被墙或存活单位挡住，倒下者已从地图退场。近战敌人找最近存活成员，同距按我方队列；移动的等长路径按右、下、左、上。没有陷阱、反击、持续伤害或其他恢复。

### 例一：保留残血射手，比只换最低生命者更省行动

A=(2,2)、B=(2,3)、C=(1,2)。H=(3,2)，HP18，相邻伤害8，否则接近一步；R=(1,5)，HP6，定点射手，同列或同行四格内无遮挡攻击2。敌方 H→R。邀请菜单打开时 A 是主控，H/R 已在所列位置存活并可见：本格 A、右格 H 均占，替 B 时下格释放，N 到(2,3)；替 C 时下格仍有 B，转取左格(1,2)。邀请来自已结束的上一完整行动轮，不假设敌人随后才生成。

| 选择 | 动作 | 结果 |
| --- | --- | --- |
| 拒绝，保留 A/B/C | 第1轮 A 强击 H 至8，覆盖 C 直线击倒 R，B 等待；H 打 A 8。第2轮 A 强击结束 | 2轮，3 PP，1次伙伴覆盖；生命 A/B/C=4/12/6。A 强击与 C 直线用尽，B 保护仍1 |
| 接受，换 B，保留 C | N 在(2,3)，队列 A→C→N；A/C 执行同上，N 等待 | 2轮，3 PP，1次伙伴覆盖；A/C/N=4/6/10。N 两招各1，B 回营保留实例培养 |
| 接受，换 C | N 在(1,2)。第1轮 A 强击、覆盖 B 保护，H 打 A 4，R 打 N 2；第2轮 A 击倒 H，R 再打 N 2。第3、4轮 A 等待，分别覆盖 N 到(1,3)、(1,4)，各挨2；第5轮 N 默认普攻击倒 R | 5轮，3 PP，3次伙伴覆盖；A/B/N=8/12/2。A 强击与 B 保护用尽，N 两招各1；C 回营 |

第三条保住更多 A 生命，却失去远攻、增加两次干预并把 N 压到2生命。如果想迅速、少干预地清掉这段，保留 C 更合适。接受邀请也可以保留 C，并非只能在“拒绝”和“换最残血者”中二选一。没有邀请时第一条仍成立。

### 例二：新人推退改变承压过程

A=(2,2)、B=(1,2)、C=(3,3)，H=(3,2)，HP24，近战伤害8。没有其他敌人；普通出口允许在此段后结束。本例邀请产生时 C 是主控，集结格(3,3)；接受并替 C 时本格释放，N 到(3,3)。接受或拒绝并结束菜单后均改选 A 主控，免费选择不重排队列，不附送动作。

| 选择 | 第1轮 | 第2轮 | 结果 |
| --- | --- | --- | --- |
| 保留原队 | A 强击使 H 剩14；覆盖 B 保护 A；C 默认普攻使 H 剩8；H 打 A 4 | A 强击击倒 H | 2轮、3 PP、1次覆盖，A/B/C=8/12/6；C 直线仍1 |
| 接受 N 换 C | A 强击使 H 剩14；B 等待；覆盖 N 向上推 H 到(3,1)；H 回到(3,2)，本轮只移动 | A 强击使 H 剩4；B 等待；N 默认普攻击倒 H | 2轮、3 PP、1次覆盖，A/B/N=12/12/10；B 保护仍1，N 强击仍1、推退用尽 |

推退让 H 的这一轮从攻击变为移动，A 少受4伤害。N 多出的生命是另一项独立收益。若下一段重新需要射程，失去 C 的代价仍会出现。本表没有穷举其他输入，例如接受 N 后用强击更快压血也可能省 PP，但会承伤；不能把本例写成 N 全面优于 C。

### 例三：单纯补生命可以就是正确理由

A=(2,2)、B=(2,3)、C=(1,2)，另有墙(2,1)和(3,2)；M=(1,1)，HP12、相邻伤害6。邀请时 A 主控：本格被占、右格是墙、下格有 B，替 C 后左格(1,2)是第一个合法格，N 到该格。这里只比较“留在当前位置清除”计划，A/B 都等待。

| 选择 | 第1轮 | 后续与结论 |
| --- | --- | --- |
| 保留 C | 覆盖 C 直线打击，M 剩2；M 打 C 6，C 倒下 | 用1 PP、1次覆盖，C=0。队伍未全灭，后续另按倒下规则处理 |
| 接受 N 换 C | N 在(1,2)，覆盖 N 强击，M 剩2；M 打 N 6，N 剩4 | 第2轮 N 默认普攻击倒 M；共1 PP、1次覆盖。N=4，强击用尽、推退仍1；C 安全回营 |

两种技能此处都造成10伤害，推退没有贡献。差异来自新人多4生命，资源改善足以支持这次接受。不据此说拒绝必败：玩家还能后撤、改变主控或接敌位置，只是那些属于另一套需要另算行动的计划。

## 3. 旧伙伴的价值与处理方向

| 价值 | 成立条件 | 对选择的含义 |
| --- | --- | --- |
| 当前局继续同行 | 还有能在眼前使用、改变做法的招式或属性 | 是具体保留理由；次数耗尽或用不上时不能仅凭培养过就说更强 |
| 回营后的培养 | 同一实例保留永久招式库，下次能重配 | 可能支持换下保人，不一定支持继续同行 |
| 情感与收集 | 玩家喜欢该实例或其经历 | 玩家可为此承担代价，不当作已存在的战术平衡 |

| 处理方向 | 收益与问题 | 当前取舍 |
| --- | --- | --- |
| 容许局内换人，沿用个人永久配招 | 规则少，新人不复制旧人已学招式；接受部分邀请明显有利 | 主推荐 |
| 统一降低新人生命或 PP | 能减少补给，但不能创造功能差异；过低会让新人没有可用行动 | 有明确资源总量问题再调整，不先普降 |
| 忠诚、连续上场加成或额外使用成长 | 能人为拉开新人老人的数值，却增加计数、说明与通胀，并可能强迫反复带人 | 当前不采用 |

目标是让配招投资在合适局面有具体作用，不保证所有旧伙伴每次都值得留下。同种不等于同功能；但如果属性、招式、站位、队列机会都一样，只有新人生命更多，就承认这是一次补给奖励。半额资源仍是计算样例，不是已经证明的平衡比例。

## 4. 连续两次邀请怎样改变同一支队伍

这里是三次同构遭遇的连续**资源账本**，不是自然概率模拟或完整地图行动脚本。每次局部接敌都是 y=0、x=0…3 的单格走廊，A在0、B在1、前排在2、敌人在3，边界外为墙。场间安全路段使用正常移动，无承伤、恢复或资源掉落；各分支以同构队形接敌，不把行进算入战斗轮数或当作免费战斗移动。真实地图的另一组完整对照见[连续探险](一段完整探险的连续推演.md)，不将本账本的同构输入冒充已经走过的地图。

初队 A→B→C。A为12/20生命、强击2/2 PP；B为12/20生命、保护1/2 PP；C为10/20生命、强击2/2 PP。每场前排为主控，A被 B 隔住而等待，B邻接主控等待。普攻6、强击10耗1 PP、保护抵首次伤害4。敌人 HP16、相邻伤害4，无其他效果。

第一、第二场击倒后分别实际产生 N1、N2 邀请；二者各为10/20生命、强击1/2 PP，与 C 同属性同配置。替前排会释放本批集结格，新人仍在2并排队末；菜单结束后可改选新人为主控，下一轮才行动。前两场没有别的邀请。未来敌人只是作者用于核算的输入，玩家在邀请时不预知未探索房间。

每次“强击→普攻”使敌人16→6→0，前排承伤4、耗强击1 PP，用2个战斗轮。

| 节点与选择 | A：HP／强击PP | B：HP／保护PP | 前排：HP／强击PP | 说明 |
| --- | --- | --- | --- | --- |
| 初始 | 12／2 | 12／1 | C：10／2 | 最大HP均20，所列招式最大PP均2 |
| 第一场结束 | 12／2 | 12／1 | C：6／1 | C承伤4、用1强击 |
| 接受 N1 换 C | 12／2 | 12／1 | N1：10／1 | 净多4生命，强击次数未增加，C回营 |
| 拒绝 N1 或没有这份邀请 | 12／2 | 12／1 | C：6／1 | 同一资源结果，分别代表主动选择与没有选择 |
| 第二场结束，之前接受 | 12／2 | 12／1 | N1：6／0 | 又承伤4、用1强击 |
| 第二场结束，之前保留 | 12／2 | 12／1 | C：2／0 | C累计承伤8、强击用尽 |
| 接受 N2 换当前前排 | 12／2 | 12／1 | N2：10／1 | N1或C回营；获得新生命与一次强击 |
| 拒绝 N2 或没有这份邀请 | 12／2 | 12／1 | N1：6／0，或C：2／0 | 不自行恢复 |

第三场明确比较：

| 路线 | 行动与结果 |
| --- | --- |
| 已接受 N2 | 强击→普攻，2轮；N2=6生命、强击0。A/B仍12生命，强击2／保护1 |
| 保留 N1 | 第1轮普攻，覆盖 B 保护抵消4伤害；第2轮普攻后挨4，N1剩2；第3轮普攻击倒。共3轮、1次覆盖、1保护PP；A=12／强击2，B=12／保护0，N1=2／强击0 |
| 保留原 C 且坚持原位清场 | 即使 B 抵消第一轮伤害，第二轮 C 仍会倒下，敌人剩4。A/B存活，不是整队必败；换前排、撤退或其他做法要另算动作 |

普通出口可在第二场后使用，这是本账本的输入。无邀请分支可以结束，不要求必须招到人。这里没有证明每种地图都存在同样安全的出口。

**完全同功能的反例：**第一场后 C 为6生命、强击1，N1为10生命、强击1；同属性、同配招、同落点且同为队尾。在这些输入下，N1能做 C 现有的动作并多承受4伤害，没有必要发明一个战术理由强迫保留 C。旧 C 回营的培养保留同时可以是收益。

**滚动补给确实成立的边界：**如果整条路线一直重复这个单敌负担，并且每场后都实际出现同配置新人，前排就能反复回到10生命、一次强击，A/B不消耗。半额规则没有阻止它；实际有限邀请也不等于它对深入毫无影响。同轮 C→N→M 不插入行动，不能把 N/M 资源相加，但不同场之间实际耗用的新资源确实能延长探索。

## 5. 旧人的已学招式何时值得留下

沿用第二场后原 C 的2生命、强击0，另明确 C 已永久学会并装备直线打击，剩1/2 PP、伤害10、射程3；前两场没有用过。新人仍10生命、强击1，没有远攻。A/B资源沿原保留分支，均12生命，强击2／保护1。

本例地面为 y=0、x=0…5 的走廊，其余为墙。A0、B1、C2，队列 A→B→C，C主控；邀请时已经看见 R5，HP6、定点射程4、伤害6，射线被活单位遮挡。不借未知房间突然出现克制来制造取舍。

保留 C：第1轮 A/B等待，C从2直线击倒 R，耗1远攻PP，无伤。C仍2生命，强击0、直线0，B保护保留1。

换新人：预览释放主控所在格2，N入该格、排队末；结束菜单后选 N 主控。无保护时，两次接近各挨6，N会在攻击前倒下。一条使用现有保护的明确路线是：

| 轮 | A行动后位置 | B行动后位置 | N行动后位置 | 敌方结果 |
| --- | --- | --- | --- | --- |
| 1 | 0，受 B 阻挡等待 | 1，覆盖为保护 N，PP1→0 | 3，向右移动 | N受2伤害，从10→8 |
| 2 | 0，执行时 B 仍在1 | 2，默认跟近 | 4，向右移动 | N受6伤害，从8→2 |
| 3 | 1，默认跟近 | 3，默认跟近 | 4，普攻击倒 R | 无伤，结束 |

结果3轮、1次覆盖、1保护PP，N强击仍1；A强击仍2。旧人的一项**尚有次数且眼前能用**的已学招式，节省了2轮和一份支援资源。它已耗尽时只有下次出发价值，不能继续称为当前远攻；另一成员也能同样无代价射倒 R 时，保留 C 的优势也会减弱。

## 6. 用现有遭遇改变负担，不加招募惩罚

当前建议接受短段同质遭遇中的换人收益；重要深入路线不要只重复“一个前排就能独立完成”的同一负担。优先改已经存在的敌人组合和位置，而不是新增忠诚值、费用或每局招募次数。下面给出一项明确配置，说明这不是只写一句“增加敌人”。

地面仅 (0,0)…(3,0) 及(2,1)，其余为墙。A=(0,0)，12生命、强击2；B=(1,0)，12生命、保护1；N主控=(2,0)，10生命、强击1。E=(3,0)，HP16、相邻伤害4；F=(2,1)，HP10、相邻伤害4。队列 A→B→N，敌方 E→F，所有敌人已见，位置全程不变。击倒 F 和 E 后本例都**没有邀请**；这是明确分支输入，不是招募概率结论。

| 轮 | N 独自原位输出，A/B一直等待 | 使用一次 B 保护的应对 |
| --- | --- | --- |
| 1 | 强击击倒 F，PP用尽；E打4，N剩6 | B保护PP1→0；N强击击倒 F，E伤害被抵消，N仍10 |
| 2 | 普攻 E：16→10；挨4，N剩2 | 同样普攻，挨4，N剩6 |
| 3 | 普攻 E：10→4；挨4，N倒下 | 同样普攻，挨4，N剩2 |
| 4 | 该独自输出计划已失败 | N普攻击倒 E，结束 |

先打 E 也不能救这套独自原位打法：第一轮两敌打8，N剩2；第二轮即使击倒 E，F仍会击倒 N。优先杀 F 时，N总共要4次攻击，期间 E 有3次攻击共12伤害，超过10生命。这只否定“不退位、不支援”的计划，不声称所有撤退或换前排打法均失败。

可行应对最终 A=12生命／强击2，B=12生命／保护0，N=2生命／强击0；付出1次伙伴覆盖及1保护PP。没有要求每个成员都掉血，也没新增技能。若 F 实际产生邀请，必须按轮末入场重新算，不能沿用这张“没有中途补给”的表。

这些表支持当前取舍：容许清楚的补给奖励，让既有配招和遭遇结构承载选择。它们没有证明整局邀请分布、所有路线或最终资源平衡成立；若坚持全程同质输入且连续补给，就应接受持续换人可能占优。

## 7. 面板应帮助玩家看懂什么

并排展示新人和被换下者的准确当前/最大生命、各招式当前/最大 PP、射程、阻挡条件、个人学习归属。明确写出旧实例回营、本局不能远程调回、留下成员不恢复、共用背包不随普通替换带走。

“失去直线打击”须区分两件事：同行是否还有人装备它、是否还有次数。可显示“离队后无人装备直线打击”，或者“仍有 A 装备，但 PP 为0”。这只核对已知配招和次数，不替玩家计算最佳站位或泄露未探索房间。

同配置新人只多资源时，可以直接写“多4生命，强击次数相同”，不制造含糊的总战力。接受前显示本批集结格、实际入场格、队列末尾和下一轮才行动；附近没有合法格时提前说明，倒下在哪一层不影响资格。保留拒绝与查看队伍，不把回营写成未经决定的免费治疗。

## 8. 与移动和保存共同使用的结果要求

邀请产生与资源快照、本批集结格 → 玩家接受或拒绝 → 旧实例回营、新人位置与队列、必要主控继任 → 必要直接效果 → 已处理状态，共同构成一个完整结果。接受不附送移动、展开、攻击或等待恢复，也不重新跑世界周期。

存档恢复到完整轮末或某项邀请完整处理后，恢复相同随机结果、资源快照、队伍、占位和待处理顺序。不能只恢复旧人回营而漏掉新人，也不能重复初始化。直接效果若使全队倒下，先前已完成的回营保留，其余邀请取消。[玩家操作方案](玩家操作与中断恢复.md)明确保存成功后才开放后续状态变化，保存失败重试当前完整结果。这里要求正常保存与恢复的一致性，不宣称本地文件防篡改。

后续实际观察记录选择理由（资源、功能、保人、收集）、损失作用是否真的有用、轮数、伙伴覆盖次数、逐招 PP、倒下人数，以及玩家是否看懂面板。当前只有明确输入下的纸面结果，没有玩家行为、招募密度或平衡结论。
