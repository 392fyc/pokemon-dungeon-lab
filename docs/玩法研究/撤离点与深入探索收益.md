# 撤离点与深入探索收益

当前规则以[核心玩法与首版范围](核心玩法与首版范围.md)为准。首版地图当前沿用可返回G的候选，单向推进只作对照；两者不并列为同时生效的规则，最终采纳仍由用户决定。

状态：沿用户保留的方案 B 继续形成候选。目标是让短局可以完整结束、长局有值得继续的内容，并保持每局一次基础报酬与救援时钟结算。任务与时长见[基础勘探任务与单局节奏](基础勘探任务与单局节奏.md)；收入和救援时钟见[有效探险与基础收入](有效探险与基础收入.md)。

## 三种出口结构比较

| 结构 | 有利之处 | 主要代价 | 本轮判断 |
| --- | --- | --- | --- |
| 随时免费结束并保留所有收获 | 时间最自由，几乎没有返程负担 | 每次获得关键物品后都能立即解除风险，继续与撤离的空间判断较弱 | 不作为普通冒险起点；暂停另行解决时间中断 |
| 每个探索段末尾保证出口，单向推进 | 玩家在可预知的节点收尾，下一段形成明确承诺 | 进入下一段后要到下个出口，必须提前说明风险与大致内容量 | 对照候选，不作为当前首版规则 |
| 回到最初入口，或随机找到稀少出口 | 返程规划和应急资源有价值 | 大量重走已清区域，出口位置不确定会拉长恢复过程 | 暂不作为基础任务默认；以后可用于特定高风险任务 |

当前首版候选：**基础目标附近保证出口，继续后可沿原路返回G；后段也可配置正常出口。** 返回保留旧层的敌人、物品和目标状态，不重置收益或恢复资源。不能返回上一段的单向推进只作对照，若以后采用须明确变更，不悄悄关闭已承诺可用的出口。

下一段的保证出口不以抽到钥匙、指定属性、击败稀有随机敌人或可选 Boss 为条件。普通任务仍可能需要处理公开的常规遭遇；最低恢复路线的必经段保持无强制战斗。高级任务可有不同规则，但要在选任务时列明。

## 普通迷宫与无尽守关的适用范围

本页的前段与出口结构首先用于普通定向迷宫。[无尽分区候选](无尽迷宫分区与守关规则.md)以十层为例组织区域：中段、Boss 战前以及胜利后有正常结束选择，Boss 守的是继续进入下一主题的入口，不能用它锁住战前普通撤离。十层不是普通十个探索段，也没有已测时长。

装置按用户明确的低概率保伙伴定位处理，探索到节点后才成为额外选择，普通出口不以它出现为前提。

## 一次探险中的节点关系

```mermaid
flowchart LR
    A[基地：选择任务与队伍] --> B[前段：基础目标与可选探索]
    B --> C[第一出口：查看收获与下一段线索]
    C -->|撤离| Z[结束本局并统一结算]
    C <-->|继续或原路返回| D[第二段：新的生态或战术机会]
    D --> E[第二出口]
    E -->|撤离| Z
    E -->|继续| F[第三段：自选深入目标]
    F --> G[末段出口]
    G --> Z
```

最低恢复配置可以只走前段；普通配置使用同一组目标和出口规则，后续段落提供正常冒险内容。不要求玩家先返回基地重接任务才能接着探索。

“段”不是另一次探险。选择继续时，保留当前局的队伍、消耗、目标完成状态、背包和随机进度；没有第二笔基础工资，没有新的有效计数，也不在此迎回基地中的救援伙伴。

## 出口提供什么，不提供什么

| 行为 | 当前候选结果 |
| --- | --- |
| 在出口选择撤离 | 结束整局，按合法撤离处理收获，然后判断有效并推进一次 L/X |
| 在出口选择继续 | 同一局进入下一段，已完成基础报酬资格仍保留 |
| 在出口整理保护袋与普通背包 | 依当前容器规则调整，不能增加容量或把袋外物品自动存回基地 |
| 路过出口 | 不自动付款、治疗、恢复招式使用次数或重发补给 |
| 局内新招募伙伴经过出口后继续 | 仍在本次探险；不能以经过出口当作已经安全带回 |
| 接近出口时菜单中止 | 仍按候选失败规则结算，不能冒充合法撤离 |
| 暂停或关闭页面 | 保存并恢复同局，不带出、不计救援 |

正常出口不额外收费、不需要稀有消耗品，也不追加一场倒计时防守战。角色仍需到达出口并完成撤离交互；不能在远处点菜单就无损带走全部物资。队伍跟随、倒下成员怎样携出属于队伍规则，不能让不可控的同伴寻路把已经完成的路线拖成重复劳动。

应急返回道具可以作为后续备选，但当前的“可收尾”不能依赖随机捡到它。已取得的基础报酬资格继续受保护，其他物品与伙伴仍遵守全灭损失候选；出口附近不附送一次全背包保险。

## 特殊服务点与普通出口分开

用户提出商店与伙伴交换机，细则见[商店与伙伴交换机](迷宫商店与伙伴交换机.md)。普通出口仍不自动存货；交换机通过明确选择，将一名成员及少量物资**立即安全转移**，剩余队伍继续同局。该成员和货物不再进入后续全灭损失，工资与 L/X 仍等整局结束一次处理。此处的一次结算不禁止这项显式转移，也不把它算成新探险。

三张[迷宫样例](迷宫与任务样例推演.md)标出不同阶段出口前庭的候选生成位置；只有稀有装置实际出现时，才比较保住新招募者或珍贵成员的价值，携物为附带作用。撤回后须真实击败合格敌人并触发邀请才可能补位。商店只改变当前补给和钱袋，不替玩家存款或发工资；使用装置后也可整队撤离，不强制继续。

## 继续前要看到哪些信息

第一出口与后续出口应能回答：

- 已经有多少能安全保留的基础报酬资格，背包里哪些收获仍有风险。
- 当前队伍状态、消耗与保护物品选择；装置已经送回的成员与货物独立列明，不计作留队战力或仍有风险的背包。
- 下一段的主要生态、敌人或地形主题，以及可能出现的收益类别。
- 下一次正常出口与可返回路线的位置、预计内容量；当前首版可返回上一出口，不提示为单向承诺。
- 本任务既定的走失风险和救援报价。若任务另有风险变化，必须事先列明，不能仅因玩家背包值钱临时涨价。

信息应帮助选择，不必提前公开全部敌人位置和掉落。初期可只给两类重点线索，例如“更可能遇到水边生态伙伴”与“有机会取得移动用途的招式机”；来源与可用名单确定后再配置。

本轮比较先假设同一任务内走失条件与救援费遵守进场前的说明，深入增加的主要是战斗失败风险、消耗和额外收获；没有擅自确定逐层上涨的费率公式。

现行返回策略与三种终局的期望口径见[可返回出口的探险对照](可返回出口的探险对照.md)。下文二结果算式保留为简化例：只有没有提前返回，或把s与G分别改为所有正常返回概率及其条件平均新增收益时适用，不能直接拿旧参数证明当前可返回地图的风险。

## 深入的价值来自新的机会

| 收益方向 | 可用于本作的候选 | 如何保留短局价值 |
| --- | --- | --- |
| 伙伴生态 | 深段增加某类生态的接触机会，让想补齐队伍作用的玩家有明确方向 | 浅层仍能招募多样普通伙伴；不把所有有用伙伴锁到深处 |
| 招式用途 | 更有针对性的招式类别或选择机会，帮助构建近身、远程、支援、位移组合 | 不要求深层专属物才能完成基础目标或支付最普通救援 |
| 地形与战术 | 通过已有二维地形和敌人组合，让刚形成的队伍搭配有新的使用场合 | 不用长距离空走或单纯增加敌人血量填时长 |
| 额外战利品 | 更高的潜在价值，给玩家筹措多只伙伴费用的机会 | 高阶净收益仍需承担对应风险；早撤照常得到已赚基础报酬 |

这些是内容组织方向，不是已经批准加入融合、Mega 或其他大型机制。只给“更多同样的金币”，可能无法抵消长局在等待计数上的劣势；全部放独占强力奖励又会把短局变成明显次等选择。优先增加不同用途与可预判的方向，数量和平衡留给代表内容验证。

完成目标后提前撤离，应有完整结算，不扣已赚工资、不降低委托评价来羞辱早退、不强制重做已经完成的部分。继续探索的理由来自下一段机会，不来自失去眼前成果的威胁。

## 一个继续或返回的算术例子

只比较下一段的货币价值，暂时不计算喜爱伙伴、等待机会和游玩乐趣：

- V：现在能通过撤离保住、若失败则会失去的那部分物资价值。
- G：继续并成功到下一出口时，预期增加的可带回收益。
- s：从当前点继续并成功带回的假设概率。
- D：如果失败，额外救援费用的条件期望。
- k：为这次深入额外消耗的物资成本。

假定本例中的 V、G 在失败时都会丢失，已保护物品和基础报酬是两种选择共有的部分，则继续相对立即撤离的货币期望变化为：

**Δ = s × G − (1 − s) × (V + D) − k**

令 s = 0.8、G = 160、D = 60、k = 10，仅为纸面示例：

| 当前风险物资 V | 继续的期望变化 Δ | 例子表达的选择 |
| --- | --- | --- |
| 100 | +86 | 收获尚少时，有理由继续寻找更多机会 |
| 600 | −14 | 已经取得很多需要的东西时，有理由先保住它们 |

算式没有证明真实胜率、物价或玩家偏好；新伙伴的情感价值、期限压力、失去可用队员的成本，以及短局更快推进 X，都未包括。玩家可以因自己的目标作出不同于货币期望的选择。这里要验证的是同一个出口能否产生不同而合理的选择，不能把所有人都引向继续当作唯一成功指标。

## 和救援池的衔接

只在整局退出或失败时处理一次有效结算：

1. 基础目标完成时登记报酬资格，继续探索不再重复登记。
2. 最终按目标或新增跨局成果判断有效，包含本局通过交换机已安全送回的新伙伴或物资；处理剩余物资和伙伴归属并发工资，不复制已转移对象，不对已送回成员再判走失。
3. 有效局仅推进出发前池内的 L/X 一次；新走失者完整 L 入池；回归者不参与本局走失判定。
4. 在基地处理最后付款窗口；同局刚付款的伙伴从下一次有效探险开始计算 X。

因此，选择三段长局也只消耗一次未付费期限，可能争取更多收入来支付多只伙伴；选择短局则更快推进已付费等待。二者是玩家可以利用的差异，没有额外制造第二种计时货币。

若某伙伴只剩一次未付费期限，继续深入既可能挣够钱，也可能全灭损失物资。界面应提醒本局结束后会到期，但不能自动替玩家决定继续。退出后先发收入、再给最后付款机会，仍沿用候选顺序。

## 需要被反例检验的部分

- **只为等待而重复跑短局。** 固定 X 与每局一次计数使其速度更快；详见[恢复时间推演](基础勘探任务与单局节奏.md)。靠更多目标皮肤不能解决费用或等待过重。
- **基础目标过于安全且收益过高。** 高等级玩家可能只做最短段；需要比较实际净收益与时间，同时尊重玩家偏好低风险。
- **单向深入变成意外绑架。** 若玩家不知道不能返回，或下一段需要未提示的道具、必打 Boss，阶段选择就失去可信度。必须提前说明且保证普通出口条件。
- **普通出口与特殊保存混淆。** 路过出口不自动存货；交换机是用户提出的显式局内保存功能。候选只送一人和有限物资，但若与保护袋合计保住全部关键价值，仍可能使风险很低，不能以数量有限宣布问题已经解决。
- **稀有收获让快速中止仍更划算。** 标准迷宫可能出现目标前拿到保护物品就离开；有成果必须计有效，但仍不能声称消除了所有此类策略。
- **为了观察点而观察。** 若目标只增加重复交互、不影响路线和下一步决策，应删减目标步骤，不靠增加奖励掩盖无趣。

## 后续验证顺序

纸面路线已经在[三组样例](迷宫与任务样例推演.md)展开，装置例外与经济对照分别见[服务点规则](迷宫商店与伙伴交换机.md)、[恢复账本](救援费用与等待次数推演.md)；以后在用户授权的实现阶段验证代表内容。纸面至少覆盖：首段正常撤离；连续穿过两处出口再失败；只剩一次期限时带货返回；最低二人恢复；携带新伙伴继续后全灭；退出页面后恢复同局。

原型阶段记录到各出口的时间、继续/撤离原因、重复路程、实际入账与救援支出。不要先建大地图再用隐藏出口或敌人血量拉长局时。
